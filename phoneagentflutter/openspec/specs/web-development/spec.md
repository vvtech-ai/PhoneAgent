# web-development

## Purpose

记录用户批准的 Web 优先研发目标；完成进度见 active change，不代表已验收。

## Requirements

### Requirement: 完整App回执评价演练按目标隔离
隔离完整App宿主 MUST 复用正式回执、录音、赞踩和条件评分页面及控制器，只替换外部服务；MUST NOT 调用真实电话、音频、文件或积分服务。

#### Scenario: 恢复回执后跨任务评价
- **WHEN** 从任务列表恢复合成单路或批量回执，操作录音、赞踩及条件评分后重新进入
- **THEN** 评价和草稿按FeedbackTarget种类/ID隔离，eligible决定评分显隐；失败保留草稿和重试身份，成功只读，退出合成登录或场景重置
- **AND** 恢复与续聊保留种子历史，普通新对话不伪造外呼完成，样例奖励不修改真实钱包

### Requirement: 完整App附件演练必须同源恢复
隔离完整App验收宿主 MUST 复用正式文档、OCR、会话与历史控制器，仅替换文件选择/解析/识别/存储外部端口，不访问真实文件或账号。

#### Scenario: 导入附件后从任务恢复
- **WHEN** 从正式对话菜单导入合成文档或图片，退出后从任务列表恢复
- **THEN** 从同一会话内存ledger恢复文档类型、图片及锚点；选图本身不提交Agent，随后文字携带成功OCR上下文，恢复不重新上传
- **AND** 不同会话及登录代次不串数据；失败/取消不创建成功文档消息，OCR只读展示不新增确认步骤

### Requirement: 完整App联系人演练必须连续且隔离
隔离完整App验收宿主 MUST 使用正式联系人、备注、Skill、对话和任务路由，由同一合成数据源支持连续恢复；联系人与备注 MUST 按登录代次隔离，系统拨号 MUST 由合成端口替代。正常Web默认不读取手机通讯录，手机端业务规则不变。

#### Scenario: 指定联系人进入任务后恢复
- **WHEN** 从联系人详情选择Skill并发送首条有效输入，退出后从任务列表恢复
- **THEN** 首轮携带所选联系人，恢复不重发命令，后续输入不重复注入首轮上下文；保存备注在同场景保留而退出登录或目录后重置
- **AND** Web路由覆盖只在验收宿主设置，不改变正常Web不支持页面，不发生真实备注写入或系统电话操作

### Requirement: 完整App开发者演练复用正式入口
完整App演练 MUST 通过既有拨号暗号解锁开发者功能，复用正式设置/外呼页面及Controller，仅以隔离内存Repository替换号码服务；MUST NOT 修改真实后端号码、系统网络、记录或权限。

#### Scenario: 连续设置与退出
- **WHEN** 保存、取消、删除或失败重试后重新进入外呼设置
- **THEN** 页面关闭保留合成保存值，取消不写入，退出登录或场景重置；网络/列表/权限重置入口继续使用既有共享规则和合成端口

### Requirement: 评价与积分集中演练保持隔离
验收目录 MUST 复用正式评价和积分组件，外部服务与草稿使用隔离内存实例，不访问真实账号或发放积分。

#### Scenario: 连续操作与退出
- **WHEN** 评价经历草稿关闭重开、失败重试、成功只读，或积分页重复挂载
- **THEN** 草稿在场景内保留、积分同会话不重复激活；退出目录释放状态和计时器，重开恢复初态
- **AND** 根成功弹窗期间MOCK与返回目录保持可达，返回时清理弹窗，不让上个场景残留覆盖目录

### Requirement: 完整App翻译历史演练保持隔离
开发演练 MUST 从正式任务入口进入正式翻译详情和录音控制器，只替换外部端口，不访问真实账号、声音或文件。

#### Scenario: 查看不同记录与返回
- **WHEN** 从演练任务列表打开不同翻译记录、播放暂停或选择保存
- **THEN** 按合成ID显示对应字幕，未知ID拒绝；保存弹层明确MOCK，取消不显示已保存
- **AND** 返回或退出场景释放计时与端口，不把模拟结果当作真实录音或服务端收件

### Requirement: 完整App对话恢复演练保持一致
隔离验收工具 MUST 复用正式页面，由同一内存事件源提供新对话、任务列表与历史恢复，不改变正式后端或存储。

#### Scenario: 新建对话连续恢复演练
- **WHEN** 在基础App演练中新建文字对话、退出并从任务列表重新打开
- **THEN** 恢复该会话的输入、候选与回复，未处理候选可继续、已处理候选不可重复选择，恢复不重发命令
- **AND** 不同会话不串数据；退出合成登录或重开场景重置新增数据；不得将内存演练标记为真实后端或跨进程持久化通过

### Requirement: 共享移动视口调试
Web MUST 复用移动应用页面和业务代码，宽屏限制手机宽度，窄屏自适应；MUST NOT 另建一套业务网页。

#### Scenario: 桌面与手机宽度
- **WHEN** 在桌面或手机宽度浏览器打开
- **THEN** 页面、弹层与输入区使用相同受限视口，页面无横向溢出

### Requirement: 浏览器流式协议兼容
浏览器 MUST 逐段交付 POST SSE 响应并支持取消，复用既有解码器和会话隔离；开发代理 MUST 限定本机及测试上游，不缓存流、不记录凭据。

#### Scenario: 响应尚未结束
- **WHEN** 上游分段发送且尚未关闭
- **THEN** 页面能接收首段；退出取消上游，不再修改已关闭会话

### Requirement: 分层验证与证据
页面与普通文字流程 MUST 优先使用浏览器及自动化测试；平台能力和里程碑 MUST 在对应真机验证，样例与真实验证必须区分。

#### Scenario: 验收一次文字闭环
- **WHEN** 验证登录、发送、退出、恢复和继续发送
- **THEN** 记录自动断言和关键状态截图；真实接口未通过不得用样例测试替代
