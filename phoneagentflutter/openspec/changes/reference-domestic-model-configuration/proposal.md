## Why
用户确认将指定Android/iOS原生实时翻译配置接入Flutter，解决正式配置来源始终返回null导致国内拨号被拒绝。

## What Changes
- 从固定双端Git对象读取服务默认值与本地Android覆盖，私有凭据仅写ignored工程输入。
- Android有效凭据优先，缺失时采用iOS同服务固定默认配置；豆包voice共同采用Android Nofish，不新增协议字段。
- 双端原生只读配置通道、Dart严格解析及正式Provider接线，缺失/非法/不支持平台仍拒绝。
- 服务端SIP租约及账号/计费门禁不变，不迁移静态SIP账号密码。

## Impact
仅国内模型部署与薄原生适配；无真实外呼/收费/权限动作，不替换普通App。原生客户端已有长期凭据模式按用户最新授权采用，不能称短期凭据或不可提取；Git/日志无值。
