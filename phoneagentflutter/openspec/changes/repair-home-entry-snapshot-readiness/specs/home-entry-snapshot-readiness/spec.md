## ADDED Requirements

### Requirement: 点击普通入口必须取得完整一致快照
客户端 MUST 优先使用有效缓存，无缓存时使用经确认随包卡片与普通 Skill 开场，MUST NOT 等网络或 slogan 持久化才显示有效入口；真实准入仍独立校验。

#### Scenario: 首次启动或缓存读取仍等待
- **WHEN** 网络或本地缓存尚未返回，立即点击随包可用普通卡片
- **THEN** 同快照开场非空且与选定 Skill 匹配，道歉不使用普通开场

### Requirement: 后台配置更新只影响下次读取
客户端 MUST 对 HTTP 刷新单飞并消费失败；有效缓存不能因网络失败被丢弃，关闭后旧响应 MUST NOT 写回或污染当前入口。

#### Scenario: 缓存命中后网络慢或返回新版本
- **WHEN** 已进入旧快照任务，后台返回新配置且缓存写入等待
- **THEN** 当前开场与 TTS 身份保持不变，入口不被阻塞；缓存更新完成后的新读取才使用新版本

#### Scenario: 错误与关闭后迟到
- **WHEN** 后台响应为错误、无效普通开场或在 repository 关闭后返回
- **THEN** 保留有效快照，不伪造成功、不发布旧回调，关闭后不写缓存
