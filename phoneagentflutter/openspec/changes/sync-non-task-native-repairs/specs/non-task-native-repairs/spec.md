## ADDED Requirements
### Requirement: 克隆准入刷新不得使用过期价格
选择及重录前 MUST 刷新目录并核对可用性及价格；价格变化 MUST 更新展示并要求重新选择，不自动提交付费请求。失败候选 MUST 允许重新进入准入，处理中候选 MUST 不重复生成。
#### Scenario: 价格变化与刷新失败
- **WHEN** 当前价格变化或目录刷新失败
- **THEN** 不进入新生成，保留安全反馈；仅显式重新确认后才使用新报价
### Requirement: 候选持续观察与模型隔离
MUST 保留账号、模型、请求代次和候选身份隔离。短轮询到限后 MUST 转为低频只读查询，页面失效停止；晚到READY更新已有页面，不自动生成。录音勾选 MUST 保留，只有确认成功可提交保存。
#### Scenario: 晚到与关闭
- **WHEN** 处理中候选超过短查询时限或旧模型结果晚到
- **THEN** 当前候选低频刷新，旧结果不能覆盖当前模型，关闭后不继续查询
### Requirement: 可信SDK兼容保持凭据与平台边界
Android MUST 在签名加密前按可信域规范身份与协议参数，保留表单编码语义；凭据 MUST 来自安全配置。iOS SDK与任务业务 MUST 不变。
#### Scenario: SDK表单特殊字符
- **WHEN** SDK提交表单或multipart参数
- **THEN** 身份一致且字段解码供签名读取，发送编码保持正确，不打印凭据
### Requirement: Flutter视觉及业务排除边界
MUST 保留Flutter布局和共用控件，仅改必要状态文案和可用性；MUST NOT 修改对话页面、任务列表及其外呼/卡片/评分逻辑。公共错误与诊断 MUST 使用安全有限数据。
#### Scenario: 业务同步
- **WHEN** 非任务修复需要展示新状态
- **THEN** 复用现有控件，不照搬Android视觉；真实认证/收费/设备验收单列待验
