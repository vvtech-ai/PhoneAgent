## Context

批量权益拒绝后，App 未失效会员与商品目录，展示可能继续停留在旧权益。 已读取当前源码，相关后端权益读取直接查询配置与会员数据，没有证据表明该路径存在 Redis 权益缓存。

## Goals / Non-Goals

目标：最新等级批量权益用于后续任务，旧会员与新会员一致。
范围外：运行中通话中断、历史快照改写、支付计价、全量会员迁移和新缓存机制。

## Decisions

新增独立 AgentGateway 装饰器，识别结构化批量权益拒绝后使 catalogControllerProvider 失效；现有 provider 同时承载会员与商品。只刷新一次，不重发命令；原事件、播报、错误和取消保持原样。按登录会话及取消状态隔离延迟回调；不 watch 目录以免重建正在执行的对话。

现有确认、排队成员拨号和实际呼叫准入继续复核权益；幂等回执沿用现有分支，不为旧完成任务追加副作用。配置发布版本和账号会员版本属于不同维度，不相互比较、不改字段语义。

## Risks / Trade-offs

权限收回可能影响尚未拨打的排队任务，按当前准入规则拒绝；已开始通话保留原记录。以旧快照回归与正常流程测试保护兼容路径。真实账号和部署后环境验收单独记录，不以 mock 代替。

## Migration Plan

后端共用规则需随 SDK 与 Agent SSE 服务一起更新；Flutter 单独交付。无 SQL 数据迁移。回滚代码即可恢复旧规则。
