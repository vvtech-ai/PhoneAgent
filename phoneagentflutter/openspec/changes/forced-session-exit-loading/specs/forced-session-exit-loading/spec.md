## ADDED Requirements
### Requirement: 强制失效到登录的连续不透明过渡
系统 MUST 在异地注销等账号失效清理期间优先保留当前页面内存静态画面并使用唯一共用加载控件，采集不可用时用不透明背景兜底，保持到登录首帧就绪；MUST 保留真实卸载/清理和权限屏障，不以保留旧业务页面替代。失败 MUST 停止加载并保留原重试，账号变化和旧回调不得恢复过渡。普通退出及主动注销原流程不变。
#### Scenario: 双平台慢退出
- **WHEN** Android/iOS收到注销失效且存储或草稿清理未完成
- **THEN** 每帧有不透明覆盖和一个加载，旧页实际卸载，登录就绪后移除，原失效提示保持。
#### Scenario: 清理失败与重试
- **WHEN** 清理失败后用户重试
- **THEN** 加载停止后原重试可达，重试只清理且重新加载；不重复注销或放开业务。
#### Scenario: 账号替换
- **WHEN** 新账号登录或旧帧回调迟到
- **THEN** 旧覆盖撤销，不影响新账号或复活旧页面。

### Requirement: 静态画面生命周期有界
系统 MUST 在旧页面重建前发起采集，最多一张约200万像素的内存画面；不保存/上传，不等待采集才阻断权限或执行退出。采集250ms超时、未绘制、平台视图/Texture等不可用时 MUST 保留安全占位。登录就绪、清理失败、账号替换或宿主销毁 MUST 释放画面；迟到图像 MUST dispose，不恢复旧账号画面。主动注销原验证码页过渡 MUST 不变。
#### Scenario: 当前页面画面保留
- **WHEN** 普通Flutter页面收到强制账号失效且采集成功
- **THEN** 旧页真实卸载后静态像素仍属于退出前页面，加载唯一；登录首帧就绪后释放。
#### Scenario: 采集失败或迟到
- **WHEN** 图像未能及时取得、账号已经变化或宿主销毁
- **THEN** 清理照常完成，不露黑底，不显示旧账号迟到画面且图像释放。
