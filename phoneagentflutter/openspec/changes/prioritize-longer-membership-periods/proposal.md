# 同等级VIP长周期卡优先生效

## Why
用户于2026-10-27明确修改规则并确认执行：先比较等级，同等级年卡>季卡>月卡；存量有效卡也适用，已消耗时长不追溯。此前restrict-new-membership-purchases中保持同级排队的约束由本次明确决策覆盖；新购买限制继续保留。

## What Changes
- 同级候选先按周期降序，再沿用已使用暂停卡、支付时间和订单ID的原顺序；同周期不抢占正在使用的卡。
- 同级更长卡入账即生效，短卡精确暂停；到期/退款后按统一优先级选择。
- 报价及既有确认说明反映实际立即生效与保留时长。无新增UI、支付渠道或数据库字段。

## Impact
Java membership-core负责权益；SDK报价消费统一预览；Flutter既有确认说明与测试适配。不同等级、支付验签/幂等/历史初始履约快照及积分余额规则保留。
