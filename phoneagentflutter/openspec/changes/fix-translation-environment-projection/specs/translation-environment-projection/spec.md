## ADDED Requirements
### Requirement: 国内状态必须基于实际事件更新
客户端 MUST 将实际系统网络、双模型握手、SIP注册结果接入现有environment指示器，不仅依据页面已接通置绿。
#### Scenario: 正常翻译通话
- **WHEN** 双模型握手完成且SIP注册/接通成功
- **THEN** 模型和SIP分别显示可用，网络显示实际可用证据，不能全部保持pending
#### Scenario: 明确离线
- **WHEN** 系统明确报告无网络
- **THEN** 网络显示不可用，后续已有握手证据不覆盖该离线状态
#### Scenario: 模型失败
- **WHEN** 模型握手或运行失败
- **THEN** 模型显示不可用，不无依据将其他项全部标红
### Requirement: 环境监测必须与通话生命周期隔离
客户端 MUST 在终止或注销后取消网络监测、拒绝旧结果，并保留版本和最新事件优先。
#### Scenario: 读取中网络事件更新
- **WHEN** 新事件先于旧异步网络读取结果到达
- **THEN** 旧读取不得覆盖新事件
#### Scenario: 通话结束
- **WHEN** 结束后旧网络回调到达
- **THEN** 不更新已结束通话或下一通话
