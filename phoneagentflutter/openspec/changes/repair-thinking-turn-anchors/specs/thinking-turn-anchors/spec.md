## ADDED Requirements

### Requirement: 思考位置不因所属轮次缺少正文而漂移
实时思考 MUST 保留所属 command 与不同轮次身份；账本补查或结果完成后，思考 MUST 仍位于本轮内容内。同轮没有 assistant 正文时 MUST 使用本轮已知输入或下一已知轮次作为锚点，不追加到其他轮次结果或最终说明之后。

#### Scenario: 两轮思考后结果触发完整账本补查
- **WHEN** 早两轮分别含思考且账本只保留其输入，后续轮结果和账本交错到达
- **THEN** 两张思考各留在对应输入后、后续轮之前，结束内容保留且无占位重复，重复事件不移动或复制消息

### Requirement: 局部定位保持原有事实与副作用边界
修复 MUST 保留有同轮 assistant 的原定位、不同轮次思考内容与已提交事实顺序；MUST NOT 删除思考、全局重排、伪造历史或重复发送任务命令。

#### Scenario: 结果先到或账本先到
- **WHEN** finalResponse 与 committed 的到达顺序互换或重复
- **THEN** 最终业务顺序一致，同身份结果只有一份，既有后续消息与执行次数不受影响
