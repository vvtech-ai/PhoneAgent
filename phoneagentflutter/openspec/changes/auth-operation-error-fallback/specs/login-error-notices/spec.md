## MODIFIED Requirements
### Requirement: 登录异常按失败原因展示共用Toast
客户端 MUST 保留 Flutter 共用 Toast 样式及已分类业务提示，区分无网络、超时、连接失败；未分类错误 MUST 按请求入口显示固定兜底，不展示服务器 message 或异常原文。
#### Scenario: 无网络
- **WHEN** 请求发生传输错误且检测确认无非回环网络接口地址
- **THEN** 提示“当前无网络连接，请检查网络设置”，不自动重试认证
- **AND** 检测不支持、失败或超时不得将服务异常推断为无网络
#### Scenario: 请求超时
- **WHEN** 连接、发送或接收超时
- **THEN** 提示“网络连接超时，请检查网络设置”
#### Scenario: 连接失败
- **WHEN** 无法建立连接、DNS 解析失败或证书连接失败
- **THEN** 提示“暂时无法连接登录服务，请稍后重试”
#### Scenario: 获取验证码未分类失败 AUTH-FALLBACK-01
- **WHEN** 获取验证码出现未识别业务错误或其他未分类异常，无论 message 非空、为空或仅空白
- **THEN** 提示“获取验证失败，请稍后重试”，不展示服务器 message 或异常原文
- **AND** 释放 busy，不启动成功冷却，允许手动重试
#### Scenario: 短信登录未分类失败 AUTH-FALLBACK-02
- **WHEN** 短信登录出现未识别业务错误或其他未分类异常，无论 message 非空、为空或仅空白
- **THEN** 提示“登录失败，请稍后重试”，不展示服务器 message 或异常原文
- **AND** 释放 busy，保留原重试及请求代次隔离
#### Scenario: 已分类失败及成功 AUTH-PRESERVE-01
- **WHEN** 两个入口返回已分类业务错误、网络错误或成功结果
- **THEN** 保留原提示和成功流程，包括验证码过期、错误及频控；诊断不保存 message 或凭据
