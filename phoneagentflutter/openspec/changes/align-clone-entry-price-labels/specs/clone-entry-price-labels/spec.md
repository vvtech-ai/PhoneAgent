## ADDED Requirements
### Requirement: 克隆入口显示当前模型价格
主页面与音色子页声音克隆按钮 MUST 使用各自当前公开modelId对应的服务端pricePoints，不显示固定300，不使用其他模型或全局默认价格。
#### Scenario: 模型切换与无价
- **WHEN** 当前模型切换或价格加载中/失败/缺失/非正
- **THEN** 显示新模型有效价格或—，无障碍标签一致；旧结果不得覆盖当前模型
### Requirement: 入口价格复用现有数据并隔离账号
入口价格 MUST 复用既有目录/状态响应，按账号生命周期隔离；克隆完成和身份删除刷新，未知价格不得禁止进入模型选择。
#### Scenario: 价格未知或旧账号返回
- **WHEN** 用户点击未知价格入口或旧账号请求迟到
- **THEN** 点击仍打开原模型选择流程，旧账号价格不显示，不自动认证或扣费
