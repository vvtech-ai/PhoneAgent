## ADDED Requirements
### Requirement: 下载完成后的APK兼容性由系统决定
系统 MUST 在当前有效用户下载成功后将可用文件交Android安装器，MUST NOT 通过APK元信息、版本、包名、签名或后台摘要/大小比对阻止交接。系统安装器负责其安装兼容性校验；该要求覆盖旧的客户端保留验包决定。
#### Scenario: 后台元数据与APK不同
- **WHEN** 当前下载任务成功，文件存在且非空，无论APK与后台元数据是否一致或APK元信息是否可被应用解析
- **THEN** 应用可以交给系统安装，不显示版本/包名/签名/摘要不匹配提示
### Requirement: 应用必须保持下载归属和系统授权
系统 MUST 保持scope/job、路径归属、下载状态、文件可用性、系统安装来源权限及账号/取消代次守卫。恢复任务 MUST NOT 自动打开安装器；交接、系统返回或取消 MUST NOT 伪装成安装成功。
#### Scenario: 恢复已下载任务
- **WHEN** 进程重建恢复已有下载文件
- **THEN** 显示可安装状态，等待新的用户动作后交接系统
### Requirement: OTA按钮必须在边界内绘制
OTA启动提示与安装弹窗 MUST 使用相同的明确圆角裁剪、等宽等高及独立间距，渐变和交互绘制 MUST NOT 进入按钮间留白。强制更新 MUST 保持隐藏稍后和阻止返回。
#### Scenario: 窄屏与分数像素比
- **WHEN** 在窄屏、大字或分数像素比下显示OTA弹窗
- **THEN** 两按钮完整可点，边缘与留白清晰，其他业务Dialog默认展示不改变
