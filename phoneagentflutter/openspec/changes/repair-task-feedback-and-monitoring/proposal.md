# 任务权限反馈、监听与预置音色修复

## Why
定位拒绝后出现常驻设置提示，实时转写不随 SSE 更新滚动，后台新增预置音色被本地资源表禁用试听。诊断日志另显示监听反复重连，需要可验证地定位播放链路。

## What Changes
- 定位拒绝与永久拒绝使用一次性 Toast，保留真实权限回传及用户手动提供区域的能力。
- 通话转写按实际内容跟随最新消息；计时和音源刷新不强制滚动。
- 后台目录中非空音色通过现有动态试听接口播放，保留加载、切号、关闭和选择状态隔离。
- 检查监听真实 Netty 双向混音与 Flutter 播放，先构造证据再修复；补充安全诊断，不记录音频、号码或票据。
- Java 权益拒绝任务状态修正由同名服务端 change 管理。

## Impact
Flutter conversation/calls/call_models。旧 App 只读参考；不部署、不发起真实电话或付费试听，不变更数据库。
