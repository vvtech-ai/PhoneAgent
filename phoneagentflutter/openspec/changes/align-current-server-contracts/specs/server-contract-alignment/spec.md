## ADDED Requirements

### Requirement: 当前账户请求必须统一鉴权
客户端 MUST 对有效任务、账户设置、SIP、翻译历史、Agent及续接请求使用正确服务、Bearer及C1，并复用现有受控刷新，不改变暂缓的登录失效提示规则。
#### Scenario: 受保护路径与刷新
- **WHEN** 当前账号调用上述接口或收到401
- **THEN** 凭据与签名一致且仅按现有刷新策略重试，旧账号响应不得污染新账号

### Requirement: 附件和注册来源必须保持身份
客户端 MUST 用授权直传及complete提交OCR，不向对象存储发送账户凭据；邀请码来源 MUST 来自输入入口而不是格式猜测。
#### Scenario: 重试与来源变更
- **WHEN** 上传提交失败或用户改写邀请码
- **THEN** 同附件提交保持幂等，改写邀请码清除不适用的链接归因

### Requirement: 翻译配置必须来自有效服务器契约
客户端 MUST 对齐有效options/runtime目录，验证国家模型路由及节点、语言、价格、欢迎语；活动通话冻结配置，未启用新路由不得擅自切换。
#### Scenario: 节点与探测
- **WHEN** 准备新翻译电话
- **THEN** 探测和连接使用一致有效模型配置，网络可达不得冒充模型就绪

### Requirement: 代办通话必须按本次身份同步事实
客户端 MUST 分开物理结束和语义结果，恢复只读，字幕合并保留可信段身份、顺序和真实重复。
#### Scenario: 迟到结果与挂断
- **WHEN** 上一通事件迟到或当前挂断仅受理
- **THEN** 不结束下一通且不把受理当作物理结束，持续同步匹配身份的结果

### Requirement: 配置展示与验证必须真实
客户端 MUST 使用有效服务端样音和价格口径；下载、评分、停止、TTS仅修复确认问题，运行验收与自动测试分别记录。
#### Scenario: 设备尚未验证
- **WHEN** 自动验证通过但无真实媒体证据
- **THEN** 保留设备待验，不宣称真实通话验收通过

### Requirement: 实时翻译选择必须保留精确模型身份
客户端 MUST 按当前所在地国家绑定及目录协议能力解析本地精确模型ID，按ID区分同协议模型；账号设置解析失败不得阻止目录支持的正式选择。账号设置请求 MUST 携带国内或海外region，迟到响应不得跨账号/地区生效。
#### Scenario: 新ID及同协议多模型
- **WHEN** 目录存在多个相同providerCode的不同modelId
- **THEN** 可分别展示选择，runtime和计费保持本通话的精确模型ID
#### Scenario: 配置不可用
- **WHEN** 目录加载失败或当前位置未确认
- **THEN** 页面展示明确状态和适用重试入口，不持续使用含义模糊的模型待确认
