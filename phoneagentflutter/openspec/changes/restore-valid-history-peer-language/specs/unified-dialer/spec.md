## ADDED Requirements

### Requirement: 历史回填优先恢复有效历史对方语言
统一拨号页每次成功回填历史号码时 MUST 根据本条优先级重新确定对方语言，不得保留当前语言作为替代。历史语言有效指在当前目录语言列表中且受当前模型支持；国家默认语言指所选国家目录配置的 defaultLanguage。回填 MUST 保留当前翻译开关、另一模式国家、模型、提示及其他偏好，沿用 Flutter UI 与共用控件，不自动拨号。本条覆盖旧历史恢复中禁止回填历史对方语言及保留当前对方语言的决策。

#### Scenario: 历史对方语言有效
- **WHEN** 成功选择历史号码且历史对方语言在当前目录及模型支持范围内
- **THEN** 使用该历史对方语言，即使与国家默认语言不同或所选国家未改变
- **AND** 普通和翻译模式均恢复有效历史我方语言并保存配置

#### Scenario: 历史语言无效或为空
- **WHEN** 历史对方语言为空、不在当前目录或不受当前模型支持
- **THEN** 使用所选国家目录中有效且受模型支持的 defaultLanguage
- **AND** 不保留页面之前选择的对方语言

#### Scenario: 国家默认语言也不可用
- **WHEN** 历史对方语言及国家目录默认语言均不可用
- **THEN** 使用当前语言列表中第一个模型支持的语种
- **AND** 无可选项时留空，继续由现有拨号校验阻止无语种呼叫

#### Scenario: 同国家多条历史和不可回填号码
- **WHEN** 连续选择同国家不同历史记录
- **THEN** 每次独立按历史语言、国家默认、首项的顺序重新选择
- **AND** 号码无法回填时不修改语言、不发起通话
