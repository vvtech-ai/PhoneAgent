## Context
指定原生有效联系人页均无搜索/字母索引。列表逐号码展示，按姓名和目录查询号码去重；设备号码与AI备注目录独立。iOS正式空权限入口为“去设置授权”，Android有显式授权流程。Flutter已有详情备注CRUD、系统电话薄端口及技能任务上下文。

## Decisions
- 共同视觉沿已有Android/iOS参数：列表31标题（自然平台字体高度，不强制压缩CJK行盒）、42头像、16姓名、13号码、18横边距；详情88头像及固定底部两个动作。Shell已经为浮动导航预留动态contentInset，不叠加Android原生128底距。
- ContactsPage用ListView.builder构建可见行，状态头与行按索引映射，失败不重复展示“暂无联系人”。保持PageStorage滚动和完整姓名号码语义。
- 拒绝权限显示现有读取重试及“去设置授权”；有限授权显示范围说明及设置入口。复用现有系统应用设置端口，由装配注入，不在UI访问设备。不新增权限或自动打开设置。
- 技能控制器属于联系人，读取现有HomeRepository与InstalledAppSource，不把弹层生命周期塞入共享HomeController。有效技能须enabled/OpenSkill/nonempty ID且满足实际版本；版本读取失败明确重试，不猜1.0.0。无版本门禁卡可保留；公共仓库主动builtin回退是有效返回，不伪称网络失败可被联系人检测。
- 通讯录重读后所选联系人不再在授权集合中时清除详情选择及草稿；撤权不保留联系人，正常读取失败保留已有列表并显示错误，不伪称空结果。
- 每批不超过三个手写源码文件，日志文档独立。定向测试联系人及Shell直接入口/analyze/OpenSpec；改平台才正式构建。隔离运行包不替换普通App，不真实拨号或写备注。

## Validation
列表长数据/双平台大字/错误/权限；技能版本变化、空态/失败重试/晚到销毁；授权集合变化；既有备注/电话/任务连续测试。运行图明确区分原生组件与完整业务流程；模拟器有限重试失败继续自动验证，缺失记录待验。未用户验收不归档。

## 运行差异修正
同Android320×640/DPR1实际图，固定32点标题行使Flutter首头像比原生高约14点；使用自然系统字体行盒，字号/粗细/外边距仍共用。Android原生Compose有字体padding，iOS系统UIFont另有自然度量，不增加两套普通布局。iOS原生行副标题仅号码，统一沿Android号码+设备来源提示；原生iOS固定字号不当作支持Flutter两倍TextScaler的证据。Flutter语义热区48与iOS原生44保持既有可访问适配。
