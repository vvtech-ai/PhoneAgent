## ADDED Requirements

### Requirement: 北京时间精确范围
邀请统计、记录和导出 MUST 支持日期与时分秒范围，使用同一 from 包含/to 排除语义，快捷整日范围和清空 MUST 保持一致。

#### Scenario: 手选时段与导出
- **WHEN** 选择北京时间 2026-10-26 10:00:00 至 11:30:00
- **THEN** 查询和导出使用 02:00:00Z 至 03:30:00Z，不额外增加一天

#### Scenario: 无效范围
- **WHEN** 结束等于或早于开始
- **THEN** 页面阻止查询并说明结束须晚于开始

#### Scenario: 快捷与清空
- **WHEN** 选择今日或全部
- **THEN** 今日为北京零点至次日零点，全部不携带时间限制
