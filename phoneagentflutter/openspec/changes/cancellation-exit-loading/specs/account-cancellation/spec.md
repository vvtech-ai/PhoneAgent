## ADDED Requirements

### Requirement: 注销退出期间连续展示无文本加载
客户端 MUST 在最终确认注销后，在当前验证码页外观上显示一个共用loading，无提交/退出阶段文本。加载 MUST 连续覆盖受理请求、存储/订阅/草稿释放及登录页就绪，旧页面真实订阅仍按原顺序卸载。加载 MUST 阻止重复提交和返回，且不得以展示占位授予账号业务权限。

#### Scenario: DEL-02-04 受理后慢退出再进入登录页
- **WHEN** 受理成功，存储和旧账号页面/草稿释放延迟
- **THEN** 原验证码页外观与一个loading连续可见，无黑色/透明空白过渡；旧页面实际dispose后才清理；登录页就绪撤下loading，原中央成功提示自动消失

#### Scenario: DEL-05-01 提交未受理或未知
- **WHEN** 申请失败或查询后仍未知
- **THEN** 停止loading并保持既有反馈/原操作查询，不显示成功、不新建申请

#### Scenario: DEL-02-05 已受理但退出失败
- **WHEN** 本地退出清理失败并重试
- **THEN** 停止loading并给适用重试；重试只退出清理，使用同样loading，不重复申请、不恢复业务权限

#### Scenario: ENTRY-03/08 账号变化或旧操作迟到
- **WHEN** 加载期间切换账号或旧回调到达
- **THEN** 原加载层失效且旧回调不影响新页面/新loading；普通退出和原支付loading保持原职责
