## ADDED Requirements

### Requirement: 普通页面统一左对齐大标题
普通页面导航头 MUST 复用统一组件，标题左对齐28/w800、行高40/28、字距0，默认#111111；容器左右18/上下8，文字前占位28。常规页头高56，无额外父级留白时文字起点距左46。标题默认单行超长省略，已有允许换行的详情标题继续允许换行。
#### Scenario: 窄屏长标题与右侧操作
- **WHEN** 在320/390/430逻辑宽度和正常或两倍字体下展示长标题及宽操作
- **THEN** 标题保持左起点并按可用宽度省略，右操作不越界且可横向访问，完整标题与操作语义仍可读取

### Requirement: 字体缩放与导航适配
头部 MUST 随实际TextScaler增高，不能固定旧64或把大字号裁到56；AppBar首选高度与内部标题缩放 MUST 一致，顶部安全区只计算一次。返回目标48×48，返回字形不随文字缩放；无返回与禁用返回 MUST 区分。
#### Scenario: 两倍字体与系统顶部安全区
- **WHEN** AppBar在两倍字体、顶部安全区30的页面渲染
- **THEN** 头部高96且正文起点126，返回目标仍为48，原背景保持

### Requirement: 保留业务与专用展示边界
页面原右侧操作、返回回调、busy、PopScope、账号与路由守卫 MUST 保持原语义。品牌/通话/联系人资料等专用内容、弹窗/Sheet内部标题 MUST 保持独立，邀请海报原白色前景保留。业务逻辑、接口、状态机及按钮/卡片/背景/正文间距不在本批迁移范围。
#### Scenario: 初始化操作与注销验证
- **WHEN** 初始化busy或注销验证进行中
- **THEN** 原返回、跳过及业务门禁仍有效，注销验证只显示一处“输入6位验证码”页头
#### Scenario: AI任务停止处理
- **WHEN** 文字或语音模式进入停止处理中
- **THEN** 沿用原文字灰色/语音蓝色、原尺寸、三点反馈与禁用规则，不套用主按钮新配色

### Requirement: 项目规范持久化
AGENTS MUST 引用仓库内完整设计规范；新增UI按D01–D06和适用Cxx执行，旧页面仅按批准范围迁移。所有待核参数 MUST 保持待核，不得猜测后声称验收通过。
#### Scenario: 后续AI修改页面
- **WHEN** 开发者在另一台机器或新聊天中修改UI
- **THEN** 可从仓库规范获取设计参数、专用例外与验收边界，无需个人Downloads文件

### Requirement: 按钮不显示视觉 tooltip
主应用及独立来电身份展示入口 MUST 统一禁用按钮、返回和关闭控件的视觉 tooltip，覆盖普通路由及弹层；MUST 保留原 tooltip 和语义文案供读屏使用，不改点击、返回、关闭与业务回调。
#### Scenario: 持续按住按钮及关闭控件
- **WHEN** 用户长按或悬停按钮、返回或关闭控件
- **THEN** 不出现 tooltip 提示，读屏说明仍可用，普通点击继续执行原操作
