## ADDED Requirements
### Requirement: 完整子页面共用居中导航栏
范围内完整页面 MUST 使用统一21/w700标题（默认#0F172A，原蓝底邀请详情保留白色前景）、64最小高度、左右16内边距和同样式可选返回箭头；标题 MUST 相对整栏居中，单行超长末尾省略；两侧 MUST 按实际较大宽度对称预留。
#### Scenario: 两侧内容不等宽
- **WHEN** 返回、右侧操作或字体发生变化
- **THEN** 同次布局重新计算两侧留白，标题居中且不与操作重叠
### Requirement: 保留背景和业务边界
导航栏 MUST 保留各页面背景、右侧业务操作与禁用、返回拦截和账号隔离；弹出页面 MUST 保持原样。
#### Scenario: 会员订单与记忆保存
- **WHEN** 用户打开会员页面或编辑记忆
- **THEN** 导航背景及原操作保留，busy不被样式组件解除，发票和确认弹层不迁移
