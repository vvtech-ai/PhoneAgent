# 迁移设计

来源使用 `git show/diff 9a95803..origin/feature/test_v1.6.0`，不把仍停留在旧提交的原生工作树当最新源码。目标复用既有codex/dev隔离工作树，按语义迁移，不能跨Kotlin/Dart仓库直接合并。

1. 流解码和消息覆盖层处理memory_notice，独立助手提示按原命令留在当前轮；账本替换后仍保留，若可信最终文本已包含同一提示则去重。普通业务回复和未知事件保持原有处理。
2. ASK_USER按session/pending身份在成功交给播报器后记为已处理；暂停、文字模式、同步交付失败不消耗身份，恢复本身不重播。
3. 批次请求失败仅把尚未终结的逐路展示改为VERIFYING；继续保留batch/attempt与只读补查，不能合成最终失败、SIP关闭或释放批次门禁。物理停止/收尾阶段文案与可信业务结果区分。
4. 历史确认投影按toolCallId移除被拒绝卡；恢复定位最后仍待确认且后面没有新用户回复/批次结果的卡，保持账本顺序。终态后的旧单路确认文字只做展示去重，不删除新任务确认。
5. 导航只隐藏活动通话页面，不停止/关闭观察；任务列表取消置顶按已加载分页窗口处理并支持失败回滚。文档选择时冻结会话/代次/输入模式，解析后仅原上下文可提交，不覆盖用户手动切换。
6. 克隆输入在既有纯校验规则与TextField中约束最多18位ASCII数字/仅末位X，保留完整生日/校验码和现有认证/账号边界。

每批最多三个手写文件；控制器只接线。各子模块先RED后GREEN，集成后运行相关conversation/calls/tasks/attachments/voice_clone回归、analyze和OpenSpec；开发包与设备验证单独记录，不能当真实供应商验收。
