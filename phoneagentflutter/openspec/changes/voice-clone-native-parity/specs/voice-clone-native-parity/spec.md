## ADDED Requirements

### Requirement: 认证音频配置必须遵守SDK所有权
Flutter iOS MUST 仅在显式认证采集、权限已授权且SDK尚未启动时设置PlayAndRecord/Default/DefaultToSpeaker。MUST NOT 在注册、MetaInfo准备或SDK使用期间重设音频。配置失败 MUST 不启动SDK。

#### Scenario: 首次采集与权限取消
- **WHEN** 用户明确开始认证且相机/麦克风权限准备完成
- **THEN** 仅当前未取消会话配置一次再启动SDK；拒绝或旧权限回调不得启动SDK

#### Scenario: SDK取消和音频交接
- **WHEN** SDK仍未实际完成或容器未关闭
- **THEN** 取消回执不释放不可抢占租约，不恢复旧音频；真实完成后下一业务才可重新配置，试听使用Playback

### Requirement: 候选退出必须区分录音提醒与音色恢复
Flutter MUST 对未确认ready候选退出恢复系统音色，不依赖候选来源；仅有本次认证可保存录音且用户勾选保存时显示丢弃录音警告。成功退出准备 MUST 去重，失败允许显式重试。

#### Scenario: 本地录音候选或取消保存
- **WHEN** 用户退出未确认候选且没有勾选待保存的本次认证录音
- **THEN** 不显示丢弃录音警告，仍恢复该模型系统音色；不删除候选/身份/录音或其他模型资产

#### Scenario: 已确认或重复返回
- **WHEN** 候选已确认，或同次退出准备已成功
- **THEN** 不重复恢复音色/提交确认/扣费

### Requirement: 声音克隆必须复用正式业务闭环
Flutter MUST 共用有效原生模型选择、授权认证、候选生成/试听/确认、认证录音保存复用、音色管理和积分状态。MUST 保持服务端权威、账号/模型隔离、未知结果只读恢复及共用UI；平台差异限系统能力。

#### Scenario: 合成与真实验收
- **WHEN** 自动协议/页面测试、平台构建或隔离UI通过
- **THEN** 只记录对应证据，不声称真实认证/音频/收费完成；未授权真实项保持待验

### Requirement: 失败反馈必须区分生成状态与供应商细节
Flutter MUST 仅在failed候选展示有效业务失败原因；处理中不得暴露历史失败；包含HTTP或供应商结果未知的原因 MUST 转为友好服务不可用提示。

#### Scenario: 服务暂不可用
- **WHEN** failed候选返回HTTP细节或供应商结果未知
- **THEN** 显示“声音克隆服务暂时不可用，请稍后重试。”，不显示供应商原始细节

### Requirement: 身份页声音克隆必须保留来源页面
Flutter MUST 从当前身份页打开克隆模型选择，不得为启动克隆先关闭身份页。

#### Scenario: 从设置进入身份再选择声音克隆
- **WHEN** 用户在我的身份页点击声音克隆
- **THEN** 在身份页之上显示模型选择；取消选择或退出克隆回到身份页，显式返回身份页才回到设置

### Requirement: 目录解析与错误恢复必须遵循原生语义
Flutter MUST 将current和candidate为空或缺省视为无对应音色资产，非空跨模型响应仍拒绝；不得将空值伪装为ready。目录错误 MUST 分类提供安全提示，不展示原始响应或凭据。双端模型选择失败 MUST 保留身份背景，关闭重新进入触发新加载，不增加原生没有的重试按钮。models列表为空/缺省 MUST 按原生保留标题和说明，不伪造模型或添加额外空态入口。

#### Scenario: 无当前音色
- **WHEN** 合法模型目录中的current或candidate为空或缺省
- **THEN** 显示模型及未创建状态，创建仍需积分与认证准入

#### Scenario: 失败与恢复
- **WHEN** 网络、鉴权、配置或响应格式导致加载失败
- **THEN** 弹窗保留来源页并显示安全分类提示；关闭重新进入重新加载且不启动认证/扣费

### Requirement: 模型目录必须按摘要协议解析
Flutter MUST 按原生目录摘要读取current/candidate，不得要求列表候选满足完整操作DTO。Gson兼容的标量String及Boolean MUST 按原生转换，缺省Boolean为false；非空跨模型摘要仍拒绝。未知状态不得提升为ready，完整候选读取/认证/确认 MUST 按原生操作DTO兼容规则解析，计费就绪不得伪造。

#### Scenario: 非就绪摘要与可选字段
- **WHEN** 目录候选缺省计费/source/标识或返回未知状态
- **THEN** 目录可展示但候选不视为ready；选择已有候选只读恢复，不触发新生成或扣费

### Requirement: 关闭未进入流程的模型选择不得刷新身份
Flutter MUST 在只打开并关闭模型选择时保留现有身份数据和加载状态，不失效身份/音色/钱包provider、不发送相关刷新。原生无业务变化的关闭 MUST 不表现为数据加载。进入实际克隆流程后的既有业务刷新 MUST 保持。

#### Scenario: 关闭选择或取消重新认证
- **WHEN** 用户关闭模型选择，或取消重新认证后关闭，尚未进入克隆流程
- **THEN** 返回原身份内容，身份Controller保持同一实例，期间无额外busy/loading状态

### Requirement: 候选生成与录音授权必须独立处理
Flutter MUST 接收有效候选且不因可选录音授权缺失或无效丢弃该候选；无效、跨认证或过期授权 MUST 不用于下载保存。候选归属及计费就绪保护 MUST 保持。

#### Scenario: 候选有效但录音授权无效
- **WHEN** 认证生成返回有效候选及缺失或无效录音授权
- **THEN** 继续候选展示和轮询，不显示保存录音选项，不重提生成请求

### Requirement: 创建失败必须使用原生平台交互
Flutter MUST 在iOS创建失败时回到模型选择显示安全错误，在Android保留认证失败反馈；MUST NOT 显示额外的创建结果未知独立同步页，MUST NOT 自动重新生成。内部不确定标记 MUST 不作为原请求计费成功证据。

#### Scenario: 认证后创建失败
- **WHEN** 创建候选请求失败或候选无法接收
- **THEN** 按平台呈现对应原生错误界面，显式重新选择或重新开始才允许进入新流程

### Requirement: 候选展示与录音提交必须保持原生流程
Flutter MUST 对处理中及失败候选使用统一结果卡片，未就绪禁止试听及设为默认，处理中禁止退出。确认录音下载 MUST 与确认请求并行准备，只有确认成功才允许替换存储；可选保存 MUST 不阻塞成功返回或产生额外正式重试页。

#### Scenario: 确认成功与录音保存失败
- **WHEN** 候选已确认且认证录音仍在下载或保存失败
- **THEN** 返回来源页，账号绑定保存独立完成并记录安全诊断，旧录音不被未校验或未确认材料替换

### Requirement: 替换认证必须保留旧候选与身份草稿
Flutter MUST 在新候选成功接收前保留旧候选；取消或失败可回到旧候选，新候选接收后才释放旧状态。旧异步回调 MUST 不覆盖新流程。Android创建失败 MUST 保留本次身份输入并按原生遮蔽，显式编辑可恢复输入；草稿不得写入诊断或持久化。

#### Scenario: 取消重新录制
- **WHEN** 用户在替换认证期间返回或新生成失败
- **THEN** 原候选及录音保存选项仍可恢复，不重复生成或扣费

### Requirement: 候选操作DTO必须遵循原生兼容规则
Flutter MUST 将candidateId作为不透明字符串接收，不套用请求路径或幂等键正则；MUST 支持原生Gson标量字符串、缺省文本、整数数字字符串及Long默认值。未知状态 MUST 保留非就绪状态，不因未知值拒绝整个候选或伪造计费成功。明确跨模型/跨候选结果 MUST 不被绑定到当前流程。解析诊断 MUST 只记录白名单字段、JSON类型及失败类别，不记录值。

#### Scenario: 带冒号候选与兼容字段
- **WHEN** 生成、查询或确认返回带冒号candidateId及原生可解析的标量/空缺字段
- **THEN** Flutter正常接收并按状态控制轮询、试听、确认，候选ID不进入请求路径或header

#### Scenario: 非法结构诊断
- **WHEN** 字符串字段返回对象/数组或积分无法按原生Long解析
- **THEN** 提供安全错误且记录字段类型，不输出身份/账号/录音授权或原始响应
