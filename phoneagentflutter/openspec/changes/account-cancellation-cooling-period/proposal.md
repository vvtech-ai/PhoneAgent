# 账号注销与15天冷静期

2026-10-27最新用户决策：注销协议固定为https://www.chaken.ai/agreements/Phone_Agent_account_cancellation.html。客户端固定打开该链接；SDK保留响应字段并固定返回相同地址，不再依赖agreement-url配置，版本继续为1.0。此决策覆盖此前动态协议地址方案，不授权发布、线上配置、重启或数据库操作。

## Why
当前 AccountRoute 的注销操作只调用 SessionController.signOut，确认框要求输入“确认注销”；没有短信本人验证、服务端申请和冷静期登录选择，不能满足2026-10-26用户需求。

## What Changes
- 沿用设置 → 关于PhoneAgent → 账号管理 → 注销账号；先弹注销确认，用户点击注销后才请求绑定手机6位验证码；验证成功后展示最终确认，明确注销才提交申请。
- 入口恢复历史完整UI（含输入“确认注销”）；验证后的最终确认框仅“取消 / 注销”，协议为内联链接，无复选框、确认文字输入或额外须知页。
- 服务端受理后退出，原登录页中央显示约2秒“已提交注销申请”。
- 15天内再次验证登录，仅明确选择继续登录并由服务端撤销成功才进入首页；保持注销、关闭和返回均不撤销。
- 服务端独立到期注销、多设备准入、数据清理和权益终止；退款依既有协议。

## Impact
仓库 PhoneAgent；presentation 负责页面和交互，domain 负责注销流程及操作身份，data 负责接口 DTO；session owner 继续由 SessionController 持有。账号生命周期、时钟、短信与权益事实由服务端负责。影响 AccountRoute、账号确认框、AuthController/AuthGateway 登录接线、协议端口；保留普通退出、任务确认、TTS、记忆和账号隔离规则。

依据：https://agent.vvtech.tech/cancel 与用户提供的《PhoneAgent账号注销协议》。入口按用户指定覆盖；2026-10-28用户确认最终正文保留“再次登录自动终止”，其语义为明确继续登录并成功完成撤销/登录。2026-10-26用户确认尚无接口，后续用户已批准实施，当前已完成核心源码与定向自动验证，尚未部署或签收真实环境。
