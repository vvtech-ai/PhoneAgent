## ADDED Requirements

### Requirement: 关于页末尾提供账号管理
客户端 MUST 从设置首页移除账号入口，在关于PhoneAgent列表末尾增加“账号管理”，排在版本更新之后，并打开标题为“账号管理”的原账号页面。

#### Scenario: 入口顺序
- **WHEN** Android 或 iOS 用户打开关于页
- **THEN** 账号管理是最后一项，用户协议、隐私协议、个人信息明示清单、日志及版本更新仍可用

#### Scenario: 返回和账号操作
- **WHEN** 用户从关于页进入账号管理后通过页面或系统返回
- **THEN** 回到关于页；原账号确认、取消、登录态清理与重复操作保护保持有效
