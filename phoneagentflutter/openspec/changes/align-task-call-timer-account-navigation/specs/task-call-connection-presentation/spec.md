## ADDED Requirements

### Requirement: 接通事实统一驱动任务外呼展示
客户端 MUST 对当前合法通话的查询或推送 CONNECTED 建立单次接通事实，共用于文案、计时与监听接线；不得将字幕或准备完成当成接通。

#### Scenario: 推送先于查询
- **WHEN** 当前 attempt 的 CONNECTED 推送先于查询快照到达
- **THEN** 页面立即显示已接通并从 00:00 开始，不等待后续轮询

#### Scenario: 重复与旧快照
- **WHEN** 同通话重复 CONNECTED 或较早 DIALING 快照到达
- **THEN** 保持已接通且不重复归零；其他通话的迟到事件不影响当前通话

### Requirement: 等待与通话时间分离
客户端 MUST 在未接通时仅显示“接通中”，首次接通显示“已接通 00:00”并递增；终态停止，下一通重置，页面重建不重置同一通话。

#### Scenario: 等待后接通
- **WHEN** 通话等待任意时长后首次可信接通
- **THEN** 等待时间不显示、不累计到通话秒数，首次显示 00:00

#### Scenario: 连续通话
- **WHEN** 前一通结束后开始新的通话
- **THEN** 新通话未接通前无秒数，接通从 00:00 开始；原通话事件不改变新计时
