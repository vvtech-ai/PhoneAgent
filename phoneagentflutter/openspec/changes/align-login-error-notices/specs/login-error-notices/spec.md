## ADDED Requirements
### Requirement: 登录异常按失败原因展示共用Toast
客户端 MUST 保留Flutter共用Toast样式并区分超时、连接失败和未分类异常，保留已分类业务提示及诊断隐私。
#### Scenario: 无网络
- **WHEN** 请求发生传输错误且检测确认无非回环网络接口地址
- **THEN** 提示“当前无网络连接，请检查网络设置”，不自动重试认证
- **AND** 检测不支持、失败或超时不得将服务异常推断为无网络
#### Scenario: 请求超时
- **WHEN** 连接、发送或接收超时
- **THEN** 提示“网络连接超时，请检查网络设置”
#### Scenario: 连接失败
- **WHEN** 无法建立连接、DNS解析失败或证书连接失败
- **THEN** 提示“暂时无法连接登录服务，请稍后重试”
#### Scenario: 未分类异常
- **WHEN** 登录出现未分类异常
- **THEN** 优先展示message，无有效message时提示“登录失败”，不拼接请求参数或堆栈
- **AND** 诊断不得保存message或凭据
### Requirement: 验证码统一为6位数字
客户端 MUST 将验证码输入限制为6位ASCII数字，并在提交时独立验证；本轮规则覆盖历史4–8位规则。
#### Scenario: 非法验证码
- **WHEN** 提交非6位数字验证码且无有效邀请challenge
- **THEN** 不调用登录端口并提示“请输入正确的验证码”
#### Scenario: 粘贴验证码
- **WHEN** 输入包含非数字或超过6位
- **THEN** 过滤非ASCII数字并保留前6位
#### Scenario: 邀请及保存重试
- **WHEN** 有效邀请challenge提交或登录后本地保存失败重试
- **THEN** 保持原有免重传验证码和仅重试本地保存行为
