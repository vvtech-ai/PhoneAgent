# 会员展示配置

用户已确认实施：模型准入提示按实际已发布等级简化；每条权益独立常规/放大字号，缺省常规；高峰极速优先线路、新模型抢先体验由各等级勾选显示，缺省隐藏，不再按高级写死；会员协议完整单行且可打开；删除即时到账小字和订单退款提示。

## 契约与职责
CommerceBenefits 增加可空 displayOptions，按稳定权益键 monthlyPoints、batchCalls、models、voiceClone、singleCall、priorityLine、newModelPreview、packDiscount 保存 {fontSize: REGULAR|LARGE, visible?: boolean}。字号缺省 REGULAR；仅 priorityLine/newModelPreview 接受 visible，缺省 false。保留旧构造和旧 JSON 兼容，发布配置与现有购买数值组合时取最新展示配置。
Web 独立展示编辑器与纯规则接入现有四档权益表单，互斥字号单选，两可选权益单独显示勾选。Flutter 独立规则读取展示选项，每行使用稳定键；模型提示仅实际完整高等级后缀才写“及以上”，不连续等级逐个列出，保留实际当前权益与环境不可用提示。
协议单行缩放适配可用宽度，保留同意框和独立协议点击/语义。排队生效时到账说明保留；订单提示移除后不留占位。

## 验证
Java 旧快照反序列化、新字段往返、发布校验、有效权益组合；Web 实际组件渲染/编辑草稿/取消与构建；Flutter 混合字号、四档开关、旧配置默认、等级提示、窄屏与大字体协议和相关购买/订单回归。每批不超过三个手写源码文件；不部署、不真实支付或外呼；真机视觉另行验收。
