# 对齐当前原生开发者功能

## Why
Flutter 正式开发者页仍使用旧版强制 WebRTC、固定节点和模型控件，与 aiassistant_app 当前正式入口不一致。

## What Changes
- 对齐列表数据、外呼调试、实时翻译、V8.8 模拟能力的顺序、文案和卡片。
- 模拟主叫国家从服务器目录选择，独立保存于翻译偏好，覆盖有效主叫国家；关闭恢复真实位置并刷新，不写入真实位置缓存。
- 模拟国家联动目录模型、节点、国内/海外账户设置和拨号权限门控。
- 增加账号翻译模型调试页，刷新和设置账号偏好不改变拨号页模型选择。
- 正式页移除旧测试控件和迁移 MOCK 入口；独立预览页源码保留。
- 保留列表真实刷新/清空、固定外呼号码、网络提示、重置提示并打开翻译拨号行为。

## Impact
仅设置和翻译地区直接调用链；无平台、依赖、系统权限修改，无真实外呼测试。
