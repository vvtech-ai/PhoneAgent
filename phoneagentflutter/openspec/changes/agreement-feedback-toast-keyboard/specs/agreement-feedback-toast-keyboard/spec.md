## ADDED Requirements
### Requirement: 协议拒绝必须复现原生局部反馈
Flutter MUST 在未勾选时阻止验证码/登录请求，将普通协议文字及未选框边变为E5484D、链接保持蓝色，整行240ms执行0/-3/3/0水平平移并显示共用Toast，不新增错误说明行。
#### Scenario: 重复点击与勾选
- **WHEN** 用户再次拒绝提交或切换勾选
- **THEN** 重新播放抖动或清除错误样式，动画不改变布局尺寸
#### Scenario: 减少动态效果
- **WHEN** 系统要求减少动态效果
- **THEN** 保留颜色和Toast反馈，不播放抖动
### Requirement: 通用Toast必须统一避让键盘
showNativeNotice MUST 对全部调用方以max(设备底部安全区+96,键盘底部遮挡+16)作为底部间距；显示期间随指标变化重新定位，不重置提示寿命或阻挡操作。
#### Scenario: 键盘显示变化
- **WHEN** Toast存在时键盘弹出、改变高度或收起
- **THEN** 提示同步位于可见区域，安全区不重复计算；替换/超时/离页清理保持有效

### Requirement: 共用Toast必须采用iOS原生样式和动画
showNativeNotice MUST 双端统一使用白色98%背景、1像素灰度0.82边框、圆角10、黑色12%阴影半径8/偏移(0,3)、灰度0.10的15号Semibold居中文字、上下10左右18内边距及左右至少32外边距，支持多行。MUST 以180ms淡入，停留指定时间后180ms淡出；默认停留1.8秒，登录协议提示2秒。
#### Scenario: 替换与销毁
- **WHEN** 连续提示或Overlay销毁
- **THEN** 旧动画与计时取消，没有残留或清理异常，Toast不拦截点击
