# 任务授权与通话交互集成验证

## 需求与实现范围

用户确认旧原生APP只作为对照，修Flutter `codex/dev`；本轮版本为 `1.0.52 (45)`。基点 `8756f449`，原生及Java/Web未修改。详细分组证据见本目录的权限、消息、入口与通话四份验证记录。

1. 首页任务卡片、任务列表继续任务、联系人正式技能入口共用录音授权检查；拒绝留原页面。用户明确追加的联系人/任务列表没有遗漏。翻译技能卡片复用检查，只读详情与系统拨号交接保持原用途。
2. 定位新意图可再次检查并申请，永久拒绝提供主动设置；实际返回后回读，不把打开设置当授权。临时inactive等待，真正后台/离页/切号/旧输入代次不续接。
3. 预检和权限工具共用纯Dart生命周期owner，恢复当前有效播报；旧原生Future不阻塞或污染新意图，也不能因第二次后台误取消新普通轮次。
4. 权限请求卡保留真实结果，普通文字不吞掉卡片；新任务开场在首句后保留并与历史去重，思考使用已有真实事件和工作反馈。
5. 通话图标按旧XML路径；活动通话系统/手势返回无副作用，音源子弹层可单独关闭，正常结束/明确挂断沿既有流程。
