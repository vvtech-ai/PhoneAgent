# UI 优化、连续购买排查与订餐搜索号码规则

> 执行授权更新（2026-10-21）：用户已要求拉取指定分支后实施全部 8 项，第 7 项先定位再修复，完成相关验证并打测试环境签名包；版本明确为 1.0.52（45），界面统一覆盖 iOS/Android。下文“本次仅提案”为创建阶段记录，不限制本轮已授权实现和打包；不自动授权部署、安装或真实收费。

## Why

首页邀请入口、任务操作反馈及会员页面存在与用户确认稿不一致的图标、间距、颜色和命名；支付频控等具体原因在展示层被通用失败文案覆盖。订餐推荐混入无电话门店，使用户选店后才知道无法拨打。

用户于 2026-10-21 确认将以下 8 项纳入本变更，并明确免费用户首次购买不加续购或升级标识。第 7 项只确认了失败现象和诊断缺口，必须独立定位、修复与验证，不能将提示优化当作故障修复。

同日用户追加 R09：设置中的模型音色页面若固定拼接“当前语音大模型 {模型名} 支持以下音色”，则删除；后台可配置内容不处理。源码已确认整句为客户端模板，只有模型名来自目录。

## Capabilities

- `app-ui-polish`: R01、R04、R05 及追加 R09 的资源与界面行为。

无。相关会员和任务合同仍在既有 active changes；本变更新增增量规格，保留其价格、排队、协议、任务身份与确认规则。`agent-location` 的授权、采样与缓存合同不变。
