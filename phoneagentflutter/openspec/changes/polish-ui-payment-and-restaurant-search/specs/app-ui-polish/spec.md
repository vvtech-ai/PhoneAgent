## ADDED Requirements

### Requirement: 移除客户端固定系统音色提示
语音模型与音色的共享页面 MUST 移除固定模板“当前语音大模型 {模型名} 支持以下音色”；此模板已确认由客户端写死，不是后台可配置文案。模型标题、系统音色标题、服务端模型介绍 / 音色说明、选择 / 试听 / 克隆及关闭行为 MUST 保留，Android/iOS 一致。

#### Scenario: 打开模型音色弹层
- **WHEN** 用户在设置中打开任一模型的音色页面
- **THEN** 不再展示该固定提示行，仍可看到真实模型名及原音色数据并正常选择、试听和关闭

### Requirement: 首页邀请入口使用提供的 SVG 图标
客户端 MUST 在原邀请好友入口使用用户提供的礼包 SVG 矢量资源，保留原入口可见性、语义、点击区域和导航行为；资源 MUST 纳入工程，不依赖用户本机下载路径。

#### Scenario: 邀请入口可用
- **WHEN** 首页邀请入口按现有活动规则显示
- **THEN** 展示礼包 SVG，点击原按钮区域仍打开原邀请流程，不受图标透明区域影响

### Requirement: 积分流水为独立整行入口
会员积分卡 MUST 按用户图 3 将“+ 购买积分”保留在右上，余额与说明下增加分隔线，下方独立整行展示“查看积分流水”和右箭头；两入口 MUST 有独立且互不重叠的点击区域。

#### Scenario: 点击购买或流水
- **WHEN** 用户分别点击购买积分按钮、流水行左侧文字、中部空白和右箭头区域
- **THEN** 购买按钮仅进入购买积分，其余流水行区域仅进入积分流水，均沿原路由和账号上下文

#### Scenario: 窄屏与大字体
- **WHEN** 页面宽度为 320/375/430 逻辑像素且字体比例为 1 或 2
- **THEN** 积分、原说明和两个入口可读可操作，点击区域不重叠、无布局溢出，不为适配删除实际到账信息

### Requirement: 当前权益标签蓝色高亮
客户端 MUST 仅对当前真实生效等级对应的“当前权益”标签使用蓝色文字；浏览其他会员档位不得改变真实当前权益标识。

#### Scenario: 浏览其他等级
- **WHEN** 当前生效初级会员，用户切换到中级或高级商品再返回初级
- **THEN** 其他档位不被标为当前权益，初级标签保留蓝色高亮，权益判定不因营销选择变化
