## ADDED Requirements

### Requirement: 账号请求与访问令牌隔离
系统 MUST 仅对固定服务端的相对 API 地址发起账号请求，附加账号标识；MUST 仅向 v65 指定的受保护路径附加 Bearer。系统 MUST NOT 将令牌输出日志或发往资源域名。

#### Scenario: 普通模型请求
- **WHEN** 请求模型设置接口
- **THEN** 使用账号标识而不附加不必要的 Bearer

### Requirement: 单次刷新和账号切换安全
系统 MUST 在受保护请求 401 后共享单次刷新，并最多重试原请求一次；刷新 401 MUST 使匹配的当前会话失效，其他失败 MUST 保留会话。旧账号请求 MUST NOT 更新新账号会话或用新账号身份重放。

#### Scenario: 并发未授权
- **WHEN** 同一会话多个受保护请求同时返回 401
- **THEN** 共享刷新结果并以新令牌各重试一次

#### Scenario: 刷新期间退出登录
- **WHEN** 刷新尚未完成而用户已退出或切换账号
- **THEN** 丢弃刷新结果且不重放原请求
