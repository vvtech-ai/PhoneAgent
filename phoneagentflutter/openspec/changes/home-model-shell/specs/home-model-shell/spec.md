## ADDED Requirements

### Requirement: 正式创建与隔离演练必须共用页面编排
系统 MUST 从身份与音色入口装配模型目录、300积分准入、已认证姓名预填锁定、SDK核验、候选生成、确认与加密录音保存。页面 MUST 仅通过共享协调器交互，生产端口和全合成端口 MUST 显式隔离；账号切换 MUST 移除旧流程并释放自有播放器，禁止使用新账号继续旧操作。

#### Scenario: 正式模型选择与 Web 采集限制
- **WHEN** 用户从正式入口选择可用克隆模型
- **THEN** 按现有候选/已保存录音/完整认证分流，未授权或积分不足不得初始化SDK或发生成请求
- **AND** Web真人采集明确不可用，MOCK成功不能代替真实认证；关闭模型弹层返回原入口

#### Scenario: 试听与独立保存恢复
- **WHEN** 用户试听、确认后保存失败或离开页面
- **THEN** 试听使用已鉴权且有界的WAV字节，离页/后台停止并清理自有临时文件；确认后的失败只能重试保存
- **AND** 三类请求未知只能同步各自服务端状态，不能把组件演练的重试创建策略用于生产

### Requirement: 克隆确认与录音保存必须独立核对
系统 MUST 核对确认响应的模型、候选和资产；结果未知 MUST 只读核对同模型当前资产，不重复确认。当前资产核对 MUST 要求 READY、active、同资产且无新候选；无法证明时不得视作通过。录音保存失败 MUST 保留已确认事实且重试仅保存，不重新认证、生成或确认。

#### Scenario: 确认响应丢失或保存失败
- **WHEN** 确认请求结果未知
- **THEN** 只读目录核对已捕获的资产身份，不能把任意当前音色或候选不存在当作本次成功
- **AND** 确认后保存录音失败独立提示；关闭或账号变化后不得续发保存

### Requirement: 身份采集SDK必须延迟初始化且会话隔离
系统 MUST 仅在认证授权后初始化原生SDK，平台端口仅负责prepare/capture/abort，不包含认证判定或生成计费。每次采集 MUST 绑定独立session且单飞，回调最多交付一次；关闭只影响自身会话并抑制晚到。Web或不支持平台 MUST 明确不可用，不以模拟结果降级生产。

#### Scenario: 页面关闭与旧采集未结束
- **WHEN** 采集所属页面关闭或会话失效
- **THEN** 请求平台取消并忽略旧回调，不能继续后台核验；SDK不支持可靠中止时保持重入门禁直到实际回调结束
- **AND** 构造端口或注册插件不得触发SDK初始化或收集设备metaInfo

### Requirement: 认证结果必须由服务端核验且不隐式重启
系统 MUST 将SDK返回1000或2006视为需要查询服务端，只有匹配attempt的PASS才可进入候选生成。查询 MUST 有界；未知状态、失败、取消或过期不得视为通过。同步 MUST 只读同attempt，不重复初始化或SDK采集。身份、metaInfo、certifyId和SDK原文 MUST NOT 进入普通日志或页面状态。

#### Scenario: SDK完成而后台处理中
- **WHEN** SDK返回1000或2006且后台为INIT、INITIATED或PROCESSING
- **THEN** 最多60次间隔一秒查询，超时保留待同步，不声称认证成功；脱敏客户端观察失败不覆盖后台结果
- **AND** 页面关闭或账号改变后不得继续采集、查询或上报旧结果

#### Scenario: SDK取消或未知初始化结果
- **WHEN** SDK取消、其他失败或初始化响应未知
- **THEN** 不自动查询通过、不重复初始化、不生成候选；后续新认证必须是新的明确用户操作

### Requirement: 认证录音必须加密且绑定账号
系统 MUST 在原生私有排除备份存储中加密保存认证录音及凭据，按环境/服务端/账号隔离；MUST 校验版本、摘要、绑定及10MiB上限。Web MUST NOT 将真实认证录音降级存入普通浏览器存储。

#### Scenario: 保存与复用
- **WHEN** 用户选择保存且同源grant下载成功、摘要与当前会话校验通过
- **THEN** 原子替换对应账号slot；后续读取等待在途保存结束再校验，不返回半写数据
- **AND** 下载/校验/写入失败保留旧有效文件，账号变化或关闭后的下载不得继续写入

#### Scenario: 无效与暂时不可用
- **WHEN** 解密或内容校验确认损坏或绑定不符
- **THEN** 清除本slot并报告无效，不能复用；临时I/O/钥匙串不可用不得误报不存在或删除旧录音

### Requirement: 候选创建必须保持操作身份并有界同步
系统 MUST 按v65区分认证attempt生成与认证录音生成，使用同一操作的稳定幂等键；401刷新 MUST 保留该键。响应 MUST 匹配目标模型及已知候选身份，READY与CHARGED同时满足才能视为可确认。认证材料 MUST NOT 写入日志或普通UI状态。

#### Scenario: 生成结果未知
- **WHEN** 创建请求失败或返回未能完整确认
- **THEN** 只允许读取服务端候选同步，不自动重发创建或换新幂等键
- **AND** 已知候选被其他候选替换时报告冲突，不悄悄采用另一操作结果

#### Scenario: 候选仍在处理
- **WHEN** 服务端返回生成中或处理中
- **THEN** 有界间隔读取，达到上限保留实际候选并提供稍后同步，不伪造失败或就绪
- **AND** 页面销毁后不发后续请求或更新状态

### Requirement: 创建模型选择与认证录音复用必须保留来源语义
系统 MUST 使用共享模型底部弹层并根据模型可用性、已确认音色和候选状态选择后续流程；已有就绪克隆重新创建 MUST 先确认且走完整认证。新生成 MUST 通过300积分准入；认证录音不可用 MUST 回完整认证，不伪造复用成功。

#### Scenario: 复用录音生成候选
- **WHEN** 没有就绪克隆、积分允许且存在有效认证录音
- **THEN** 跳过身份表单与采集进入生成候选，隐藏保存本次认证录音选项，按来源处理再次生成
- **AND** 候选已有处理中/失败状态不隐式重新创建；隔离演练不操作真实身份、文件、模型或积分

### Requirement: 分模型克隆删除必须确认且隔离
系统 MUST 仅在可删除current且无已就绪候选时展示删除操作，确认时 MUST 校验当前模型仍匹配目标。删除 MUST 只调用目标模型clone接口，不删除身份/认证录音/其他模型。结果未知或刷新失败 MUST 先同步而不自动重放删除。

#### Scenario: 删除并返回音色设置
- **WHEN** 用户确认删除当前模型的已确认克隆音色
- **THEN** 单次提交目标模型删除并读取实际音色/克隆状态，按服务端结果展示系统音色，其他模型保持不变
- **AND** 取消/候选就绪/忙碌/目标变化时不发送删除；MOCK演练不触碰真实账号

### Requirement: 克隆创建必须区分采集与服务端核验
系统 MUST 用共享Flutter页面承载授权说明、身份表单、采集/核验/生成与候选结果，SDK采集结果 MUST NOT 直接视为身份认证或克隆成功。人工依赖尚未接入时 MUST 以隔离MOCK显式标识，不修改真实身份、音色或积分。

#### Scenario: 认证与候选结果演练
- **WHEN** 用户从音色页进入明确的克隆演练并完成授权说明及合成身份表单
- **THEN** 按采集、服务端核验、生成顺序进入候选；支持失败重试、试听状态、保存选项与确认返回
- **AND** 未确认候选返回及重新录制有对应提示，离页晚到不得更新原页面或发起后续调用


### Requirement: 动态首页及入口门禁
本条已由用户批准的 `task-orchestration-v1` 替代旧网络优先策略。系统 MUST 支持已发布配置、ETag 和 304，优先使用完整有效缓存，无缓存时使用经确认的完整随包快照；卡片、Skill 与开场 MUST 来自一致版本，明确无开场的入口除外。后台更新仅供下次进入，不改写已打开会话。disabled、版本门禁及首页不包含旧内嵌对话流程的边界保持不变；缓存不代表当前权益或实时最新配置。

#### Scenario: 缓存验证命中
- **WHEN** 存在已校验缓存且请求返回 304
- **THEN** 缓存已先行供入口使用，继续保留该快照和当前会话标语，不重复展示或播报开场

#### Scenario: 请求或配置失败
- **WHEN** 网络失败或响应配置校验失败
- **THEN** 保留已有完整有效快照；缓存缺失或损坏时使用经确认随包快照，不冒充实时最新，不增加常规任务内加载重试或等待会员展示的整页门禁

#### Scenario: 抢先点击及后台配置更新
- **WHEN** 用户在远端返回前从首页或联系人选择任务，随后收到不同版本配置
- **THEN** 当前任务冻结原卡片 / Skill / 普通或联系人专用开场，新配置供下次进入；道歉保持专用 Consent，不吞掉或重复当前已显示内容

#### Scenario: 入口不可用
- **WHEN** 卡片为 comingSoon、版本不支持或没有动作
- **THEN** 禁止进入业务流程并展示对应提示

### Requirement: 模型和系统音色
系统 MUST 根据接口展示模型、可用性、音色与选择结果，选择成功后才更新当前配置。切换模型 MUST 仅影响后续通话，不主动开始通话。

#### Scenario: 保存失败
- **WHEN** 模型或音色保存失败
- **THEN** 保留原选择并允许重试

#### Scenario: 过期音色响应
- **WHEN** 用户切换模型后旧模型音色请求返回
- **THEN** 忽略旧响应，不能覆盖新模型状态

### Requirement: 克隆目录与选择必须区分当前资产和候选
系统 MUST 按 v65 对支持模型读取各自 current/candidate，MUST NOT 将 READY 候选当作已确认当前音色；候选确认与普通 CLONE/AI 切换 MUST 互斥且仅在用户操作时执行。

#### Scenario: 当前克隆和新候选并存
- **WHEN** 当前模型存在 READY 且 billingStatus=CHARGED 的候选且用户选择克隆
- **THEN** 优先确认该模型候选，再同步服务端实际选择；不调用旧 activate 或重复生成接口

#### Scenario: 确认成功但刷新失败
- **WHEN** 候选确认成功后音色或目录读取失败
- **THEN** 提示状态待同步，重试只读刷新而不重复确认 POST

#### Scenario: 跨模型或失败目录
- **WHEN** 目录请求失败或返回其他模型数据
- **THEN** 不将失败显示为未克隆，不套用其他模型资产；模型切换后的晚到结果不能覆盖新页

### Requirement: 主导航与视觉来源
系统 MUST 具备首页、联系人、任务、设置四个主导航及中央拨号入口；MUST 使用固定设计稿视觉，排除未在 v65 生效的未来功能。尚未迁移的下游功能 MUST 明确标记而非伪造成功。

#### Scenario: 登录成功
- **WHEN** 有效会话恢复或登录成功
- **THEN** 进入正式首页，而不是工程状态展示页
