# 设计

平台适配以AppLocalStorage保持现有FlutterSecureStorage注入接口；非iOS逐参数委托原插件。iOS通过固定MethodChannel调用私有目录的每键原子文件存储，偏好明文受系统文件保护，业务数据AES-GCM加密，AAD绑定类别与键摘要，密钥仅在钥匙串。目录排除备份并设置首次解锁文件保护；失败不当作不存在。

认证独立IosSessionStore：Token钥匙串、账号/电话/显示名加密沙盒；共同随机绑定值防止半写恢复。首次启动检查沙盒标记、只清本应用新Token前缀、清理完成后提交标记。失败不恢复登录，后续可重试；不扫描/导入旧业务钥匙串。并发初始化串行。正常重启及覆盖升级不重置。

C1 UUID为安装随机标识，保持协议和格式，仅iOS位置改沙盒；新安装生成新的值。凭据与服务路由不变。诊断加密密钥继续钥匙串，iOS不读取历史钥匙串日志迁移源；Android原日志迁移保留。认证录音密钥/文件及内购接线不变。

按最多3个手写源文件微批推进；各业务原有scope、版本、读改写锁和生命周期guard保持不变。退出登录继续使用现有账号切换生命周期，不新增队列重放或服务器副作用。

验证：OpenSpec、analyze、平台路由/会话失败与重装模拟及受影响业务定向测试；iOS无签名构建。不安装或卸载真实业务App，不真实认证/外呼/支付。无新增依赖，Android无需构建链更新。
