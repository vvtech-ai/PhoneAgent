## ADDED Requirements

### Requirement: 单路录音卡与相邻卡共同对齐
普通单路录音卡 MUST 左排且最大宽 280，与同入口字幕和结果卡左右边界一致；MUST 保留旧版 81 最小高度，大字体可自然增高。翻译入口 MUST 保留既有外边距，批量紧凑控件 MUST 保持既有行为。

#### Scenario: 正常和大字体回执
- **WHEN** Android/iOS 的正常或大字体页面展示单路字幕、录音及结果
- **THEN** 三卡左右边界相同，下载与播放操作可用，无溢出

### Requirement: 波形展示按录音身份与播放状态协调
待播 MUST 显示旧版静态高低占位。播放 MUST 消费当前录音已有采样，不使用展示时钟伪造音量；暂停 MUST 保留本卡最近帧。媒体/宿主身份变化、idle/结束或销毁 MUST 清除旧展示缓存。系统 MUST 保留既有下载、播放/暂停/恢复、结束重取源与无用户 seek 的边界。

#### Scenario: 暂停及切换录音
- **WHEN** 实际采样后暂停，再切另一个录音或结束
- **THEN** 暂停帧保持，另一个身份和结束态恢复各自静态默认，不接纳上一卡波形
