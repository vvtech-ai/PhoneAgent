## ADDED Requirements

### Requirement: 可信位置刷新与原生一致
客户端 MUST 在已有可信位置刷新时保持resolved并允许使用该位置拨号，独立标记刷新中并防重复请求；失败 MUST 保留可信位置。没有可信位置时 MUST 等待定位，不发起电话。
#### Scenario: 已有中国位置后台刷新
- **WHEN** 定位尚未完成且已有可信CN
- **THEN** 国内拨号使用该可信位置，刷新失败也保留该位置
#### Scenario: 首次定位和取消
- **WHEN** 无可信位置定位中或刷新被取消
- **THEN** 无可信位置不准入；取消清理刷新状态，迟到结果不覆盖现有状态
