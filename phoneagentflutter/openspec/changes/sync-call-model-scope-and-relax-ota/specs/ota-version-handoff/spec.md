## ADDED Requirements
### Requirement: 客户端验包不得依据版本大小或元数据版本差异拒绝安装
系统 MUST 接受后台下发更新中的同号/较小号以及后台版本与APK内版本不同的包，版本字段格式仍合法。MUST 保留包名、兼容签名、文件摘要/大小、下载归属和系统安装权限检查。MUST 同步覆盖启动恢复及原生安装前复核；不宣称绕过系统安装限制。
#### Scenario: 从未经批准的大号回到45
- **WHEN** 后台下发有效更新包且APK内版本为45，当前已安装版本更大或后台填写版本不同
- **THEN** APP完成身份与完整性校验后允许交给系统安装，不显示版本不匹配错误
#### Scenario: 包身份或完整性不正确
- **WHEN** 包名/签名不兼容或摘要/大小不匹配
- **THEN** 继续拒绝交接系统安装并提供现有重试提示
