## ADDED Requirements
### Requirement: 所有模型入口必须采用最新可用目录
系统 MUST 在首页、任务列表、设置及模型面板进入/恢复时刷新当前模型目录，会员可信履约后同步刷新。MUST 防止旧请求覆盖升级/发布后的新权益；失败不得沿旧目录授权操作。默认值校正 MUST 由服务端保存，合法原选择保持；无可用模型不伪造默认。
#### Scenario: 权益被收回后返回首页
- **WHEN** 旧默认已不在当前可用目录
- **THEN** 显示服务端校正的第一个可用模型，所有入口一致，后续拨打使用新默认
#### Scenario: 会员升级时旧读取仍在途中
- **WHEN** 旧读取与购买后的新读取先后完成
- **THEN** 仅最新有效代次结果可影响显示与操作

### Requirement: 道歉任务模型与全局默认必须区分
系统 MUST 让任务标签/倍率/列表选中项反映同一任务模型。Agent选项 MUST 只修改任务；任务模型列表显式手动切换 MUST 同时更新全局和当前任务。打开/关闭面板或恢复历史 MUST NOT 写全局；历史有任务选择时优先恢复，后台全局刷新不得覆盖有效任务选择。
#### Scenario: 全局豆包而任务选千问
- **WHEN** 用户在Agent选项选择千问并打开模型列表
- **THEN** 任务标签与列表均选千问，全局仍为豆包，退出首页继续显示豆包
#### Scenario: 用户在任务列表内手动切换
- **WHEN** 用户在任务模型面板明确选择另一个可用模型
- **THEN** 保存全局默认，成功后更新任务并按原门禁确认音色，返回首页反映新全局
#### Scenario: 历史任务和权限变化
- **WHEN** 从历史任务恢复或模型权限刷新
- **THEN** 合法任务选择保持；无权限的旧模型不能拨打，克隆仍按当前权益和确认状态校验
