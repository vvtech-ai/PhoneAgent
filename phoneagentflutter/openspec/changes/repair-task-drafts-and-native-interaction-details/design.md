## Context

当前Flutter codex/dev，旧App 1.6.0与原origin/test/v66.0.3@a0bedb12只读。四个草稿核心文件一致，既有Flutter实例内写队列不能防跨页面读旧值。OCR相册触发生命周期使在途TTS被当作失败，状态投影只识别失败文本。

## Goals / Non-Goals

目标：当前账号当前任务的未发送草稿持久化；已发送内容清除且失败/旧回执不覆盖新输入；旧版拨前布局/语言提示和正常暂停分类双端一致。
不处理Java、真实计费、翻译断网重连、声音克隆或自动重播播报。

## Decisions

1. TaskDraftController负责编辑版本和临时发送副本。发送入口接受后登记持久化清空，拒绝发送保持原值；真正传输未受理失败仅在没有新编辑时恢复。接入有效流事件的受理证据，不依赖唯一USER_TURN_ACCEPTED事实；业务执行失败不回填已受理输入。
2. SecureTaskDraftRepository复用持久化key、引入按账号共享读写队列。独立账号草稿索引负责已访问任务登记与清理，保留iOS保护沙盒；删除只清目标任务，登出清当前账号，不能用全局deleteAll。旧页面关闭后不再新增回调写入，后续读取等待已登记删除。
3. 应用接线负责账号释放与任务删除后的清理；存储和生命周期不塞到UI或认证Controller。新建会话沿用当前唯一sessionId，不借用其它任务。应用层清理适配器捕获本地存储异常，仅记固定无正文日志，不反转已成功的远程删除或阻塞认证释放；清理失败不能宣称数据已删除。账号provider仅观察accountId，不因token刷新重建任务控制器。迟到的其它命令账本不算本轮输入受理。
4. 现有积分格式化不变，独立RichText组件只负责灰色正文/金色星标；拨号页为底部说明提供槽位，布局保持小屏/字体缩放可用。用户取消的结束账单页不恢复。
5. 语言策略只在无效/缺省时避同语，保留有效手选；拨号准入先语言后号码提醒。不可用模型补原因并不推荐；国家页后台刷新保留列表。
6. TTS正常生命周期/音频焦点/附件打断先进入取消/暂停，不能发故障回执；真实供应商/传输/输出故障保持失败。附件入口显式暂停现有播报；控制器及状态投影显示指定短句，下一轮/录音/关闭播报/退出时清理暂停提示。复用现有取消和资源释放，不建第二套音频状态机。

## Risks / Trade-offs

跨页面旧写覆盖删除 -> 账号共享队列和延迟读写回归。迟到回执误删新输入 -> 编辑版本保护和账号/任务隔离回归。正常取消掩盖真故障 -> 故障状态优先，测试真实错误后再打断仍失败。刷新改变已选语言 -> 回归有效同语种保留。

## Migration Plan

现有草稿key不变，索引登记已访问任务；登出写当前账号reset标记，未索引的旧版本草稿在后续精确读取时清除，不猜测或扫描其它账号密文key。重新登录后的新保存重新登记为有效。失败保留源码与既有数据。完成测试后中文提交、正常push，打包前同步最新远端并验证最终代码。
