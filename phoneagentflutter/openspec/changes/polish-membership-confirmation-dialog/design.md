# 设计

以只读旧仓 origin/codex/phone-agent-monetization-linkage-20260814 的 demo 为视觉参考，用户提供的居中卡片图优先于旧 demo 底部支付层。不得复制旧差价、补发或折算规则。

保留 MembershipConfirmationSheet 的调用接口，由其渲染 Dialog；新增独立明细展示组件与渠道/协议操作组件，避免明细和交互状态堆在同一大文件。MembershipRoute 仅将会员确认入口切换 showDialog，积分及结果弹层不改。卡片最大342、内容左右24；可滚动内容、白底圆角、蓝色金额、灰标签/深值、原生渠道卡片、方checkbox和横排取消/确认并支付。

现有平台只提供一个有效渠道（Android支付宝或iOS系统内购），默认选中，不创造微信等不可用入口。通过可用性参数禁用失效渠道；已有选择在重建时保持，不因重建重新勾协议。协议初始false。提交一次后保持处理中与禁用取消；渠道展示不影响订单契约。价格仍直接消费原StoreKit地区格式或可信quote金额。

逐批不超过3文件；先RED验证居中、默认渠道、协议未勾选、小屏和支付互斥，再GREEN及真实会员入口定向。仅离线测试与截图，不构建安装、提交推送或真实支付。
