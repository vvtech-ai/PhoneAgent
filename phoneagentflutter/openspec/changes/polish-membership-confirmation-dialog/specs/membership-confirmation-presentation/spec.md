## ADDED Requirements

### Requirement: 居中会员确认卡片
客户端 MUST 使用居中白色圆角会员确认弹窗，最大宽342，内容左右24间距；标题左对齐，明细左右对齐，金额蓝色突出，支付渠道浅蓝卡片，协议左对齐方checkbox，取消和确认并支付横排；长内容及小屏大字体 MUST 可滚动且无溢出。

#### Scenario: 确认四种会员购买
- **WHEN** 用户确认 NEW、UPGRADE、RENEW 或 LOWER_QUEUED
- **THEN** 弹窗展示现有可信报价和首期、暂停、排队说明，不使用旧demo差价或补发规则
- **AND** iOS地区价格和Android报价格式保持原值

### Requirement: 默认可用支付渠道与主动协议
客户端 MUST 默认选中首个可用渠道并保持已有显式选择，MUST NOT 自动同意协议或选择禁用渠道；当前只有平台对应有效渠道，不展示虚构渠道。

#### Scenario: 用户确认付款
- **WHEN** 确认弹窗初次打开
- **THEN** 有效渠道已选中，协议未勾选且付款按钮不可用
- **AND** 用户勾选协议后可显式确认，处理中防止重复提交与取消
