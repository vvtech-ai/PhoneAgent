# 本轮源码与回归核验

## 范围与保留

实现记忆候选完整性、首轮缺资料补核、管理操作结果连续性，及客户端任务模型与安装版本来源。用户复核评分为既有设计，本轮没有评分源码、测试、资格锚点、奖励快照或既有评分规则变更。SIP、TTS、数据库结构和部署配置未调整。

## 只读现场证据

- 两位候选现场：主模型可用状态数量为二，已提交的记忆确认工具绑定仅一位，候选缩减发生在服务端展示前。
- 首次漏问现场：实际绑定餐厅预订；四次主模型请求均有 AVAILABLE / count=1，搜索选店后直接补问联系人，没有调用记忆检索。不是客户端把开关或候选正文缓存带入请求。道歉另以首次绑定真实 Agent 连续回放验证，不能将餐厅现场说成道歉现场。
- 管理结果现场存在重复同内容 ADD 与内部隐藏说明。源码投影会抹掉安全工具结果；原始现场写入是否成功不由重复工具名推断。
- 道歉准入读全局模型，而显示和最终请求使用任务选择；日志版本来自没有对应 Dart define 的默认常量。原生旧版的有效任务模型解析用于对照。

原生旧版正常能力保留；旧版直接注入未确认记忆正文的方式不恢复，沿用已批准的账号 / Skill / 版本 / 用途和采用门禁。

- Java Agent 及依赖模块离线 package 成功；未部署。
- Flutter 新增客户端 11 项通过，补齐原生版本夹具的既有正式上传用例 1 项通过；本轮 28 个路径的相邻复验 332 项通过、3 项失败。8 文件模型专项回归 33 项通过；改动源文件与测试静态检查无问题。

- 另一 UDP 用例在当前检出单独运行仍失败（有效包等待返回空），基线通过；直接测试及所有直接生产依赖字节一致，本轮未修改翻译 / SIP。环境或编译缓存差异未定位，不能将全量称为通过，也不在本次范围改 UDP 业务或删断言。

扩大运行比较清单见 regression-comparison.json。自动回放中的模型响应受控，不代表所有真实模型措辞已经验收。
