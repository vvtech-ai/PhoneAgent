## ADDED Requirements

### Requirement: App最近记录必须来自账号隔离本机元数据
系统 MUST 将本机拨号元数据与后台任务/归档分离，按环境/API/账号隔离保存；MUST NOT 保存媒体凭据或将未知schema/读取失败当作空记录覆盖。

#### Scenario: 普通交接和翻译记录
- **WHEN** 正式系统拨号交接成功或共享翻译Finished明确提交本机元数据
- **THEN** 保存本机记录，翻译按callId+kind去重；最近拨号只投影App翻译子集，系统交接不表示已接通

#### Scenario: 清理并发与换账号
- **WHEN** 同账号追加和清理同时发生，或读写期间登录代次失效
- **THEN** 同槽串行修改，已失效操作不写入新账号、不显示晚到数据；保存失败明确，不自动重复拨号

### Requirement: 最近通话合并与回填不得触发电话
Flutter MUST 共用系统记录和App翻译记录的source+id去重、时间倒序及20项上限；iOS MUST NOT 读取系统通话记录，未接数据源不得伪装读取成功。

#### Scenario: 空号拨号与选择历史
- **WHEN** 输入为空点击呼叫且存在历史，或点击有效历史行
- **THEN** 只回填号码和姓名，不发起电话；无效号码不回填；输入非空显示联系人建议

#### Scenario: 翻译历史恢复
- **WHEN** 翻译配置页选择历史
- **THEN** 保持当前翻译开关，恢复号码/地区和有效主叫语言，不用记录被叫语言覆盖当前值

#### Scenario: 双源错误与隔离演练
- **WHEN** 一个来源失败、撤权或控制器销毁后返回
- **THEN** 不泄露旧记录或更新已销毁页面，独立来源仍可展示；MOCK仅显式入口，不能调用真实来源或保存到账号

#### Scenario: 已授权Android系统记录
- **WHEN** 正式拨号加载系统来源
- **THEN** MUST仅在Android且已具有READ_CALL_LOG授权时读取CallLog，前后复查权限，撤权丢弃记录；未授权不自动弹权限，iOS/Web不调用平台通道；读取异常不得伪装成功空列表

### Requirement: 拨号建议必须沿用联系人匹配和只回填语义
Flutter MUST 在普通和翻译拨号共用纯数字T9/号码候选规则，姓名组优先并至多10项；MUST只读取已授权联系人，不因建议自动申请权限、上传通讯录或拨打电话。

#### Scenario: 同人多个号码与国际区号
- **WHEN** 查询命中姓名拼音全拼或首字母T9前缀
- **THEN** 该联系人组只返回首个号码，排在号码子串命中之前；国际号码匹配不包含已知区号

#### Scenario: 选择与权限变化
- **WHEN** 点击候选或恢复前台后发现权限已撤回
- **THEN** 选择只回填姓名号码，撤权清除旧候选；错误和退出晚到不泄露旧数据

### Requirement: 联系人列表与目录备注分开管理
Flutter MUST 使用系统通讯录作为联系人列表来源，将后端目录作为账号备注来源，不把仅存在于后端的目录项自动添加到系统列表。

#### Scenario: 同名多号码
- **WHEN** 同一姓名具有多个不同号码
- **THEN** 保留不同号码，仅按姓名与查询号码去重并排序，系统拨号使用独立原始号码

#### Scenario: 权限拒绝或平台不可用
- **WHEN** 设备未授权或 Web 无系统通讯录能力
- **THEN** 返回明确权限/不可用状态，不伪造授权，不自动上传或展示假通讯录

### Requirement: 备注写入必须保持既有字段及账号边界
Flutter MUST 沿 v65 通过账号绑定 POST 保存备注，保留已有关系/说话风格/显示名，空备注发送 null。

#### Scenario: 编辑备注
- **WHEN** 选择设备联系人并保存备注
- **THEN** 按标准目录号码匹配已有项，仅提交该联系人资料，不上传其他联系人

#### Scenario: 保存失败或重复点击
- **WHEN** 请求失败或请求仍在执行
- **THEN** 保留草稿和旧备注，同一保存只发送一次，可在失败后重试

#### Scenario: 账号或详情变化
- **WHEN** 保存/读取晚到时所属控制器已销毁或当前详情改变
- **THEN** 不覆盖新账号/其他联系人的编辑状态

### Requirement: 平台接口必须保持薄适配
Flutter MUST 共享业务状态和页面，只有系统授权及通讯录读取依赖各平台；普通拨号与 Agent 任务入口不得混淆。

#### Scenario: Android 与 iOS 读取
- **WHEN** 获得授权后读取通讯录
- **THEN** 原生仅返回名称/号码等必要字段，格式处理与去重在 Dart 共用，不读取 iOS 系统通话记录

#### Scenario: 设计与人工验收
- **WHEN** 使用合成权限/联系人验证 Web
- **THEN** 明确标记 mock，与真实平台读取分开记录；没有运行态设计证据不声明页面已还原

### Requirement: 联系人技能入口复用统一对话
Flutter MUST 按 v65 仅展示可用 OpenSkill 入口，选择后进入默认语音的统一页，首轮有效用户输入携带 source=CONTACT_DETAIL 的姓名和查询号码；后续轮次不重复转发该上下文。

#### Scenario: 显式 Web 演练
- **WHEN** 用户主动开启 debug Web 联系人演练并选择技能
- **THEN** 列表、备注和 Agent 使用隔离合成端口；统一页允许切文字和离线回复，不读取真实账号、不发送联系人、不创建真实任务或拨号

#### Scenario: 静态设计优先实现
- **WHEN** 按 2026-09-17 用户批准接入交互页面
- **THEN** 允许基于已有 HTML/CSS 和组件开发，单独记录视觉差异并后续校准，不能用模拟或静态推导冒称真实系统/视觉验收

### Requirement: 普通拨号必须保留号码和平台边界
Flutter MUST 共享v65号码解析和四地区目录；普通拨号仅交给系统电话，不创建Agent任务或假通话记录。

#### Scenario: 号码编辑与返回
- **WHEN** 从底栏或联系人进入拨号盘
- **THEN** 支持数字输入、14位数字上限、删除/长按清空、地区选择；关闭和系统返回回到来源页面

#### Scenario: 普通系统电话交接
- **WHEN** 用户明确点击普通拨号且号码合法
- **THEN** Android通过ACTION_DIAL打开系统拨号盘，iOS通过tel打开系统确认；失败可重试，交接成功不代表已接通

#### Scenario: Web交互演练
- **WHEN** 浏览器无法调用平台电话能力
- **THEN** 明确提示不可用；仅显式debug演练可模拟交接，不能发真实电话或伪造通话历史
