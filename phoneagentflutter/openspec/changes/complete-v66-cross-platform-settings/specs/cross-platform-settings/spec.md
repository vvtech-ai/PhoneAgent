## ADDED Requirements
### Requirement: 双端独立任务音色
Android和iOS MUST 提供Maia默认及Andre设备级选择和任务TTS试听，回复创建时固定音色且不改通话/克隆配置。失败MUST可重试，离页/后台MUST停止试听，已有音频租约MUST继续生效。
#### Scenario: 播报期间修改音色
- **WHEN** 用户修改音色
- **THEN** 当前回复保持快照，下一条使用已保存选择
### Requirement: 双端设置入口
两端 MUST 按顺序提供“记忆”“Skill 卡片”“语音模型与音色”前三个设置入口，说明文字分别为“管理在任务中使用的背景与偏好”“调整首页Skill 卡片的顺序与显示”“通话AI语音、任务AI语音”，MUST移除我的身份设置入口并保留克隆认证能力。
#### Scenario: 管理卡片
- **WHEN** 用户在设置打开卡片管理
- **THEN** 复用原账号显隐/排序偏好和恢复默认
### Requirement: 记忆由服务端权威管理
两端 MUST 通过现有签名AccountApi读取及操作记忆，支持范围、编辑、删除、清空和即时开关；失败MUST回滚且旧账号结果MUST失效。订餐MUST保留自然回答，不自动读取身份或手机号，不伪造记忆保存。
#### Scenario: 开关提交失败
- **WHEN** SET_ENABLED失败
- **THEN** 回到原开关状态并提示重试，返回无需丢弃确认
### Requirement: 无需预订独立结果
明确NO_RESERVATION_REQUIRED结果 MUST 作为完成且与预订成功区分，实时与历史 MUST一致。
#### Scenario: 商户要求直接到店
- **WHEN** 服务端返回NO_RESERVATION_REQUIRED
- **THEN** 显示无需预订、直接到店并保留原因和账单

### Requirement: 语音页面保持原生布局和交互
两端 MUST 从设置直接进入语音模型与音色原页面，保持克隆和模型选择交互，在原模型列表下方展示任务AI语音卡片；MUST使用任务AI音色底部弹层选择/试听，不增加中间入口或独立任务音色页面。
#### Scenario: 打开任务音色
- **WHEN** 用户点击原模型页面底部的任务AI语音卡片
- **THEN** 展示Maia温柔女声、Andre沉稳男声、当前标记和独立试听按钮
- **AND** 关闭按钮、遮罩或系统返回关闭弹层并停止试听；保存失败不显示成功

### Requirement: 记忆页面保持原生UI和交互
两端 MUST 还原a0bedb12记忆首页两卡片、记忆内容列表容量条/更多菜单/底部添加、编辑页标签和圆角内容区及保存按钮。适用任务 MUST 使用取消/完成底部弹层，临时选择仅完成应用，停用标签保持可移除。单条删除 MUST 在编辑页，删除全部 MUST 在列表更多菜单；确认文案/按钮与原生一致。失败重试 MUST 重做失败动作，开关失败回滚，编辑未保存返回丢弃，提交中阻止重复操作及返回。
#### Scenario: 取消适用任务修改
- **WHEN** 用户在任务选择弹层改变选项后取消、点击遮罩或系统返回
- **THEN** 编辑草稿范围保持原值，不发送保存请求
#### Scenario: 删除失败重试
- **WHEN** 删除请求失败后点击重试
- **THEN** 重做失败的删除动作而非重新加载，成功后按原生返回列表

### Requirement: Skill卡片保持原生UI和交互
两端 MUST 还原Skill卡片居中标题、拖动说明、白色圆角列表、左侧六点即时拖动手柄、右侧绿色显隐开关及底部固定恢复默认按钮。即将提供卡片 MUST 仅显示对应状态说明。拖动取消 MUST 不保存；松手保存及显隐修改 MUST 在成功持久化后发布首页有效偏好，失败保留原设置并提示设置未保存，请重试。恢复默认 MUST 使用原生文案/布局确认框，仅清除当前账号偏好。
#### Scenario: 保存排序失败
- **WHEN** 用户通过手柄拖动松手且持久化失败
- **THEN** 页面与首页保持此前有效顺序，重试保存失败目标，不发布假成功
#### Scenario: 取消恢复默认
- **WHEN** 用户关闭或取消恢复默认设置确认框
- **THEN** 不修改当前账号的排序和显隐

### Requirement: 记忆保存按钮文字保持原生样式
添加与编辑记忆的保存按钮 MUST 对齐AIAssistant1的38高、胶囊形、14号Medium、水平16内边距及最小64宽，MUST保留启禁用配色与保存状态流；正常字号的保存及保存中文字 MUST 单行完整居中呈现。
#### Scenario: 保存进入提交状态
- **WHEN** 用户保存有效记忆且请求未完成
- **THEN** 按钮显示单行保存中，沿用禁用配色并阻止重复提交
