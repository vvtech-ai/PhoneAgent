## ADDED Requirements

### Requirement: 完整App权限工具演练必须隔离并可恢复
完整App演练 MUST 复用正式权限协调器与统一对话页面，仅注入合成权限源；权限请求、结果及后续文字 MUST 属于同一内存会话历史，不申请真实权限或读取设备资料。

#### Scenario: 权限结果后恢复续聊
- **WHEN** 合成Agent请求权限，返回允许、拒绝或需设置结果后退出并恢复任务
- **THEN** 对应permission_result只提交一次，历史恢复不重新申请权限或重发结果；用户可继续文字，不增加空的用户消息
- **AND** 退出合成登录后端口与历史重置，旧会话迟到结果不得作用到新会话

### Requirement: 登录代次改变必须释放旧业务导航
正式App MUST 在登录身份代次失效或替换时释放旧业务路由与弹层，显示当前认证状态；MUST NOT 通过保留旧凭据、吞掉鉴权错误或自动发送短信维持旧页面。

#### Scenario: 活跃对话被服务端拒绝
- **WHEN** 有效当前会话经rejectSession失效或显式退出时仍有对话及子页面
- **THEN** 旧页面/流/控制器被释放，不因重建访问已失效账号而产生未处理异常，登录页可见，旧回复不覆盖新状态

#### Scenario: 同代次令牌刷新
- **WHEN** 同一登录身份仅替换访问令牌
- **THEN** 现有导航和输入草稿保持，不当作重新登录；后续真实登录更换代次则不能返回旧业务页面

### Requirement: 完整App联系人工具演练必须续接同一历史
隔离完整App宿主 MUST 复用正式号码/姓名匹配与ConversationToolCoordinator，仅替换联系人及服务端续接外部端口；MUST NOT 读取系统通讯录或发送真实联系人结果。

#### Scenario: 查询与候选恢复
- **WHEN** 合成Agent请求号码或姓名查询并在返回候选后退出恢复
- **THEN** 查询结果与后续候选写入同一会话ledger，恢复不重新查询或重发用户命令；姓名候选由共享匹配器生成，文字输入保持typed来源，选择继续按既有“第N个”语义
- **AND** 关闭/换登录后的旧端口拒绝提交，不能接受其他session或不匹配tool的结果；所有样例与反馈明确MOCK

### Requirement: 集中验收目录必须复用并隔离已有页面
开发验收入口 MUST 在同一移动视口提供已注册模块目录、模拟范围和返回目录，复用已有共享页面/演练宿主，MUST NOT 复制业务页面、访问真实账号或将模拟能力标为真实通过。正式main不得依赖该工具目录。

#### Scenario: 场景导航与重置
- **WHEN** 用户打开场景、进入其子页，然后返回目录再重新打开
- **THEN** 场景子Navigator和原状态被释放，新实例从原合成初态开始；常驻MOCK和目录操作保持可达，小屏不横向溢出

#### Scenario: 完整App诊断存储隔离
- **WHEN** 合成页面创建诊断、切换登录或退出场景触发flush
- **THEN** MUST 只使用场景内按登录代次隔离的内存日志，不读取或写入设备安全存储；验收测试必须断言没有安全存储通道调用

#### Scenario: 完整App日志上报连续演练
- **WHEN** 在隔离完整App从设置进入日志页并操作上传与清理重试
- **THEN** MUST 使用正式日志页面/控制器和当前合成登录的Journal，只替换外部仓库端口；首次进入仅准备ZIP，不自动上传
- **AND** 上传失败保留日志，上传成功而清理失败只重试清理、不重复上传；离页后重进查看同源余留日志，换登录不复用旧模拟状态，不能发真实HTTP或访问设备存储

#### Scenario: 评价与会话积分集中演练
- **WHEN** 打开评价或会话积分演练并连续操作后返回目录重开
- **THEN** MUST 复用正式评价/条件评分/积分组件，只使用合成服务和内存草稿；评分失败可重试、成功只读，积分同一会话重挂载不重复激活
- **AND** 退出释放容器与计时器，重新进入恢复合成初态，不调用真实接口、读取账号或发放积分

#### Scenario: 统一入口与验收边界
- **WHEN** 在独立loopback端口打开目录
- **THEN** 不触碰正式8080登录、不自动SMS/外呼/安装；目录列出当前已注册场景，不据其数量推断完整迁移完成

#### Scenario: 正式开发者入口连续演练
- **WHEN** 在完整App演练中通过既有拨号暗号解锁并打开开发者功能
- **THEN** MUST 复用正式设置/外呼页面及Controller，只以隔离内存Repository保存合成号码；保存、取消、删除与失败重试可连续进行，页面重开保留而退出登录/场景重置
- **AND** 网络/列表/权限重置操作使用已有共享规则及合成端口，不更改系统网络、真实记录、权限或后端号码

#### Scenario: 完整App联系人连续演练
- **WHEN** 在隔离完整App宿主通过联系人备注、拨号或Skill进入对话并从任务列表恢复
- **THEN** MUST 使用正式共享联系人/对话/任务路由和同一合成数据源，联系人/备注按登录代次隔离；只有首个有效提交携带选择的联系人，恢复不重发
- **AND** MUST 只在验收宿主覆盖Web路由选择，正常Web不读取系统联系人；所有系统拨号交给合成端口，不触发电话或真实备注写入

#### Scenario: 翻译关闭后的普通呼叫隔离
- **WHEN** 从首页翻译或普通拨号配置进入翻译页并关闭翻译后拨号
- **THEN** MUST 使用当前作用域系统拨号端口或调用方显式端口，不在子路由重新创建绕过注入的原生端口
- **AND** 正式默认仍交给系统，MOCK只记录合成号码且原生通道调用为0；翻译开启时不得降级为普通呼叫

#### Scenario: 完整App附件连续演练
- **WHEN** 从正式对话菜单导入合成文档或图片，退出后从任务列表恢复
- **THEN** MUST 复用正式导入、OCR和会话控制器，从同一会话内存ledger恢复文档类型、图片及锚点；选图本身不提交Agent命令，随后文字携带成功OCR上下文，恢复不重新上传
- **AND** 文件选择/解析/识别/存储仅替换为隔离端口，不访问真实文件或账号；不同会话及登录代次不串数据，失败或取消不创建成功文档消息

#### Scenario: 完整App回执评价连续演练
- **WHEN** 从任务列表恢复合成单路或批量回执，操作录音和评价后再次进入
- **THEN** MUST 复用正式回执、录音、赞踩、条件评分页面与控制器；评价及草稿按真实目标种类/ID隔离，eligible决定评分显隐，失败保留草稿、成功只读，退出合成登录或场景重置
- **AND** 声音/文件/评价/积分均为隔离合成端口，不调用真实服务；恢复与续聊保留种子历史，不据样例声称外呼完成

#### Scenario: 完整App单路通话连续演练
- **WHEN** 在隔离完整App发送明确合成单路指令并收到自动确认请求
- **THEN** MUST 经正式准入/会话控制器进入共享通话页，监听和音源仅用合成端口；明确挂断才改变合成远端状态，普通返回不挂机
- **AND** 任务和恢复来自同一会话历史，恢复不重发confirm_call，不同会话/登录不串通话；未知目标必须拒绝且不回退真实API、存储或媒体

#### Scenario: 连续查看正式基础导航
- **WHEN** 打开基础App演练
- **THEN** MUST 使用正式App与路由，基础账号、模型、任务、积分由隔离合成端口提供，未配置接口不得回退真实环境
- **AND** MUST 支持页面返回与内存退出登录；固定历史样例不得标记为新增对话持久化验收

#### Scenario: 新建对话连续恢复演练
- **WHEN** 在基础App演练中新建文字对话、退出并从任务列表重新打开
- **THEN** MUST 从同一隔离内存事件源恢复该会话的输入、候选与回复，未处理候选可继续、已处理候选不可重复选择，恢复不重发命令
- **AND** 不同会话不串数据；退出合成登录或重开场景重置新增数据；不得将内存演练标记为真实后端或跨进程持久化通过

#### Scenario: 从任务连续查看翻译历史
- **WHEN** 从完整App演练任务列表打开不同翻译记录、播放暂停或选择保存
- **THEN** MUST 使用正式详情与录音控制器，按合成ID显示不同字幕；只以合成播放器和明确MOCK保存弹层替换外部能力，不播放声音、写文件或访问真实接口
- **AND** 返回/退出场景释放计时与端口，未知ID不得返回其他记录或回退真实接口，取消保存不得显示已保存

### Requirement: 共享移动视口调试
Web MUST 复用移动应用页面和业务代码，宽屏限制手机宽度，窄屏自适应；MUST NOT 另建一套业务网页。

#### Scenario: 桌面与手机宽度
- **WHEN** 在桌面或手机宽度浏览器打开
- **THEN** 页面、弹层与输入区使用相同受限视口，页面无横向溢出

#### Scenario: 小屏键盘与异常状态
- **WHEN** 小屏竖屏打开键盘，页面处于空会话或历史同步失败状态
- **THEN** 输入与返回保持可达，提示和重试可滚动访问，不发生布局溢出
- **AND** 切换语音和文字不丢未提交草稿，提交被拒绝时不清空草稿

### Requirement: 浏览器流式协议兼容
浏览器 MUST 逐段交付 POST SSE 响应并支持取消，复用既有解码器和会话隔离；开发代理 MUST 限定本机及测试上游，不缓存流、不记录凭据。

#### Scenario: 响应尚未结束
- **WHEN** 上游分段发送且尚未关闭
- **THEN** 页面能接收首段；退出取消上游，不再修改已关闭会话

### Requirement: 分层验证与证据
页面与普通文字流程 MUST 优先使用浏览器及自动化测试；平台能力和里程碑 MUST 在对应真机验证，样例与真实验证必须区分。

#### Scenario: 共享页面双端阶段冒烟
- **WHEN** 在Android/iOS执行已在Web验证的共享页面连续流程
- **THEN** MUST 复用正式页面和控件，使用明确MOCK的隔离端口，按模型、会话和记录ID断言上下文及返回行为，并按平台保存关键状态截图
- **AND** MUST 保留原Dev数据及正常启动方式，不发送新短信、不外呼；记录实际执行范围、构建基点和未验外部能力，不能把MOCK或截图数量当作全迁移完成

#### Scenario: 收尾核验正式入口
- **WHEN** 汇总迁移剩余任务和完成证据
- **THEN** MUST 从当前正式App入口核对页面、共享控制器和外部端口接线，区分未实现与已实现待人工验收
- **AND** MUST 记录当前设备安装版本与验证边界，不用旧包、缓存页面或历史重复待办推断当前完成状态

#### Scenario: 验收一次文字闭环
- **WHEN** 验证登录、发送、退出、恢复和继续发送
- **THEN** 记录自动断言和关键状态截图；真实接口未通过不得用样例测试替代

#### Scenario: 无短信登录表单回归
- **WHEN** 在独立 Web 验收入口测试验证码、邀请码及会话保存失败
- **THEN** 使用正式共享页面与控制器，仅外部端口替换为显式 MOCK 和内存存储，不读取或清除普通 App 的登录态
- **AND** 验证小屏键盘下操作可达、错误后可修改重试、认证成功但保存失败不重复提交验证码

### Requirement: 工具卡遵循基线展示生命周期
共享统一页 MUST 按 v65 区分流式工具进度和持久业务卡，不得把 tool_card 仅当状态栏文案，也不得从脱敏历史臆造被省略的工具内容。

#### Scenario: 同一工具连续更新
- **WHEN** 一轮内相同工具 ID 收到多个 tool_card
- **THEN** 原位更新条件/结果，保留同轮 AI 文本，不重复插卡

#### Scenario: 完成本轮
- **WHEN** 本轮流结束或中断
- **THEN** 普通工具卡收起，已批准的交互卡按基线保留；同工具的结构化持久消息优先，历史恢复不补造普通工具卡
