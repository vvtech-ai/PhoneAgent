# 实施设计

- 新增CancellationCoolingProperties，复用既有@ConfigurationProperties/@RefreshScope方式，Nacos Data ID仍为aiassistant-sdk-api.yml。默认1296000秒；正整数，范围1..1296000。上限保护既有16天查询/17天清理窗口及验证/确认余量，不无界延长业务期限。非法值绑定失败，不用于新确认；不静默截断或用非法值重算申请。
- CONFIRM创建时读取一次有效配置并持久化cooling_period_seconds；SMS/VERIFIED沿用该快照。配置刷新只作用于新确认，不静默改变已展示流程。旧临时确认无快照时要求重新确认，已受理操作重放先返回原事实，截止不重算。
- applications按VERIFIED且与SMS一致的秒数快照计算acceptedAt.plusSeconds，毫秒精度保持；最终预计时间返回同快照。既有申请表和effectiveAt不回填。
- Challenge新增可空Long字段，LOGIN用途可空。更新新库与SDK测试schema，给已交付结构新增一次性补列脚本；不改旧迁移制造已执行假象。
- Confirmation响应增量coolingPeriodSeconds；客户端无输入该字段权限。Flutter缺字段时显示“冷静期内”，有字段必须为正整数，畸形响应拒绝。
- 展示严格大于阈值：>86400秒按天，>3600按小时，>60按分钟，其余秒；完整单位向下取整。例86400=24小时、3600=60分钟、60=60秒、90000=1天。绝对预计截止继续展示。复用原NativeBusinessDialog，不改其它UI及交互。
- 保留固定16/17天窗口，不缩短恢复/清理；不改协议正式15天承诺、主线程当前通话处理、登录/撤销或原权益处理。
