# 国内翻译结算未确认提示

## Why
国内翻译结束后结算未确认目前落入“通话未接通，请稍后重试”，不能准确表达已结束通话的结算状态。用户确认复用原生结算失败正文，通过 Flutter 现有共用 Toast 提示。

## What Changes
- 国内翻译无其他主错误且结算未确认时提示“通话已结束，但结算结果暂不可用，请稍后查看积分流水”。
- 主错误优先，纯资源清理异常仍使用现有兜底；保留内部清理未确认状态和诊断。
- 复用已有跨页、单次 Toast；不新增账单页面，不改 UI 样式、接口、重试、计费或释放流程。

## Impact
- 仅国内协调器终态原因和共用错误文案映射，以及定向测试。
- 细化 align-translation-toast-native-parity 的终态提示规则；海外行为和已确认扣分反馈保持。
- 初始范围仅本地实现；用户后续明确授权本次 Git 提交并推送 origin/codex/dev。无打包、安装或真实外呼，不归档。
