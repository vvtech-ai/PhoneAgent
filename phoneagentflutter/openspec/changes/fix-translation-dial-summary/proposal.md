# 修正翻译拨号摘要

## Why
用户批准仅修改拨号键上方模型与语言摘要。当前Wrap可引起错位，国内关闭后仍显示双方语言，固定语言表及海外倍率回退可能与选中目录模型不一致。

## What Changes
- UI参考AIAssistant1 a0bedb12a的状态点、字体、间距、倍率与箭头，标准尺寸单行左右排列，小屏/大字体受控分行。
- 内容参考aiassistant_app b28fc06：模型displayName及其倍率、目录语言名称、关闭文案。
- 仅修改摘要及直接接线，配置/语言/模型弹层、接口、模型ID和外呼流程不变。

## Impact
Flutter Android/iOS共享摘要；当前codex/dev_zys工作区保持，已有3份未提交记录保留。不提交推送，不触发真实外呼，不升级工具链。
