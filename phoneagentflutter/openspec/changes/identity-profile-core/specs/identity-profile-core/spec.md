## ADDED Requirements

### Requirement: 完整App身份克隆演练必须保持共享流程和模型归属
明确MOCK的完整App演练 MUST 从设置身份进入共享克隆创建、认证、候选与确认页面，仅替换外部端口；MUST 使用合成表单提示，不申请摄像头/麦克风或发送真实身份资料。

#### Scenario: 生成并确认
- **WHEN** 演练选择千问或Seeduplex V3并确认生成音色
- **THEN** 候选modelId必须匹配选择，合成身份/默认音色回流设置；原始正式配置不变，录音和试听仅为隔离状态演练

#### Scenario: 复用与退出
- **WHEN** 演练已保存认证录音后为另一模型创建，或关闭当前流程
- **THEN** 复用路径不重复采集，关闭释放合成播放器/采集资源；普通正式入口不因此开启模拟认证

### Requirement: 删除后的本地失败必须提供安全重试
Flutter MUST 在服务端删除成功、本地跳过偏好或录音清理失败时提供只重试本地处理的入口；MUST NOT 再次DELETE或重复已成功的本地步骤。重试 MUST 绑定原账号与删除时的录音写入边界，不删除后来成功生成的录音。

#### Scenario: 部分失败后重试
- **WHEN** 本地任务部分成功后用户点击重试
- **THEN** 仅执行尚未成功步骤，忙时禁止重复，成功清除该错误；页面销毁后不更新旧UI、不自动重试

#### Scenario: 新录音或账号替换
- **WHEN** 删除后有更新的录音成功保存，或原账号失效
- **THEN** 旧清理重试不清除新录音，不在新账号执行；页面中的模拟演练不持有真实账户或录音端口

### Requirement: 删除后状态必须遵循服务端结果并协调本地缓存
Flutter MUST 在服务端确认删除后更新身份、刷新模型音色并持久记录本机跳过引导状态，不把本地存储失败误报为服务端删除失败。

#### Scenario: 删除成功
- **WHEN** 当前账号删除成功且控制器仍有效
- **THEN** 使用返回的空资料，失效模型/音色缓存并记录跳过初始化
- **AND** 清除当前环境和账号绑定的本机认证录音，等待在途保存结束；本地清理失败不重发DELETE
- **AND** 跳过标志跨启动保留、按环境隔离，不在退出账号时自动清除

#### Scenario: 删除失败或晚到
- **WHEN** 服务端删除失败或结果到达前控制器已销毁
- **THEN** 不刷新当前账号模型，不写跳过标志

#### Scenario: 删除成功但跳过标志持久化失败
- **WHEN** 服务端已成功而本地存储失败
- **THEN** 保留服务端返回资料和刷新效果，提示本地保存失败，不自动再次发 DELETE

### Requirement: 身份编辑必须遵循认证边界
Flutter MUST 根据服务端状态区分普通资料和已认证资料，已认证保存只能更新元数据。

#### Scenario: 已认证资料保存
- **WHEN** 当前资料已认证
- **THEN** 使用 PATCH，仅发送账号、性别和联系电话，不覆盖认证姓名

#### Scenario: 普通资料保存
- **WHEN** 姓名有效且资料未认证
- **THEN** 使用 POST，规范化字段，保留有效既有职业信息

### Requirement: 状态必须隔离并避免误删
Flutter MUST 保留失败时旧资料/草稿，并防止重复操作和旧账号结果污染。

#### Scenario: 删除没有确认
- **WHEN** 删除未获 UI 显式确认
- **THEN** 不发请求

#### Scenario: 保存失败
- **WHEN** 网络或服务端拒绝
- **THEN** 保留原资料与编辑内容，允许重试，不伪造保存或认证成功

### Requirement: 身份页面必须使用真实编辑与确认流程
Flutter MUST 从设置进入身份页面，按服务端资料呈现空白、普通、已认证和编辑状态。

#### Scenario: 首次保存与已有资料保存
- **WHEN** 保存成功
- **THEN** 原资料为空时显示保存后的资料，原资料非空时返回设置

#### Scenario: 删除和系统返回
- **WHEN** 用户点击删除
- **THEN** 先展示可取消的确认弹层，系统返回只关闭弹层，确认才调用删除

#### Scenario: 认证资料展示
- **WHEN** 服务端资料为已认证
- **THEN** 显示已认证标记，编辑时姓名只读，仍可改手机号和性别

### Requirement: 首次引导必须以已加载身份与跳过偏好为依据
Flutter MUST 区分身份读取失败和真实空身份；根据用户2026-09-21最新纠正，共享引导 MUST 在正式登录后仅包含身份、通话模型两步及返回、草稿保留和显式跳过。MUST NOT 在初始化读取/写入国外翻译配置；国外模型仍在既有翻译设置选择。

#### Scenario: 正式登录后的首次流程
- **WHEN** 登录已恢复且身份成功加载为空、没有安装级跳过
- **THEN** 在进入主页面前展示两步；第二步保存通话模型，再保存非空姓名身份，否则持久跳过，之后进入共享Shell并刷新模型/身份消费者

#### Scenario: 翻译偏好与账号边界
- **WHEN** 用户完成初始化，或初始化期间账号失效
- **THEN** 不触发翻译偏好、位置/麦克风权限或电话操作；旧账号结果不继续发起下一项写入

#### Scenario: 已初始化或已跳过
- **WHEN** 身份成功加载且姓名非空，或本机持久跳过为true
- **THEN** 不重复展示首次引导，不因此调用模型选择或身份保存

#### Scenario: 部分保存失败
- **WHEN** 模型选择成功而后续身份或本地跳过保存失败
- **THEN** 保留步骤/草稿，重试失败环节，不再次重复前面已确认成功的写入

#### Scenario: 取消或销毁
- **WHEN** 页面销毁或用户在允许返回的步骤回退
- **THEN** 不自动保存，不继续执行晚到结果之后的下一次写入
