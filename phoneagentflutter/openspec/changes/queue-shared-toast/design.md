## 设计
公共入口维持 showNativeNotice(context, message, duration, overlay)。每个请求只保留消息和时长；队列绑定实际 Overlay，不保留调用页面 context，因此同账号普通页面跳转不取消已入队提示。不同 Overlay 不共享旧队列。

FIFO 同时最多挂载一条提示。现有180ms淡入、保持时长、180ms淡出保持；下一条在上一条移除后创建，计时从自身展示开始。空文案不入队，不合并或去重合法事件，事件幂等仍由业务控制器负责。

dismissNativeNotice 清空正在展示及待展示提示。自然结束推进下一条；非预期组件/Overlay销毁清空所属队列，不把销毁当自然结束。使用当前 entry 身份检查，防止旧组件的异步销毁回调清理新提示。SessionNavigationHost 在账号 release 和销毁时主动清空，token刷新不清队列。

UI 不变：22×22品牌图标、黄色星号、深色文字、白底圆角、边框阴影、键盘避让和 IgnorePointer。积分入口维持逐条调用及服务端金额，不新增登录提示或改变邀请奖励弹窗。

## 分批与验证
源码微批1：公共控件、会话导航宿主及公共队列测试（最多3文件）；微批2：积分集成测试、更新受新语义影响的原有公共测试（最多2文件）。均低于500行，队列与展示属于单一公共提示职责，不引入额外业务控制器。

运行固定Flutter3.32的 analyze 和公共提示/积分/账号/登录/邀请/模型直接调用方定向测试，验证连续调用、不同寿命、主动清空、淡出中追加、Overlay销毁、新队列不被旧回调清理、普通导航和账号释放。运行 openspec validate --all 和 diff检查。真实双端视觉验收待验，不发送真实短信或触发赠送。
