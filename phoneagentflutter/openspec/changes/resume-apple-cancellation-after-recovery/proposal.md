# 恢复成功后继续补报 Apple 取消待办

## Why
2026-10-22 用户要求完善自动补报恢复时机。原规则每登录仅启动一次，在启动接口尚未恢复时消耗机会，之后查单成功仍不补报。

## What Changes
- 启动恢复失败不补报；成功恢复或查单后处理已保存待办。
- iOS 复用已有网络状态事件和交易恢复入口，网络恢复、回前台后恢复原单；仅可达状态不证明支付成功。
- 同登录每单自动检查最多三次，成功上报未终态不重复，失败保留原请求 ID 和待办供后续机会或下次启动。
- 不改 UI、手动取消、验单、finish、后端和真实支付数据。

## Impact
PhoneAgent domain 的取消待办持有重试预算，purchase provider 接线，原 PurchaseController 持有展示状态。接口为原单查询和关闭；账号/环境/登录隔离不变。
