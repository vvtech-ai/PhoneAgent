# 设计

基线 feature/test_v1.8.0@0a74f992，开始时工作区干净。当前两处共用控制区没有 AI 说明。实时翻译按钮 64dp，文字 13sp / #DCE3F0，间距 7dp；任务电话按钮 52dp、固定列宽 72dp，文字 12sp / white / bold，间距 8dp。两处 Text 均未指定 textAlign，继承既有方向与默认设置。用户修正要求为文字横向对齐方式一致，不额外要求与按钮几何中心共轴。

新增 core/design 下 AiContentNotice，共用文案与自然换行，调用者传入原标签 TextStyle，并按用户 2026-10-27 最新要求将说明字号设为原标签字号 × 0.7 后四舍五入（13 → 9sp、12 → 8sp），标签自身不变；保留默认 textAlign，不限制行数或缩放字号。Center 负责收纳自然宽度的文本，长文由父约束提供整行空间，不受按钮 72dp 限制。两页均在原控制区域下追加原间距与说明，任务电话原三按钮 Row 不变；说明在禁用时沿用挂断区透明度。页面原有可伸缩字幕区继续吸收底部高度。

文件职责：AiContentNotice 提供只读文字；TranslationCallControls / CallControls 负责原样式与间距，控制回调和状态 owner 不变。不修改现有 ConversationAiContentNotice，保留输入区独立 12sp 灰色样式。

验证范围：两平台主题、小屏与大字下完整文字、换行、字体和对齐属性、真实上下间距及禁用状态；既有通话页面与无障碍回归。仅 Dart 展示变更，无原生改动，不构建安装或真实拨号。设备视觉验收另记，不能以 widget 测试冒充。

2026-10-27 附件样式修正：用户以截图底部说明为准，新增文字统一为接近截图的中性灰 #999999、系统字体常规字重（w400）、正常字体样式；不再继承任务挂断标签的白色粗体。字号仍为 9sp / 8sp，其余间距、对齐设置与换行保持。共享 AiContentNotice 统一颜色与字重；两个调用者继续提供各自字号。截图不能确定具体字体文件，使用 Flutter 平台系统字体。
