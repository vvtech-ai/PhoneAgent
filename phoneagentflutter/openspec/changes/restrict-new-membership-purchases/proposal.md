# 限制会员新购买资格

## Why
用户已确认仅新增购买限制、调整现有按钮和增加固定提示。现有同周期续购与低等级排队购买入口不符合目标，支付及VIP升级处理不变。

## What Changes
- 免费允许购买；付费仅允许更高等级或同等级更长周期。
- 同周期显示当前会员并禁用，允许升级显示升级会员，其余显示购买会员并按资格禁用。
- 按钮下增加：升级保留原会员时长，购买更长套餐可延长有效期。
- 原订单、履约、退款、计时、暂停恢复及其他UI保持不变。

## Impact
Flutter commerce domain/controller/offer；Java SDK commerce quote/order creation。无数据库、支付渠道、原生、共享编排规则变更。
