## ADDED Requirements

### Requirement: 登录表单保持当前行为规则
客户端 MUST 使用 v65 手机号清洗和 4–8 位数字验证码规则，不使用原型的模拟成功规则。

#### Scenario: 输入与提交长度一致
- **WHEN** 用户在登录验证码框输入或粘贴内容
- **THEN** 仅保留数字，最多输入 8 位；4、5、6、7、8 位数字均可通过本地格式校验，验证码真伪由服务端判断

#### Scenario: 验证码格式不合法
- **WHEN** 用户提交少于 4 位、多于 8 位或非数字验证码
- **THEN** 不调用认证端口并展示校验提示

#### Scenario: 发送冷却
- **WHEN** 发送成功返回手机号及冷却秒数
- **THEN** 只对相同标准化手机号阻止重发，并至少冷却一秒

### Requirement: 邀请码由后端结果决定
客户端 MUST 仅在端口返回 inviteRequired 时打开邀请码页面，有 challenge 时复用它且不重传旧短信验证码。

#### Scenario: 邀请与返回
- **WHEN** 邀请码页点击返回或系统返回
- **THEN** 回到可操作登录页，保留号码，后续登录不使用旧 challenge

#### Scenario: 页面退出后返回异步结果
- **WHEN** 邀请码提交未完成时返回登录，随后旧请求完成
- **THEN** 旧结果不得改变当前页面或制造认证成功状态

### Requirement: 缺少实现不能伪造认证成功
未接入数据适配 MUST 返回明确不可用错误，测试替身 MUST 仅用于测试入口。

#### Scenario: 尚未接入认证服务
- **WHEN** 用户输入合法数据并请求验证码或登录
- **THEN** 提示服务尚未接入且停留当前页面，不调用短信服务或进入假首页

### Requirement: 视觉与自动验证
页面 MUST 消费固定设计契约和真实 Logo，填满可用窗口并可滚动，不重绘系统栏；自动验收 MUST 覆盖两页和返回。

#### Scenario: 小屏或键盘可见
- **WHEN** 内容超出当前可用高度
- **THEN** 用户可滚动访问输入与提交按钮且不存在布局溢出
