## 已实施
| 环节 | 对齐结果 |
| --- | --- |
| 目录/入口 | model.pricePoints正整数报价，支持整数数字字符串；缺省/非正无报价，不回退300。已有候选查询和确认不依赖新建报价 |
| 模型绑定 | 生产Provider按不可变launch.model绑定认证仓库，初始化发送同一公开modelId，支持数字ID，不使用内部cloneModelId；认证仓库构造要求modelId |
| 准入/UI | 选择入口及认证/录音复用余额检查按同一报价；价格不可用阻止新建。模型积分标签及重新录制确认显示实际报价，整体布局未改变 |
| 候选创建 | 两条创建都发送X-Expected-Clone-Price-Points，认证生成幂等键为attemptId、无JSON请求体；录音生成保持本次稳定随机ID和原录音字段。401刷新保留报价/模型/幂等键 |
| 价格拒绝 | 固定业务消息映射priceChanged，提示返回刷新模型价格并重新确认，不自动重发或采用新价格；不误分类为身份失效/原提交结果未知 |
| 初始化错误 | 已知模型缺失、身份锁定、未完成提交等映射安全文案；未知失败用阶段友好提示，不输出内部initialization枚举或服务端原文 |
| 后续 | 查询、试听、确认/激活、保存/退出链路复核；确认显式activate=true，后台可选录音保存仍与激活独立，保存失败不回滚声音 |
| 诊断 | 保留网关逻辑路径识别、请求UUID/模型存在性；补价格变化和安全业务失败分类、动态准入状态。禁止身份/凭据/音频/receipt进入日志 |

AccountApi仅提供受限clonePricePoints参数，校验路径/方法/正整数；没有任意header注入。请求策略和录音生成ID按职责抽出，AccountApi498行、主流程495行。离线预览/旧测试明确注入合成300，不是生产默认报价。登录失效统一清理/跳转按此前要求仍未扩展。
