# 设计
默认非混音本地音频按模型块串行写入有界播放器，不再由Dart20ms定时逐帧取出。Android入队确认改为写入硬件缓冲完成，保持与原生WRITE_BLOCKING相同背压；play/drain仍等待实际播放。独立Dart isolate接管SDP已声明的UDP媒体端口（缓存端口、关闭原socket后原端口重绑），接收与发送不依赖UI事件循环；固定20ms单调时钟，无延迟追赶突发。保留主媒体160ms翻译预缓冲，工作线程加60ms调度抖动缓冲；欠载发静音，并调整后续序号/时间戳，DTMF走同一有序发送路径。生命周期关闭等待worker释放，失败不回退不同端口。原声混音规则保持。结构化导出记录固定数值统计（发送/填充/欠载/最大间隔/接收缺口/本地排队/削波），不记录地址号码音频。真实通话用户验收。

工作线程存活检查使用独立500ms owner心跳，提示音等待/模型暂未输出不会被误判为owner停止。停机后停止心跳并等待关闭确认；端口接管失败不更换SDP端口。启动前模型音频不播放。
