## ADDED Requirements
### Requirement: 填写信息须展示已认证脱敏身份并保留输入边界
Flutter MUST 在已认证且certNoMasked非空时展示已认证身份证脱敏提示，MUST NOT 将其作为完整身份证输入或认证请求参数。MUST 保留Flutter共用控件及弹窗样式。
#### Scenario: 已认证身份进入和编辑
- **WHEN** 已认证用户进入填写信息
- **THEN** 姓名锁定脱敏，脱敏身份证只读展示，完整号码输入框为空；聚焦编辑清除旧号码提示
#### Scenario: 空值及未认证
- **WHEN** 未认证或脱敏字段为空
- **THEN** 不展示已认证身份证提示，不伪造号码
### Requirement: 重置身份须安全完成删除与本地清理
Flutter MUST 提供重置身份确认，明确删除身份及全部克隆音色；删除成功清空表单并刷新音色、清理账号绑定认证录音；删除失败保留状态。MUST 防止重复删除与旧账号回调污染。
#### Scenario: 取消和失败
- **WHEN** 取消确认或删除失败
- **THEN** 取消不发请求，失败可见安全错误且保留原身份信息
#### Scenario: 已删除但清理失败
- **WHEN** 服务端删除成功而本地清理失败
- **THEN** 清空旧身份并允许仅重试本地清理，不重复DELETE，不允许旧录音继续复用
### Requirement: 姓名校验及脱敏重填须对齐有效业务
Flutter MUST 校验去空格姓名2至32字符；失败返回脱敏字段重新编辑时清空原值，认证姓名保持锁定；MUST 保留严格身份证校验。
#### Scenario: 无效姓名及重新编辑
- **WHEN** 姓名超范围或用户聚焦失败返回的可编辑脱敏字段
- **THEN** 无效姓名不发认证请求；编辑先清空原值再接收新输入
