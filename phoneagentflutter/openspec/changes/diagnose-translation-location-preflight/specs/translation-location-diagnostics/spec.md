## ADDED Requirements

### Requirement: 位置预检诊断
客户端 MUST 在实时翻译拨号入口和国内位置预检记录受限状态，包含真实、有效、实际读取位置及国家代码、模拟设置一致性和拒绝原因；MUST 不记录坐标、号码或凭证，诊断失败不得影响拨号结果。
#### Scenario: 国内预检拒绝
- **WHEN** 加载中、定位中、位置为空或国家不是CN
- **THEN** 导出日志可区分原因和两处位置状态，不修改既有提示及判断
#### Scenario: 导出往返
- **WHEN** 日志持久化并导出
- **THEN** 白名单字段保留，任意文本和未知字段丢弃
