## ADDED Requirements

### Requirement: 模型切换结果一致
系统 MUST 在设置页模型卡片切换成功后提示实际模型，失败时提示失败；重复选择当前模型或过期页面不得显示成功提示。

#### Scenario: 点击卡片切换
- **WHEN** 用户在设置页切换模型且保存成功
- **THEN** 展示“通话模型已切换为”及实际模型名称

### Requirement: 套餐明细沿用支付弹窗外观
系统 MUST 使用与会员支付一致的白底、圆角和边距，分组展示权益且保持可读可关闭。

#### Scenario: 窄屏或大字
- **WHEN** 用户打开套餐明细且内容超出可视区域
- **THEN** 内容可滚动，关闭按钮可见，分组无嵌套大卡片，无溢出

### Requirement: 忙碌辅助入口禁用并置灰
系统 MUST 让语音与文字模式下的 + 及模型入口在思考和回复时禁用并置灰，恢复时还原。

#### Scenario: 忙碌结束
- **WHEN** AI 思考、回复、停止或异常后恢复可交互
- **THEN** 辅助入口恢复正常颜色及点击行为，停止控制独立可用
