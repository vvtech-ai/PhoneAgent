## ADDED Requirements

### Requirement: 翻译详情必须支持精确身份的本地录音兜底
客户端 MUST 优先有效服务端录音，缺失时使用当前环境账号下与serverCallId精确关联的本地副本。归档成功响应 MUST 保存server/client关联供上传失败时恢复。客户端 MUST 验证私有路径、完整捕获和编码回执，不得按姓名号码猜测，不得因查看详情恢复电话或自动上传。
#### Scenario: 服务端缺少副本
- **WHEN** 详情无服务端录音且当前账号存在精确映射的完整本地录音
- **THEN** 显示录音卡片并支持加载播放、暂停、重试与保存，返回释放播放器
#### Scenario: 来源无效或账号变化
- **WHEN** 文件不完整、映射缺失或账号切换
- **THEN** 不播放其他记录；无来源隐藏卡片，旧账号响应不得更新新账号

### Requirement: 翻译详情必须对齐参考底部录音布局
详情 UI MUST 参照AIAssistant1/android的底部浮动录音卡片、渐变遮罩及字幕留白，保留大字体窄屏可操作性。
#### Scenario: 长字幕与录音共存
- **WHEN** 记录存在可用录音并滚动字幕
- **THEN** 录音控件固定底部且末条字幕可滚动到遮罩上方，播放与保存触摸可达
