# 设计

本地来源通过纯Dart端口隔离。映射只在已成功的国内归档响应后写入，按环境/API/账号和serverCallId散列定位；存储仅受控clientCallId，不保存token或任意路径。查询必须通过PrivateDomesticRecordingFiles解析并校验编码回执/校验和。完整原始日志可由现有finalizer恢复，不恢复麦克风/电话或自动上传。业务优先服务端录音，无服务端副本才查询本地；加载与重试均按当前账号隔离。

UI按AIAssistant1采用Stack底部浮层与144px渐变，字幕正常视口预留148px；窄屏大字体保留滚动兜底防溢出。元数据无效仍按参考隐藏，使用安全的解析拒绝原因诊断，不输出音频、凭据或真实字幕。既有历史无server/client映射需保留待验，不虚构关联。

验证：定向history/归档及直接调用方、分析、OpenSpec。设备仅保留数据操作；不卸载，不发起真实外呼或认证。
