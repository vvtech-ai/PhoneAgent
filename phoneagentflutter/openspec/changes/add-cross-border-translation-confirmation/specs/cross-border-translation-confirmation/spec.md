## ADDED Requirements
### Requirement: 跨境实时翻译必须二次确认
客户端 MUST 在实时翻译开启且有效主叫国家与所选被叫国家均已确定并不同时，在创建会话、计费或媒体准备前展示确认。国家比较 MUST trim及大小写归一，模拟国家 MUST 采用有效位置。
#### Scenario: 跨境确认
- **WHEN** 用户从拨号按钮或预设确认发起跨境实时翻译
- **THEN** 每次拨打只展示一次确认，点击仍要继续后才进入既有预检及准备
#### Scenario: 不适用跨境确认
- **WHEN** 普通电话、同国或国家缺失
- **THEN** 不展示跨境弹窗，保留既有号码和位置准入
### Requirement: 跨境弹窗复用Flutter共用风格
客户端 MUST 使用既有NativeConfirmationDialog，标题跨境通话质量提示，正文当前为跨境实时翻译通话，可能出现信号不稳定或延迟较大的情况。，按钮取消及仍要继续；布局和风格 MUST 不复制Android实现。
#### Scenario: 取消
- **WHEN** 用户取消、返回或关闭弹窗
- **THEN** 留在拨号页且无通话创建、媒体及计费副作用
### Requirement: 旧确认不得发起新通话
客户端 MUST 防止重复点击产生重复确认或外呼；确认期间页面、账号、号码、国家或配置变化后 MUST 拒绝继续。
#### Scenario: 失效后确认
- **WHEN** 弹窗打开期间拨号条件变化或页面账号失效
- **THEN** 确认结果丢弃，不创建通话
