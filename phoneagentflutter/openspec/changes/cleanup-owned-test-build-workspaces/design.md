# 设计

- 新增scripts/run-test-build.py命令入口和test_build_workspace.py生命周期模块。构建与平台验证均使用JSON参数数组，禁止shell拼接；占位符{workspace}/{repo}用于明确源码和工具路径，命令工作目录为本次临时目录。常驻配置及签名仍引用工程既有路径；隔离构建如需临时副本，由本次构建阶段从既有来源复制，随工作区清理，不建立新的常驻配置来源。
- 使用mkdtemp创建带时间和随机后缀的私有目录；所有权仅保存在当前进程，包含工程路径、目录设备及inode，不生成打包日志或所有权回执。没有接受任意旧目录的清理命令。
- 构建完成后捕获APK/IPA指纹，执行平台验证命令，之后再次校验指纹，防止验证期间产物变化。平台验证必须覆盖既有签名、版本、环境及供应商库等门禁，不能用空命令代替。
- 每个产物声明工作区相对源路径及交付文件名；拒绝绝对路径、父级越界、符号链接以及非APK/IPA或空文件。导出到deliveries独立目录，复制到临时文件后计算SHA256再原子重命名，全部确认完整后才清理。输出产物路径与SHA256到当前对话，不另存报告。
- 删除前重新核对.local父路径、目录前缀、设备及inode。只删除当前进程创建的目录；使用支持防链接攻击的rmtree，不支持的平台保留并提示，禁止扩大清理范围。
- 构建、验证、导出失败或KeyboardInterrupt均保留当前目录；清理失败不改成功状态，仅提示路径。后台子任务应由构建命令等待结束，禁止在返回成功后继续写入产物。
- 新增模拟命令端到端测试及安全失败测试，不修改业务代码、不以真实打包验证清理。旧临时目录不扫描、不接管、不删除。
