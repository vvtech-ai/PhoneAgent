# 成功交付后清理本次打包目录

## Why
用户批准test-build临时目录在成功构建、成包验证及完整导出后自动清理；失败或中断保留，禁止批量删除其他任务目录。

## What Changes
- 新增Android/iOS通用打包调度入口，管理自己新建的.local/test-build-*目录。
- 按构建、平台成包验证、原子导出及字节校验顺序执行，全部完成后清理所属目录。
- 路径越界、符号链接、身份替换拒绝；清理失败只提示残留目录，不撤销交付。

## Impact
既有固定Android脚本不创建test-build目录，既有iOS验证脚本不是交付入口；两者不被伪装成已包含完整成包验证。未来需要隔离目录的交付统一走新调度入口，平台实际构建及验证命令显式传入。既有历史目录、配置、签名、deliveries和主线程工作保持不动；本轮仅模拟验证，不打包安装、提交推送。
