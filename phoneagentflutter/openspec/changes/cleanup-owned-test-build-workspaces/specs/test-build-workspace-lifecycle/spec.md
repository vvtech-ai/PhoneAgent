## ADDED Requirements

### Requirement: 成功交付后清理本次目录
创建test-build隔离目录的打包调度入口 MUST 仅在构建成功、平台验证通过、全部产物完整导出至deliveries并校验字节一致后自动清理自己创建的目录；MUST NOT 扫描或删除历史及其他任务目录。

#### Scenario: 双端产物完整交付
- **WHEN** 本次APK/IPA均通过平台验证并成功导出
- **THEN** 删除本次临时目录，保留交付产物、常驻环境配置和签名

#### Scenario: 构建验证或导出失败
- **WHEN** 任一阶段失败或用户中断
- **THEN** 保留本次目录并返回失败，不执行清理

### Requirement: 清理须校验目录所有权和边界
调度入口 MUST 记录自己新建目录的身份，在删除前重新校验路径与身份；MUST 拒绝路径越界、链接逃逸或目录替换，且日志不得输出凭据。

#### Scenario: 目录身份被替换
- **WHEN** 原目录变成链接、位置越界或inode变化
- **THEN** 拒绝清理，不触碰链接目标及其他目录

#### Scenario: 清理失败
- **WHEN** 已交付完成但清理遇到权限或平台限制
- **THEN** 提示残留路径，交付仍保持成功，不扩大删除范围
