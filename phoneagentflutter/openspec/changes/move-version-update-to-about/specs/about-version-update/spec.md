## ADDED Requirements

### Requirement: 版本更新必须位于关于页面末项
系统 MUST 将版本更新入口及其页面业务装配从设置首页迁到关于PhoneAgent列表最后一项。首页 MUST NOT 订阅手动更新Controller或为此读取安装版本。

#### Scenario: 设置进入关于
- **WHEN** Android用户打开设置首页后进入关于PhoneAgent
- **THEN** 首页无版本更新，关于列表最后显示版本更新；进入页面不自动手动检查
- **AND** 关于顶部既有版本、日志及协议保持原行为

### Requirement: 更新入口必须匹配关于页面样式并显示状态
更新入口 MUST 复用关于页列表样式，无副标题和右侧版本号；右侧 MUST 默认空白，仅检查进行中显示检测中，检查中禁用重复点击。

#### Scenario: 点击及返回结果
- **WHEN** 用户点击版本更新并等待结果
- **THEN** 默认不显示右侧文本，进行中显示检测中，结束后恢复空白，只有一次请求；最新/失败按原提示显示，失败允许显式重试
- **AND** 有更新沿用原共享提示/安装链路，不自动下载，不把模拟或未验安装描述为真实升级

### Requirement: 更新迁移必须保持平台和页面生命周期边界
正式更新 MUST 仅Android提供，iOS MUST 不显示OTA或初始化其Controller。Web迁移预览 MUST 仅提供标明MOCK的隔离入口；关闭或被覆盖页面 MUST 不显示旧请求的晚到提示。

#### Scenario: iOS和离页
- **WHEN** 用户使用iOS关于页或检查中离开Android关于页
- **THEN** iOS保留顶部版本但无OTA；旧页回调不可在其他页面弹出手动结果
- **AND** 共享启动/强制更新安全规则继续有效，不因迁移取消全局门禁
