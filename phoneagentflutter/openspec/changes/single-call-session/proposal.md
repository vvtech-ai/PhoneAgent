## Why

2026-10-16 用户要求单呼准备完成后才显示通话页，并明确单呼通话页禁止返回，Android/iOS 一致。当前后端已有 launchReady，Flutter 未解码该字段，导致 REQUESTED 提前显示。此次增量接入服务端就绪门禁，保留共用 PopScope 返回限制，不新增返回按钮。录音由其他人处理，不在本次修改范围。

统一页已能读取确认与结果，但缺少单路通话控制状态层。不能把物理电话结束当作 Agent 任务成功，也不能用关闭页面代替挂断。按固定 v65 完成可共用的接口/状态生命周期，再接自动确认、通话页及媒体。

## What Changes

- 2026-10-16 实时字幕跟随修复：以实际展示的说话方和字幕内容作为滚动标记，覆盖只有实时推送、轮询快照文本未变的情况；修复后按用户要求构建并保留数据覆盖安装 dev 包。

- 迁移状态查询、明确挂断、监听票据三个已启用接口。
- 独立单路 controller 管理轮询、通话归属、过期快照、转写累积与结束后等待 Agent 结果。
- 为后续通话页面和统一对话编排提供共享状态；保留人工联调边界，不伪造媒体或真实通话成功。
- 补账号切换、取消、并发、失败与终态的合成验证和人工验收说明。

## Capabilities

### New Capabilities
- `single-call-session`: 单路通话状态、挂断与监听凭证边界。

### Modified Capabilities

无。

## Impact

新增 features/calls 的 domain/data/controller 与 app 装配。沿用 AccountApi，无新依赖，无原生/后端/数据库/提示词/SIP/ASR/TTS 改动。本批只用合成 API，禁止真实外呼/挂断和监听录音。自动确认/积分准入、正式通话页面、监听 WS/播放/音源以及终态与持久回执串联继续作为本变更剩余任务，不把接口基础等同完整通话模块。
