## ADDED Requirements

### Requirement: 实时字幕必须跟随实际显示内容
Android/iOS 单呼通话页 MUST 在实际字幕新增时于布局完成后跟随到最新字幕，MUST 覆盖只有实时推送而轮询快照未变化的情况。重复话语新增一行也 MUST 跟随；仅计时刷新或同内容轮询 MUST NOT 打断用户回看。已有字幕 MUST 保留可滚动回看。

#### Scenario: 纯实时字幕与连续长字幕
- **WHEN** 当前实时段落新增且快照原文为空或未变化
- **THEN** 最新字幕进入可见区域，较早字幕保留可回看

#### Scenario: 无新字幕时回看
- **WHEN** 用户滚动回看且仅计时或同内容快照刷新
- **THEN** 保持用户滚动位置，不自动归尾

### Requirement: 单呼页面必须等待服务端明确就绪
客户端 MUST 只在当前单呼状态明确包含 launchReady=true 时显示通话页，MUST NOT 把 callId、call_started、REQUESTED 或文字提示作为就绪证明。缺失或无效就绪字段 MUST 保持会话与只读状态观察；准备失败不跳页、不自动重拨。

#### Scenario: 准备完成前后
- **WHEN** 当前单呼已有 callId 但 launchReady 缺失或为 false
- **THEN** 保持会话；后续同一通话明确返回 true 且未结束时才显示通话页

#### Scenario: 准备失败
- **WHEN** 服务端返回 FAILED 或关闭状态
- **THEN** 留在会话读取结果，不显示通话页、不重拨

### Requirement: 双端单呼通话页必须禁止返回
Android/iOS 单呼通话页 MUST 在活动通话覆盖层显示期间禁止返回，不提供页面返回按钮。系统返回和边缘手势 MUST NOT 收起页面、关闭会话或发送挂断；状态观察 MUST 保持，明确挂断和服务端结束按既有流程处理。

#### Scenario: 返回尝试与持续观察
- **WHEN** 用户在单呼通话页触发 Android 系统返回或 iOS 边缘手势
- **THEN** 保持通话页与当前状态观察，不退出会话、不调用 hangup

### Requirement: 单路监听必须接真实只读媒体并共享生命周期
Flutter MUST 在当前单路明确点击时获取票据、连接既有监听WS并播放PCM；MUST NOT 采集麦克风、重拨电话或记录票据。静音MUST清空本地音频且丢弃静音期间帧，恢复沿当前连接；失败重连最多3次/800ms且仅当前可见有效通话允许。

#### Scenario: 关闭与迟到
- **WHEN** 页面退出、后台、账号/通话改变、物理终态或明确挂断
- **THEN** 停止监听并隔离在途票据/socket/播放回调；关闭失败保持音频保护，不因重连重新播放或发送hangup

#### Scenario: 音源与模拟
- **WHEN** Playing选择听筒/扬声器/可用蓝牙，或浏览器演练
- **THEN** 显示实际返回的路由状态，失败不假成功；演练复用共享媒体/状态/页面，仅外部输入合成且明确MOCK

### Requirement: 结构化失败和实时结果必须按归属协调
Flutter MUST 优先按服务端category/errorCode分类失败，只有无结构化信息时使用v65旧网络模式；MUST NOT 把模型超时等同网络故障或因retryable自动重发业务命令。实时结果MUST校验当前命令或已登记callId，不能让旧回执结束新观察。

#### Scenario: 确认期间失败
- **WHEN** 未登记callId时收到明确非网络失败，或已登记callId时收到失败
- **THEN** 前者收起本地通话并允许调整输入；后者继续观察；网络不明保留核实，均不自动重发或挂断

#### Scenario: 实时结果早于轮询
- **WHEN** 当前确认命令的终态单路final到达，或匹配callId的持久agentOutcome到达
- **THEN** 展示回执并清理本地观察，无需等待下一次REST；只有物理结束、普通final文本、RUNNING或其他命令/通话的结果不得触发收起

#### Scenario: 安全错误提示
- **WHEN** 错误详情含上游地址或敏感诊断
- **THEN** 仅按已知错误码显示安全文案，日志只记录分类及既有会话关联，不输出原始错误详情

### Requirement: 自动确认必须保留积分准入和一次性语义
Flutter MUST 对实时待执行请求延迟1500ms确认，新输入/恢复/关闭必须取消尚未提交的操作；历史恢复MUST NOT自动确认。同pending身份不得因重复事件、网络中断或轮询失败重发confirm_call。

#### Scenario: 恢复后的当前确认
- **WHEN** 历史具有可恢复pending makeCall且用户再次输入
- **THEN** 必须通过同账号/会话的确认alias判定已通知状态；只在已通知且当前不足时刷新再决定弹框或转发原输入。恢复自身不得确认、弹框、通知POST或触发余额刷新；已解决/不可恢复/非makeCall不重建门禁，也不禁止普通输入

#### Scenario: 首次及再次积分不足
- **WHEN** 已知余额低于模型首分钟点数乘以至少1路人数
- **THEN** 首次展示并记录不足消息；再次先刷新余额，仍不足返回弹框决定，未知余额交由服务端原子校验，不本地扣费

#### Scenario: 账号隔离与提示持久化
- **WHEN** 记录不足提示
- **THEN** 按环境/账号/会话隔离并使用v65稳定确认alias，不输出号码正文；幂等提示接口最多3次尝试，不给拨号确认自动重试

#### Scenario: 不足后的用户再次输入
- **WHEN** 当前确认已提示积分不足且用户再次提交输入
- **THEN** 必须先刷新准入；仍不足只弹框，不提交或回显第二轮用户消息，允许后才发送原输入一次；关闭或恢复后不得发送晚到输入

#### Scenario: 取消与不确定结果
- **WHEN** 延时/刷新期间请求已变更，或确认提交结果未知
- **THEN** 前者忽略晚到且不确认，后者保留待核验事实并只允许同步状态，不自动再次拨号

### Requirement: 通话请求必须绑定账号与目标
共享通话仓库 MUST 使用当前登录账号及明确taskId/callId调用既有状态/挂断/监听票据接口，MUST NOT 暗中重试业务POST或输出敏感响应。

#### Scenario: 目标或归属不匹配
- **WHEN** 目标为空、账号变化或服务端返回其他task/call
- **THEN** 拒绝请求或忽略结果，不操作其他通话

#### Scenario: 监听票据
- **WHEN** 已知callId后请求票据
- **THEN** 验证期限和音频格式，不把取得票据当作监听成功

### Requirement: 轮询必须受生命周期与新旧状态约束
共享controller MUST 隔离会话、停止后晚到响应及旧快照，避免重叠查询；终态和用户关闭后必须停止轮询。

#### Scenario: 呼叫尚未登记
- **WHEN** 尚无callId且查询返回NOT_FOUND
- **THEN** 继续等待查询，不推导电话失败

#### Scenario: 状态已结束但Agent结果未到
- **WHEN** 服务端返回需等待Agent结果的物理终态
- **THEN** 标记awaitingOutcome并通知编排器同步，不生成任务成功或伪回执

#### Scenario: 响应乱序
- **WHEN** 旧updatedAt、已结束通话的运行态或关闭后的响应到达
- **THEN** 状态和转写均不回退

### Requirement: 挂断与退出必须区分
MUST 只在明确挂断动作时调用hangup；关闭页面只释放本地观察，挂断失败不得假装电话结束。

#### Scenario: 重复点击或网络失败
- **WHEN** 挂断正在提交时再次点击，或请求失败
- **THEN** 不重复发送；失败保留通话事实并恢复状态查询，允许后续明确重试

#### Scenario: 退出页面
- **WHEN** controller关闭或销毁
- **THEN** 停止定时观察并忽略晚到响应，不调用hangup

#### Scenario: 结果同步与实时事件并行
- **WHEN** REST结果包含已有SSE事实，或读取期间又收到更新的SSE
- **THEN** 只允许同事件的时间戳精度规范化，保留更新事实；正文、归属、顺序冲突时原子拒绝，不覆盖已有消息

### Requirement: 单路页面和隔离演练必须共享交互语义
页面 MUST 保留模型、目标、号码、通话状态、转写和监听/挂断/音源；MUST NOT 新增旧接管、静音麦克风或多路单路化入口。演练 MUST 持续标识MOCK，且不得调用真实通话、媒体或账号接口。

#### Scenario: 音源选择
- **WHEN** 监听处于Playing
- **THEN** 可以打开音源弹层，包含听筒、扬声器，仅蓝牙可用时展示蓝牙；取消返回原页

#### Scenario: 连接失败或挂断失败
- **WHEN** 演练进入连接失败或挂断失败状态
- **THEN** 明确提示并允许显式重试，不假装播放/挂断成功

#### Scenario: 演练退出
- **WHEN** 关闭页面、系统返回或挂断成功
- **THEN** 清理本地观察/计时/模拟播放且回到来源；返回本身不发送挂断
