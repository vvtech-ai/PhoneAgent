## ADDED Requirements

### Requirement: 海外准备诊断
客户端 MUST 记录语言加载、会话创建、媒体准备、拨号启动和清理阶段及受限错误码、HTTP状态；失败 MUST 保留实际失败阶段，不得被统一提示覆盖。诊断 MUST 不影响业务结果且不包含号码、凭证、URL或原始消息。
#### Scenario: 准备失败
- **WHEN** 语言、创建或媒体阶段失败
- **THEN** 导出可识别失败阶段、白名单错误和可用的HTTP状态
#### Scenario: 媒体降级
- **WHEN** 媒体候选失败后尝试下一个候选
- **THEN** 记录失败候选类型而不改变既有降级行为

#### Scenario: 创建请求被拒绝
- **WHEN** 创建接口返回非2xx
- **THEN** 记录固定错误分类、响应结构和固定字段标记，不记录服务端消息或请求值，不改变重试行为
