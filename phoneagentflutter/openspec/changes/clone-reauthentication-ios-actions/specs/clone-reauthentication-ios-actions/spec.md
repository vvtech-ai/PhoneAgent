## ADDED Requirements

### Requirement: 重新认证确认必须使用局部iOS按钮区域
“重新认证并克隆音色？”弹窗 MUST 在两端共用左取消、右继续重新认证的等宽居中系统蓝按钮，以横向细线分隔正文和动作区，以竖向细线分隔两按钮；继续动作 SHALL 稍加粗并使用Cupertino按压反馈。

#### Scenario: 普通和放大字体
- **WHEN** 此弹窗在Android或iOS窄屏、短屏或大字体下展示
- **THEN** 两按钮保持横向等宽，文字允许换行且自然增高，触区至少48高，动作可读可操作
- **AND** 原有标题/正文/弹窗形状/遮罩与模型面板不变，其他确认弹窗不受影响

### Requirement: 按钮展示不得改变认证准入与导航
本次展示调整 MUST 保持取消、遮罩和系统返回不启动认证，继续返回原有确认结果且走既有业务；动作 MUST 只关闭仍存活且当前的自身弹窗，并阻止重复完成。

#### Scenario: 取消与继续
- **WHEN** 用户取消后重新选择已有克隆模型并继续
- **THEN** 取消保留模型选择，继续进入原有完整认证流程，不新增认证、上传或收费调用

#### Scenario: 陈旧或重复动作
- **WHEN** 同一动作重复执行，或弹窗已销毁/被另一页覆盖
- **THEN** 不误关闭来源页或覆盖页，不重复推进流程
