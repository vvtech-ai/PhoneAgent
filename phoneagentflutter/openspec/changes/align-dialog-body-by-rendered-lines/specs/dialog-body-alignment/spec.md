## ADDED Requirements
### Requirement: 正文按实际渲染行数对齐
四类弹窗正文 MUST 根据实际宽度、字体、字体缩放及换行排版；单行居中，多行整个正文区域左对齐。标题、按钮、手机号、输入及错误提示 MUST 保持原展示，注销入口标题 MUST 居中。
#### Scenario: 单行与多行
- **WHEN** 正文实际排版只有一行或超过一行
- **THEN** 系统 MUST 分别居中或整段左对齐，字体放大/宽度变化后重新计算
#### Scenario: 协议与输入
- **WHEN** 正文含协议链接或弹窗含确认输入
- **THEN** 系统 MUST 保留链接点击及IME和确认身份门禁，正文对齐不影响交互
