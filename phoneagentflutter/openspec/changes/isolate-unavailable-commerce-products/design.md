# 设计

用户追加批准：clone.enabled=false是正常等级不支持，升级文案目录是可选补充，不能因目录失败转成读取失败。入口保持当前权益/可信legacy的错误重试与账号守卫，正常不支持弹窗说明当前等级、主操作为查看会员权益；仅列出可信目录中更高且支持的等级，无结果时使用通用权益说明。只修改clone gate/dialog与直接测试，不改实际授权或价格。
用户2026-10-16最新决定覆盖早期零分拒绝方案：Java SDK CommerceSalePolicy.discountedFen对正整数原价和1..10000bps合法折扣按整数分向下取整后保底1分，允许正常购买；原价<=0和非法折扣（包括0折）仍拒绝，不新增免费支付或发布阻断。目录、offer、quote及新订单复用后端最终金额，真正PRODUCT_UNAVAILABLE仍逐商品隔离，其他错误继续上抛。会员配置价不变。
Flutter CatalogController分别保留并发目录/会员读取结果及账号/代次保护；CatalogState沿现有接口提供可展示商品，正常不可售购买项隐藏，价格计算不搬到APP。MembershipPage将当前会员信息与目录独立渲染，错误使用底部轻量重试；PointsPurchasePage使用相同可售筛选。新增小策略/组件仅在职责确需拆开时使用，不扩大已有大页面职责。
真实错误不得被误判为目录空成功；会员读取失败时不得给出过期授权或允许购买。目录部分失败隔离只针对明确PRODUCT_UNAVAILABLE，不能吞认证/配置/系统异常。
当前验收：后端两个1分包合法9折后仍正常购买，目录/offer/quote/新订单均为1分，3000分包仍为2700分。Flutter仅补直接页面金额断言：后端1分显示¥0.01、不二次打折，原价等于实付不虚构9折或节省。iOS继续展示并支付StoreKit实际SKU价格，不以业务参考价改写。早期RED/GREEN保留为历史证据，不作为当前最低实付规则；本次不签包或设备操作。
