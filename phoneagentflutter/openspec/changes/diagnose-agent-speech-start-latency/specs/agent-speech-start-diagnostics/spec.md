## ADDED Requirements

### Requirement: 普通正文首声诊断与真实播放 trace 关联

系统 MUST 在普通 Agent 正文首个可播句子入队时，使用该实际播放流的 trace 记录一次首个非空正文观测与首句入队；原始观测时间及单调耗时必须保留，不得用补记时间冒充原始时间。诊断不得包含正文、号码或凭据。

#### Scenario: 多个正文 delta 组成首句
- **WHEN** 同一轮先收到不完整正文，随后收到句末标点及其他句子
- **THEN** `textObserved` 保留最初观测时间，`sentenceEnqueued` 只记录一次并使用单调耗时，且与现有 connect/send/receive/PCM 事件共享 trace

#### Scenario: 取消与跨轮隔离
- **WHEN** 正文尚未入队即中断，随后开始新轮，旧事件迟到
- **THEN** 取消轮次不补记语音观测，旧事件由现有流所有权检查拒绝，新轮的观测时间和 trace 不继承旧轮

#### Scenario: 历史与无可播文本
- **WHEN** 恢复历史、接收空正文或只含清理后无内容的 Markdown
- **THEN** 不生成普通正文首句入队诊断，不新增合成或播放动作

### Requirement: 诊断不改变语音行为

系统 MUST 保持既有分句、计时、缓冲、合成和播放动作顺序；诊断失败不得阻断语音，也不得新增网络请求。

#### Scenario: 诊断存储异常
- **WHEN** 诊断 sink 或观察者抛出异常
- **THEN** 原正文仍按原顺序发送合成并播放，失败不暴露敏感异常文本

#### Scenario: 解释观测边界
- **WHEN** 分析新日志
- **THEN** 文档明确入队并不代表已开口，旧缓冲不作为新回归根因，仍需新现场日志确认实际等待阶段
