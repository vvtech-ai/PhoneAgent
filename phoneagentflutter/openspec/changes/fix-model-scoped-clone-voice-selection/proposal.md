# 修复按模型选择克隆通话音色

## Why
用户反馈通话声音sheet中未选中的我的克隆音色无法设为选中。Flutter仍读写全局音色端点，已有克隆选择没有采用当前Android的模型级activate流程。

## What Changes
- 按弹窗公开modelId读取音色，激活已有克隆后按同模型重读。
- 切回系统音色按同模型停用克隆、重读并按需更新；不将部分成功当作保留原选择。
- 保留候选确认独立路径、既有布局和等待控件，结果不明只读同步。

## Impact
仅call_models data/controller及定向测试；不改主线程并行的克隆创建/原生模块，不提交推送，不真实认证或外呼，不改登录失效提示。
