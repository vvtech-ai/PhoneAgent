# 单路与批量自然语言确认统一语义判断

## Why

批量固定话术把“确定。”误判为修改，单路本地后缀可能提前授权。用户于 2026-10-28 批准统一语义判断并要求保留正常执行流程。

## What Changes

- 单路自然输入全部交给既有语义分类接口，本地不再按文案授权或覆盖意图。
- 保留卡片可见性、账号/session/tool/内容签名/代次和重复提交门禁。
- 提问、暂缓、含糊或分类失败保留当前卡及补充历史；批量由 Java 同一语义能力处理。
- 明确按钮、准备倒计时、准入、停止、结果、TTS 保持原职责。

## Impact

影响 conversation 确认交互与相应测试；不改平台、依赖、数据表或现有 API decision/answer 字段。
