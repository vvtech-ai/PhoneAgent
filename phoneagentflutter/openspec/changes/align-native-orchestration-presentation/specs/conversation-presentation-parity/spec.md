## ADDED Requirements

### Requirement: 合并远端修复时保留有效交互与生命周期
Flutter MUST 保留远端当前返回、确认门禁与权限续接规则。系统临时失焦 MUST NOT 取消当前回复的后续播报资格，真实后台 MUST 取消旧播报；新增实时字幕 MUST 立即跟随并修正长行布局，计时刷新 MUST 保持回看位置。有效系统音色ID MUST 可使用既有动态试听，加载、保存与待刷新仍禁用。

#### Scenario: 权限弹窗与后台分离
- **WHEN** 系统弹窗触发inactive后恢复，或随后进入真实后台
- **THEN** 前者保留当前回复播报资格并等待前台续接，后者放弃旧权限续接和播报

#### Scenario: 字幕与音色远端规则保留
- **WHEN** SSE新增字幕或目录返回有ID但无URL的音色
- **THEN** 字幕立即跟随至底部且计时不拉动回看；音色可调用动态试听且不改变选择

### Requirement: 展示协调使用真实身份与内容类型
Flutter MUST 仅以同类型、同命令/工具身份的账本消息替换实时覆盖；同 pending tool 的确认卡及同 attempt/batch 的回执 MUST 复用已有卡。不同工具、不同用户轮次相同文字 MUST 保留。

#### Scenario: 正文与交互卡并存
- **WHEN** 同轮已有账本补问或候选卡，实时仍有独立正文或另一工具候选
- **THEN** 正文与不同工具的候选正常展示，同工具的实时交互覆盖只出现一次

### Requirement: 卡片更新保持首次展示位置
同文件或同工具交互卡 MUST 原位更新，迟到实时文件 MUST 插在原命令旁，不得追加到后续用户轮次之后。

#### Scenario: 文件更新与历史重放
- **WHEN** 文件首次出现后已有后续用户轮次，同文件的新事实到达
- **THEN** 文件内容更新但原位置不变，实时与历史恢复展示相同

### Requirement: 候选列表按同轮语义协调
客户端 MUST 在同一真实用户轮次中合并通用候选列表与描述相同候选的正文，以及相同标题的无身份候选副本；两个明确且不同的工具身份 MUST 保留。同名联系人 MUST 使用号码尾号区分，缺失身份 MUST NOT 导致跨用户轮次合并。

#### Scenario: 通用列表与描述正文
- **WHEN** 同轮结构候选卡与带序号的正文描述同一组候选
- **THEN** 保留一份结构候选；后续用户重新查询仍保留新一轮列表

#### Scenario: 同名不同号码
- **WHEN** 同名联系人的候选号码尾号不同
- **THEN** 不因姓名相同合并为同一候选组

### Requirement: 确认卡身份缺失与跨轮历史保护
同轮双方都没有工具ID时 MUST 按确认内容判断同卡，并兼容timeline fallback ID；明确不同的真实ID MUST NOT 合并。相同pending工具跨真实用户轮次重复时 MUST 保留原确认快照，后一轮只去掉重复确认而保留独立正文；同轮的原位更新继续有效。

#### Scenario: 无ID实时历史重合
- **WHEN** 同轮实时和历史确认内容相同且都缺少工具ID
- **THEN** 只显示一张确认卡，后续用户轮次的相同内容仍按新交互保留

#### Scenario: 后轮重复同pending工具
- **WHEN** 新用户消息后再次出现同pending工具确认，其内容有变化
- **THEN** 旧卡不被新内容改写，新一轮独立正文继续显示

#### Scenario: 旧快照与待执行内容不同
- **WHEN** 旧卡与当前请求工具ID相同但确认内容不同
- **THEN** 旧卡保持历史展示，不显示当前确认提示，不上报当前请求已呈现

### Requirement: 实时与恢复使用一致的去重规则
实时与历史恢复 MUST 共用展示归一化。同轮同身份卡 MUST 只出现一次；专业通话/文件卡 MUST 替代同身份通用轨迹；同轮相同结构卡正文 MUST 不再重复展示为普通助手文本。普通工具轨迹结束后收起，持久交互白名单保留。

#### Scenario: 结构卡、正文及轨迹并行到达
- **WHEN** 同轮同工具的结构卡、通用轨迹及相同正文以不同顺序到达
- **THEN** 专业卡和正文各按有效身份展示一次，不误删其他工具卡或后续轮次的问题

### Requirement: 同次通话有效字幕保留录音展示锚点
同 attempt 终态协调时，客户端 MUST 以账本状态和结果正文为准；当账本 transcript 仅包含普通结果说明而实时回执包含可解析对话时 MUST 补用该真实对话，保留媒体门禁，不得借用其他通话字幕。

#### Scenario: 普通结果说明挡住真实字幕
- **WHEN** 账本通过旧 detail 兜底得到非对话 transcript，同次通话实时回执有有效对话及录音 callId
- **THEN** 状态和正文保留账本值，字幕使用同次真实对话，录音入口继续按现有门禁判断
