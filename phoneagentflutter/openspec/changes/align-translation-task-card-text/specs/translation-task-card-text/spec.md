## ADDED Requirements

### Requirement: 实时翻译任务必须按通话身份展示标题和时长
客户端 MUST 保留分页身份及顺序，并以callId匹配实时翻译历史。匹配成功时标题 MUST 为“实时翻译 · 联系人或号码”，清理“拨打 ”和“翻译通话 ”前缀与占位名称。时长 MUST 优先durationMillis，其次合法已有时长文本，最后有效起止时间差；负时长按零展示。未匹配历史 MUST 保留任务标题。
#### Scenario: 历史匹配与缺失时长
- **WHEN** 翻译任务存在同callId的实时翻译历史且任务durationMillis缺失
- **THEN** 使用匹配历史补充标题和可用时长，其他记录不得被串改
#### Scenario: 历史不可用
- **WHEN** 历史网络失败或者没有匹配记录
- **THEN** 保留任务分页并使用已有时长文本或有效起止时间差兜底，账号切换及失效错误仍上抛

### Requirement: 实时翻译任务第二行必须对齐历史时间展示
客户端 MUST 在匹配实时翻译历史时使用其通话日期和开始时间生成本地相对时间，缺失时使用历史发生时间；无有效历史时间时按Android展示“刚刚”。无匹配历史或历史不可用时 MUST 沿用任务detail，不再统一替换为任务createdAt或updatedAt。
#### Scenario: 匹配通话时间
- **WHEN** 任务匹配到同callId的翻译历史
- **THEN** 第二行展示历史通话时间，保留任务原始起止时间及分页身份
#### Scenario: 无历史回退
- **WHEN** 历史缺失或加载失败
- **THEN** 第二行展示任务detail原文，包括空值，不自动替换为任务创建时间
