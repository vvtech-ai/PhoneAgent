# 验证记录

2026-10-12，用户确认执行后完成标题、时长及第二行时间对齐。

## 实现
- 任务分页和置顶更新遇到实时翻译记录时，读取已有api/task/call-history，按callId且限定实时翻译场景匹配；保留权威分页身份、顺序、权限和原始任务时间。
- 历史标题按Android前缀及占位名称规则映射，缺少匹配时保留任务标题。
- 时长优先任务durationMillis，缺失时补历史durationMillis；仍缺失则已有合法时长文本、有效起止时间差依次兜底。
- 第二行匹配历史时显示其开始时间的本地相对时间，缺失则用历史发生时间，再缺失显示“刚刚”；没有匹配或历史失败时使用任务detail原文。
- 布局、颜色和点击入口不变。无翻译记录不额外请求历史。账号切换/失效错误上抛。
