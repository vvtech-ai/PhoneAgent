## ADDED Requirements

### Requirement: 历史号码回填必须同步国家默认对方语言
统一拨号页选择可回填历史号码时 MUST 恢复有效历史我方语言，并按号码国家的当前目录默认语言重置对方语言；不得使用历史对方语言覆盖国家规则。回填 MUST 保留当前翻译开关、模型、提示及另一模式国家，沿用现有 Flutter UI 和共用控件，不自动拨号。

#### Scenario: 翻译模式选择历史号码
- **WHEN** 选择有效历史号码，历史我方语言仍受目录支持
- **THEN** 回填号码、姓名、翻译模式国家和历史我方语言
- **AND** 对方语言使用所选国家当前目录默认语言，即使当前国家未改变

#### Scenario: 普通模式或历史缺少有效我方语言
- **WHEN** 普通模式选择历史号码，或历史我方语言为空或已失效
- **THEN** 普通模式也更新当前模式国家及对方默认语言
- **AND** 无效我方语言不覆盖当前我方语言，其他配置保持不变并通过现有偏好存储保存

#### Scenario: 无法回填号码
- **WHEN** 历史号码不可选择或解析失败
- **THEN** 不执行语言回填，不发起通话
