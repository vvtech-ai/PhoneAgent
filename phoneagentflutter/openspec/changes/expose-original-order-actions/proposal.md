# 显式查看原单及真实订单名称

## Why
用户实际支付未完成，订单列表固定操作列只显示禁用“—”，虽然左侧整行可打开原单，但入口不可见。ALIPAY显示为“移动支付”，会员类型也缺少原订单真实等级/单次周期。

## What Changes
- 非已完成付费订单显式提供查看订单入口，包括PENDING/PROCESSING及已付履约异常；不自动续付或新建订单。
- nullable会员等级/周期从后端原购买快照消费，缺字段保留历史商品名，不按名称猜。
- 明确ALIPAY为支付宝，会员显示初级/中级/高级会员及包月/包季/包年，单次购买不声称自动续费。
- 保留已完成订单发票入口及订单原状态/恢复查询规则。

## Impact
commerce domain/data可选订单字段、独立展示helper/操作widget和订单列表；SDK生产字段由主代理处理。原卡片UI、目录泛型修复、模型诊断不改，不构建/安装/提交。
