## Why

测试反馈实时翻译拨号页的联系人、历史号码回填后没有切换国家默认语言，部分操作提示和旧版 1.6.0 不一致。重新对照 Flutter `codex/dev@e4d52499` 和 Android `feature/test_v1.6.0@8f23592`，确认语言优先级、短提示、国内通话、权限记忆及小屏转写存在遗漏。

## What Changes

- 联系人和历史回填按号码国家选择默认对方语言；用户明确覆盖之前保留历史对方语言的决定。
- 语言组合按当前模型支持范围规范化，国际号码使用实时目录，首次我方语言结合主叫国家。
- 开发者及通话瞬时反馈使用旧版文案和短 Toast，消费已展示的拨号消息。
- 对齐国内默认扬声器及对应 DTMF 展示；按用户澄清保留拨前积分说明，结束后仅使用积分 Toast，不增加结束账单页面。
- 持久保存权限解释/申请标记；小屏大字号也跟随最新转写。

## Capabilities

### New Capabilities

- `translation-160-interaction-parity`: 约束本轮旧版实时翻译交互补齐及跨平台回归。

### Modified Capabilities

无主规格修改；本次新增聚合验收规格。历史回填的新决定优先于 `restore-valid-history-peer-language` 变更的旧决定。

## Impact

仅修改 Flutter 的翻译、拨号、开发者展示及本地偏好接线，不变更 Java API、数据库、供应商价格、签名或认证契约。保留旧版需要的号码格式/跨境确认框。断网重连处理仍按用户决定暂缓。验证包括失败用例、定向回归、静态检查、测试环境 Release 签名 APK；真实外呼和 iOS 音路仍需设备验收。
