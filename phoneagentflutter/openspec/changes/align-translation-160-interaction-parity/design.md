## Context

本次在已有 `codex/dev` 工作树上修复，旧 Android 1.6.0 只读。国家目录、语言目录、模型支持和真实结算已有后端字段，客户端未完整使用。国内与海外通话共用页面及既有终态短提示、自动返回流程。

## Goals / Non-Goals

目标：按旧版恢复号码语言联动和交互，Android/iOS 使用共享规则；修复有证据的遗漏并覆盖生产入口。
不处理：断网重连、供应商音质、后端权限及计费计算、真实外呼测试、发布上线。

## Decisions

1. 新增纯语言规范化策略，SetupController 只负责状态与偏好保存。拨号入口提供定位上下文，避免 setup/access provider 循环依赖；相同结果不重复保存。
2. 联系人解析接收实时国家目录，保留无目录调用的兼容路径；入口为联系人、历史和外部号码统一传参。
3. 使用现有共享 Toast 展示瞬时反馈，按消息值消费拨号状态，避免切换模式后旧消息再次显示；保存失败的重试入口继续可见。
4. 按用户澄清恢复拨前积分说明，文案格式化和组件分别负责价格呈现与布局；使用现有目录报价，不重复乘模型倍率，未取得完整报价时显示旧版兜底。结束账单页不恢复，不改变既有计费契约。
5. 国内、海外结束均复用共享 route 的短 Toast 和自动返回。只有已有真实正数结算产生积分 Toast；失败提示同样短暂展示，不伪造扣款成功。
6. 权限记忆通过独立本地存储适配器保存，只记录解释/申请标记；每次使用仍查询系统真实授权。保存按现有偏好队列串行，账号变化终止旧回调但不清设备标记。
7. 小屏复用已有转写跟随组件，国内默认音路和控制显示同步，不创建第二套转写算法。

## Risks / Trade-offs

- 恢复历史语言与此前决定相反 -> 以用户本轮明确选择为准，更新相关测试和记录。
- iOS 与 Android 存储实现不同 -> 使用 AppLocalStorage 既有适配，测试双平台 UI，真实 iOS 音路待设备验收。
- 提示随页面返回消失 -> 沿用根 Overlay 提示队列，页面自动返回后继续短暂展示，重复终态事件只处理一次。

## Migration Plan

无需服务端迁移。新增设备偏好键按环境隔离；无标记保持首次解释行为。交付测试环境 1.0.52（45）登记签名 Release。

## Open Questions

真实外呼音路、对端 DTMF、供应商结算和录音完整性需要真机验收，不能用组件测试代替。
