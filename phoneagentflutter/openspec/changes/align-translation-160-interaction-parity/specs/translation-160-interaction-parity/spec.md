## ADDED Requirements

### Requirement: 号码回填优先国家语言

系统 MUST 在搜索联系人、外部号码、历史记录回填时按号码国家选择默认对方语言，并按模型支持范围规范化双方语言。历史保存的我方语言在受支持时保留，对方语言以号码国家优先。

#### Scenario: 日本号码覆盖历史英语
- **WHEN** 用户选择日本号码，当前或历史对方语言为英语
- **THEN** 对方语言切为日语；即使国家原先已经为日本也执行同步

#### Scenario: 模型或目录变更
- **WHEN** 当前语言不受新模型支持或双方语言相同且有替代语言
- **THEN** 选择支持范围内的默认语言组合，并避免同语

### Requirement: 操作反馈使用短提示

系统 MUST 对拨号校验、开发者操作和通话瞬时失败使用短 Toast，已展示的拨号消息不应在切换模式后常驻。需要重试的配置保存错误仍保留重试入口。

#### Scenario: 模型切换失败
- **WHEN** 开发者切换翻译模型失败
- **THEN** 显示旧版明确失败文案并在约二至三秒后消失

### Requirement: 拨前保留积分说明且结束使用短提示

系统 MUST 在开启实时翻译的拨号页显示当前模型的积分报价和未接通不扣说明，未取得完整报价时使用旧版兜底，关闭翻译时隐藏报价。系统 MUST 保留现有积分 Toast，不增加国内结束账单页面。国内与海外通话结束后自动返回，失败原因及真实结算结果通过共享短提示展示，重复终态事件不得重复提示。

#### Scenario: 拨前查看当前模型报价
- **WHEN** 用户开启实时翻译并选择有完整报价的模型
- **THEN** 显示目录给出的首段和后续周期报价，不重复应用模型倍率，关闭翻译时隐藏说明

#### Scenario: 国内结算已确认
- **WHEN** 国内通话结束且服务端确认有真实正数扣款
- **THEN** 自动返回拨号页，并短暂展示实际扣款和余额 Toast，不停留在新增账单页

#### Scenario: 国内结算未确认
- **WHEN** 国内通话已停止但没有确认结算
- **THEN** 不伪造扣款成功或新增积分展示，已有结算错误通过短提示告知并返回

### Requirement: 权限解释记忆与系统授权分离

系统 MUST 持久保存解释和请求标记，并继续以系统授权查询作为权限证据。开发者重置位置标记不清除请求通话记录标记。

#### Scenario: 重新启动
- **WHEN** 用户此前拒绝过权限后重新进入应用
- **THEN** 首次解释与一次性通话记录申请不重复，但显式开启翻译仍可继续授权流程

### Requirement: 通话控件及小屏跟随

系统 MUST 对齐国内默认扬声器和国内普通 DTMF 展示，保持海外控件行为，并在小屏大字号布局跟随最新转写。

#### Scenario: 小屏更新最后一段转写
- **WHEN** 大字号或小屏进入紧凑布局且最新段落追加文本
- **THEN** 最新文本保持可见，且无布局溢出
