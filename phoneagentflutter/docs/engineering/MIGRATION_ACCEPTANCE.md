## 完成定义（2026-09-16 用户目标）

1. 优先复用已有安卓测试会话，避免反复短信；无法复用时才请用户提供一次验证码。
2. Web 完成批准范围内所有页面、状态和导航；需人工输入/外部设备的环节可以显式 mock，但必须列出范围，不能把 mock 当真实实现。
3. 阶段性在 Android/iOS 真机安装检查效果；不是全部页面结束后才第一次对齐。
4. 实现需人工验证的真实能力，优先 Flutter 共用；仅平台接口差异进入薄适配层。安卓参考固定 v65；iOS 参考 `origin/iOS_newui2`（当前证据 ddb996a28f98559ea7d8b76ca9d7712703dedbc1），不得覆盖已批准产品基线。
5. 交付逐项说明：实现位置、共用/原生边界、mock 开关、真实接入状态、自动验证、人工步骤/预期/失败日志。用户最后集中做人工验收；不能用“待接入”占位替代应完成实现。

本文件是目标清单，不是完成报告。详细范围由 `docs/requirements/MIGRATION_BASELINE.md` 和旧项目迁移盘点 01–14 共同约束。
