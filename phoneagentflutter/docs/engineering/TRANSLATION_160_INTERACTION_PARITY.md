# 实时翻译交互对齐 1.6.0

## 基线与职责

本轮 Flutter 基线 `codex/dev@e4d52499`，只读 Android `feature/test_v1.6.0@8f23592`。Java 接口、数据库和计费计算不变。详情见 `openspec/changes/align-translation-160-interaction-parity/`。

## 语言和号码

- 联系人搜索、历史和外部号码由 `translation_dialer_inputs.dart` 接入 `DialerController`，使用实时国家目录。目录尚在加载时等待，加载失败允许既有普通号码能力；目录恢复后只重放未被用户编辑的初始号码。
- 历史保留受支持的 caller，peer 按号码国家默认语言重算。用户 2026-10-20 明确选择此规则，覆盖此前 `restore-valid-history-peer-language` 的决定。
- `translation_language_policy.dart` 处理模型方向支持及避同语。空 source/target 列表遵循现有契约表示不限；显式手选同语仍由拨号前既有校验拦截。
- 新安装的 caller 使用空值标记尚未选择，定位到主叫国家后选择默认语言；持久化明确空值，避免无关开关保存后误当手选中文。已有合法手选继续保留。

## 提示和通话

- 瞬时拨号消息展示后按值消费；开发者失败、定位模拟失败、重置权限和通话操作失败采用共享短 Toast。配置保存失败继续保留重试入口。
- 用户澄清保留拨前积分说明、仅删除结束账单页。独立 `translation_dial_pricing.dart` 使用当前目录报价，不重复乘模型倍率，缺少完整报价显示旧版兜底；关闭翻译时隐藏。结束后沿用既有积分、结算 Toast；后端价格和计费计算不变。
- 国内、海外终态均自动返回拨号页，根 Overlay 继续显示一次失败原因及已确认的真实扣款 Toast，缺少结算结果不伪造扣款成功。
- 国内默认免提，PCM 启动之后、欢迎语之前应用音路；保留用户预接通选择。国内使用普通 DTMF 反馈，海外增强反馈保留。
- 小屏和大字号复用已有转写组件及最新文本跟随，不复制滚动状态机。

## 权限标记

`SecureDialPermissionStore` 通过现有 `AppLocalStorage` 适配 Android/iOS，按环境和 API 地址保存解释/申请标记。每次仍查询系统实际授权，不把标记当授权。模拟定位同样先等读取完成；写入立即登记现有偏好队列，避免账号切换读取越过待保存内容。开发者重置位置标记时保留 CallLog 标记。

## 验证边界

已为关键行为观察修复前失败，新增覆盖双端 JP 联系人/历史/外部入口、目录延迟、语言模型范围、短提示消失、国内终态 Toast、自动返回和小屏转写。真实电话、对端 DTMF、供应商最终结算、蓝牙及 iOS 音路仍需真机验收。用户暂缓的断网重连逻辑未调整。

固定 HEAD `e4d52499` 临时快照独立复现 12 项既有失败：国内质量 3 项、国内模型面板 6 项、地区预览页 2 项、UDP 收包 1 项。偏好页面在基线通过，本轮发现的模型支持 fixture 缺少德语已按持久化测试意图补齐，不能归为既有失败。
