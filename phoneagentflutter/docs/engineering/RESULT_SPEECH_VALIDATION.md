## 依据与边界

固定 Android v65 `4c781e3ccfcd148c1f205921534907ee0c5aa864` 的 `AgentStreamCommittedReplyNarrationCoordinator`、`TimelineSnapshotUiProjection.terminalReceiptSequence/taskResultReplies`：

- 结果信号与已验证的 `ASSISTANT_TURN_COMMITTED`、已应用消息投影关联；正文取持久消息，不取瞬态 `final.text`。
- 普通/批量分别匹配 `call_result` / `batch_call_result`，身份优先 metadata.callAttemptId、metadata.callId、batchId，缺省沿源实现的类型/状态/正文组合；不记录正文。
- 实时 commit 路径要求对应持久助手消息可见；缺失实时 commit 的只读补齐路径，匹配回执身份和终态投影锚点，选择其后最新匹配结果回复。锚点沿既有回执投影，不擅自改成“收到数据的时间”。
- 新轮清空等待关系，已播事件和已消费终态各保留最多128条。恢复历史不启动这一关联器。异会话、未应用、瞬态消息、空正文不播。
- 单路页占用音频时暂停普通播报，保留当前结果关联；返回对话且门禁允许后播报。用户打断、后台、关闭、恢复历史则作废等待，不因晚到结果重开声音。
- 前一队列已封口但未排空时，结果等实际消费后才建下一队列；输出故障作废等待结果，不自动重试。结果播报仍沿既有固定音色、Markdown清理与PCM播放端口。

## 集中人工验收（尚未执行）

1. 单路：真实授权通话结束后先等待结果，回到对话才播；正文与最终助手消息一致，不朗读工具JSON或瞬态占位。
2. 批量：结果留在统一页播报一次，重复网络事件或只读同步不重复播；逐项回执交互不受影响。
3. 时序：结果比commit先到/后到、结束后网络恢复、前句尚未播完；次序正常，不截断/重叠、末尾不丢。
4. 打断：播报中按住输入、后台、关闭、切账号、从任务列表恢复；旧结果不重新发声。输入切键盘不等于静音。
5. 故障：输出中断/首音失败后文字保留、不自动重发Agent或外呼；下一次用户输入仍可继续。
