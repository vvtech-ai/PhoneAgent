# 统一对话回执共享UI验证（2026-09-17）

## 已实现边界

正式ConversationMessageTile按类型渲染共享CallReceiptCard/BatchReceiptCard，沿用既有实时/历史投影和反馈builder。不是另外写一套HTML产品页。单路显示双方转写、语义状态、实际结构字段和计费；物理COMPLETED但未确认业务结果仍为待确认。批量显示返回数/总数、成功数独立、每项状态/字段/各次计费及独立展开。重排保留对应项状态，身份/status/transcript变化后折叠。

UI不访问HTTP、存储、媒体或拨号；不存在新增确认执行按钮。缺失转写不造记录，缺费用不造扣费，不暴露原始metadata/计费内部ID。既有赞踩/条件评分路径保留。

## 自动验证证据

- `flutter analyze`：无问题。
- `flutter test`：608项通过，相比596新增12项；旧单路文本断言改为结构字段断言，原内容/私有字段排除仍验证。旧开发者测试增加滚动定位，避免新增入口后点击到视口外。
- 新测试：单路未确认、缺字段、批量结果数≠成功数、独立展开/收起、重排、身份/状态/转写重置、320/390/430宽度与1.3倍字体长文本、390×844和320×480连续导航/文字/系统返回/草稿隔离。
- `flutter build web --debug --no-pub`、`flutter build apk --debug --no-pub`：通过。
- `openspec validate --all`：19项通过；本change仍active。
- 正式Web localhost8080：已有登录→拨号解锁开发者→设置→明确MOCK门禁→统一对话回执演练；运行态2/3→展开合成丙→模拟终态3/3且1路成功/2路关注→记录收起→切文字发送→输入清空且本地提示→关闭返回→重开无临时文字。单路成功/失败转写和渐变卡实际截图检查，无异常空白。无真实电话/短信/上传/评价提交。
- 本批没有安装Android/iOS、没有iOS新构建，不把Android构建当真机验证；此前标准安装恢复确认尚待答复，不绕过环境限制。
