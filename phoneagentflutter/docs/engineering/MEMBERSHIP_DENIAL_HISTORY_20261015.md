# 会员拒绝提示历史恢复

用户反馈：会议邀请被会员额度拒绝时，当次提示及 TTS 正常，退出后从任务历史重新进入却没有该段对话。

服务端原账本已保存 `RUN_FAILED`，不是用户对话被删除。原实时解码将权益错误码映射成助手提示，历史投影遗漏该类型。

本次仅在 `ConversationMessages` 和 `ConversationSourceSteps` 复用现有 `MembershipDenialReply`：schema v1 的五种已知权益拒绝恢复为助手消息及来源锚点；稳定事件身份与既有合并逻辑去除实时覆盖层。历史恢复不触发 TTS、任务提交或拨号；未知错误/版本不展示原始诊断，恢复替代轮次继续按原规则过滤。

验证：新用例实际 RED 8项中7失败，修复后相关57项和独立OCR/播报边界22项通过；包含重复恢复仍只有一条、实时合并、后续成功不删除旧提示、历史不播报/不拨号。analyze 无问题，OpenSpec 148项通过。两个集合路径不重叠，不与此前全流程测试相加。

Java 配套修复说明：`aiassistant-java/docs/commerce1837/batch-concurrency-history-fix-20261015.md`。用户账号有效初级权益为两路，而一个联系人任务错误使用系统十路上限校验；新任务绑定账号有效权益，免费档同样适用，原账号在途总并发守卫保留。
