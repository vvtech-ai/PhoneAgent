## 共享实现与模拟边界

- 正式 `ConversationRoute`、准入/通话/监听控制器、`CallSessionPage`、任务列表与恢复流程均复用，不复制页面或更改产品规则。
- `tool/previews/shell_call_preview.dart` 按登录代次、session 管理合成通话；严格检查通话目标，未知目标拒绝。任务和历史使用同一实例。
- 仅隔离服务器识别“演练单路通话”，确认动作委托既有 `PreviewCallFlow`。恢复后普通文字走原共享对话演练，不重新发起单路通话；目录退出或登录变化取消在途命令。
- 监听使用 `PreviewCallMonitor`：音源选择、静音及连接释放可验证，但不产生真实声音。合成挂机固定产生成功结果，仅为样例，不代表真实挂机必然任务成功。
- 正式 `lib`、接口、数据库、权限、SIP/ASR/TTS 与原生配置本批均未改。无真实短信、账户、积分、电话、文件或安全存储操作。

## 可重复路径

1. 打开 [8122验收目录](http://127.0.0.1:8122/) → 基础 App 连续导航 → 订餐厅。
2. 默认语音，切文字发送“演练单路通话”；经共享准入/确认进入单路页。
3. 开始监听 → 选择扬声器 → 停止监听 → 再次开始；只模拟媒体。
4. 挂断后返回统一页并显示合成结果；关闭对话 → 任务 → “MOCK · 演练单路通话”恢复。
5. 恢复后仍默认语音，可切文字发送“再补充一个要求”；应收到补充回复，不重新进入通话页。
6. 普通返回通话页只停止本地观察/监听，不发送挂机；此分支由完整 App 自动测试覆盖。
