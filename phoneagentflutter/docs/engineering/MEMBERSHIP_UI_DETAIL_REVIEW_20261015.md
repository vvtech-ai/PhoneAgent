## 核对表

| 项目 | 实现及边界 |
| --- | --- |
| 积分流水 | 保留余额行右侧，11号蓝字；购买积分保留右上角32高按钮；两者独立回调 |
| 余额与会员摘要 | 真实余额/分钟/赠送；等级、包月等周期及斜线到期日期 |
| 权益卡 | 分层字号、细分隔线、周期选中边框、整数价格千分位；会员专属模型读取目录实际名称 |
| 等级文案 | 中级高峰优先线路，高级高峰极速优先线路及新模型抢先体验；不显示专属号码 |
| 协议与客服 | 会员协议只在购买按钮下，未同意不报价；客服只留底部邮箱 |
| 生效规则 | 初级、中级默认收起；高级一律无入口，包括排队续购 |
| 会员确认与结果 | 紧凑渠道、46高操作按钮；成功后新读权益和钱包，保留升级暂停说明 |
| 积分包与确认 | 白底积分卡、蓝色选中框；确认弹窗18横向留白、19标题、44圆形关闭、30金额、右对齐数值 |
| 订单与发票 | 空表头及暂无更多数据；退款邮箱说明；开票中棕黄、已开票蓝色 |
| 发票查询 | 单订单投影、4并发队列、翻页只读新增订单；拒绝串单、失败不伪造成功；刷新显式失效 |
