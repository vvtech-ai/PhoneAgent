# 定向回归与证据边界

## 复现方式

以真实 ConversationController 和 public message projector，音色端口用受控 Future；选择旧 Consent，等待后返回空列表，随后再次选择。检查整个 messages 顺序，而非只检查包含文字。另以文本“确认使用”执行同一过程。用真实 ConversationPage/MessageTile 检查配置开场接管和提问/卡片分离。

## 回归目标

- 旧卡先于回答，回答先于后续结果；连续选择不会跨轮倒序。
- 查询未完成期间仅旧卡+回答，无查询气泡；旧卡不可二次提交。
- 文本选择也有一次且仅一次回显。
- 道歉专用开场接管配置 opening，普通 Skill 配置 opening 在输入后仍存在。
- 道歉提问气泡在选项容器之外，普通 options 保留标题；道歉选择后保留高亮和失活，组件重建也不丢失；仅新卡可点。
- 后续 committed 到达时，本地提问/回答留在该轮次之前，且不改变上一轮账本事实的位置。
- 复核原有模型切换、pending tool、首轮播报与普通选项回归。
