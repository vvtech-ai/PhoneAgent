### 数值解释

- `w700` 表示字重 700。`行高 20/15` 表示字号 15、行高倍率 20/15，常规字号下行框约为 20。
- `0xAARRGGBB` 的前两位是透明度；保留半透明颜色与底层背景关系。六位 `#RRGGBB` 表示不透明 RGB。
- 区分标准高度、最小约束和最大约束。常规按钮按 D03 保证目标高度；大字号适配遵守该规则的例外条件。

- `scale(n)` 指系统文字缩放后字号 n 的值，`clamp(x,a,b)` 表示将 x 限制在 a 至 b；尺寸公式中的屏幕宽度均为逻辑宽度。
- 项目采用 Material 3，主题种子色与 primary 为 #0A84FF；未指定独立字体家族，继承项目/平台字体。本文未给出独立值的行高、图标尺寸或状态色不能自行称为精确设计标准。
- D01–D06 是已确认的新增规则；C01–C29 是按适用范围使用的组件参数，来源为已核读源码和已确认界面结构；“待核”表示具体值或运行效果尚未确认。

## 2. 必须执行的基础规则

以下六条为新增开发依据。按每条规则的适用范围执行。

<a id="d01"></a>

### D01 新增模块主操作优先使用公共蓝

新模块主操作优先使用公共蓝 #0A84FF。

- 适用于新增模块；现有模块使用原有配色。
- 公共主按钮渐变为顶部 #0A84FF → 底部 #0071EB，白色文字；次要、危险、禁用配色见本文 C03。

<a id="d02"></a>

### D02 所有新增页面统一使用左对齐大标题头部

所有新增页面统一使用左对齐大标题头部，28 / w800。

- 所有新增页面：标题靠左，28 / w800，行高 40/28，沿用 NativeDetailHeader。容器水平内边距 18、垂直 8，文字前另有宽 28 的返回占位。
- 返回区域：左 8、上 4、下 4、宽 48；内部返回操作目标尺寸 48 × 48。标题默认单行省略，可按业务允许换行；右侧操作默认槽位 40 × 40。完整字形参数见本文 C02。
- 适用于新增页面的头部标题。正文、卡片和弹窗标题使用对应组件规格；现有页面使用原有实现。

<a id="d03"></a>

### D03 新增主按钮与次按钮默认高度 50、圆角 18

新增主按钮与次按钮默认高度 50、圆角 18。

- 正常字号、单行文案时，主按钮与次按钮高度统一为 50，圆角 18。
- 仅在系统大字号或必要的文字换行导致内容放不下时，允许自适应增高。
- 实现采用最小高度 50 的约束，配合文字与内边距保证常规状态高度为 50；尺寸单位为 Flutter 逻辑像素。
- 适用于新增主按钮与次按钮；同组按钮高度一致，危险确认沿用同一尺寸。顶部局部保存、图标按钮与选择项使用各自规格；现有按钮使用原有实现。

<a id="d04"></a>

### D04 页面背景使用公共浅色渐变

新增页面默认使用 NativePageBackground：顶部居中径向渐变 #FFFFFF → #F5F7FA → #EAF0F6。

- 渐变停点为 0 / 0.5 / 1；半径为可用尺寸的最长边 / 最短边，最短边为 0 时按公共组件回退值 1。
- 背景铺满页面，绘制在 SafeArea 外；页面内容遵守系统安全区。
- 适用于页面底层背景；输入框、卡片、弹窗和底部面板按各自组件设置表面颜色。

<a id="d05"></a>

### D05 通用信息卡片使用统一表面规格

新增通用信息卡片：圆角 24，白色 80% 不透明度，四周内边距 16，边框与轻阴影沿用 NativeSettingCard。

- 底色 0xCCFFFFFF；边框宽 1、颜色 0xC7FFFFFF。
- 阴影颜色 0x14101114，blurRadius 10，offset (0, 4)，spreadRadius 0；复用组件时沿用完整装饰。
- 卡片高度随内容撑开；同组相邻卡片间距 10。
- 适用于通用信息与设置卡片；输入框、套餐选项、弹窗等独立组件使用各自规格。

<a id="d06"></a>

### D06 页面内容与通用卡片使用默认间距

新增页面内容左右留白 16、模块间距 24；同组卡片间距 10、双列卡片间距 12；卡片内边距 16、标题与说明间距 6。

- 页面左右留白 16：从内容区边缘到卡片外边缘；页头继续使用 NativeDetailHeader 自身布局。
- 模块间距 24：不同内容分组之间的净间距；同组相邻卡片间距为 10。
- 双列卡片间距 12：同一网格中卡片之间的间距。
- 通用卡片四周内边距 16，卡片标题与说明间距 6；独立组件内部使用对应规格。
- 间距只计算一次；复用带底部留白的组件时，父级补足目标间距，避免重复叠加。
- 底部留白按安全区、键盘和底部导航计算；普通列表行的高度与分隔沿用对应组件。所有尺寸为 Flutter 逻辑像素。

<a id="c01"></a>

### C01 页面底色与背景

**使用场景**：新增页面背景与内容底层。

**必须遵守**：

- [D04 页面背景使用公共浅色渐变](#d04)。
- [D06 页面内容与通用卡片使用默认间距](#d06)。

**结构与参数**：

- 页面背景执行 D04；正文左右留白 16。背景先铺满整个页面，再为内容应用系统安全区，不能让状态栏或底部安全区露出另一种底色。
- 不同分组净间距 24；同组卡片 10；双列网格横向和纵向间距 12。正文、卡片内边距及导航避让分别计算，不重复叠加。

**可选复用组件**：`NativePageBackground`；实际接口以开发项目为准，设计取值以上文为准。

<a id="c02"></a>

### C02 标题与详情页头

**使用场景**：所有新增页面的头部标题。

**必须遵守**：

- [D02 所有新增页面统一使用左对齐大标题头部](#d02)。

**结构与参数**：

- 标题左对齐，字号 28、w800、行高 40/28、字距 0、颜色 #111111。容器水平内边距 18、垂直 8；标题前放宽 28、高 40 的占位；标题占剩余可用宽度。无额外父级留白时，标题文字起点距左边 46。
- 常规单行内容行高 40，加上下内边距后头部高 56；这是常规布局结果，大字号或允许换行时不得强制裁切到 56。
- 返回操作定位于头部左 8、上 4、下 4、宽 48 的区域，内部按钮目标尺寸 48 × 48；返回字形 ‹，字号 30、w700、行高 1，向上偏移 2，不随文字缩放。返回占位与操作区域是不同层，不能相加成更宽留白。
- 右侧操作的默认槽位 40 × 40。普通标题最多一行，超长省略；明确需要完整标题时允许换行，不截断。安全区由页头外层负责。

**可选复用组件**：`NativeDetailHeader`；实际接口以开发项目为准，设计取值以上文为准。

<a id="c03"></a>

### C03 通用操作按钮

**使用场景**：确认、次要操作与危险操作。

**必须遵守**：

- [D01 新增模块主操作优先使用公共蓝](#d01)。
- [D03 新增主按钮与次按钮默认高度 50、圆角 18](#d03)。

**结构与参数**：

- 常规主按钮、次按钮和危险确认按钮：高度 50、圆角 18；文字 15 / w700 / 行高 20/15，居中。内容内边距水平 14、垂直 14，外层最小高度约束 50；单行文字行框 20 加垂直内边距为 48，由约束补足至 50。
- 所有按钮渐变从顶部到底部：主按钮 #0A84FF → #0071EB、白字；次按钮 #F2F4F7 → #E8ECF2、文字 #344054；危险按钮 #F36E68 → #E14D46、白字。
- 禁用时覆盖上述配色：渐变 #EEF2F7 → #E8EDF5，描边宽 1、#DCE4EF，文字 #9CA7B5；不可响应点击。启用时无独立描边。
- 同组按钮等高，仅大字号或必要换行放不下时共同增高；不得常规使用 48 或 46 高度。全局不规定固定宽度比例：确认弹窗为 1:1、间隔 10；发票表单为次:主 = 1:2、间隔 10。
- 加载状态禁止重复提交；购买流程的加载指示器尺寸见 C05。加载、禁用和业务校验通过是不同状态，按钮颜色不能替代业务判定。

**可选复用组件**：`NativeGradientAction / InvoiceSheet`；实际接口以开发项目为准，设计取值以上文为准。

### C04 登录表单与按钮

**使用场景**：手机号、验证码、邀请码。

**必须遵守**：

- [D01 新增模块主操作优先使用公共蓝](#d01)。
- [D02 所有新增页面统一使用左对齐大标题头部](#d02)。
- [D03 新增主按钮与次按钮默认高度 50、圆角 18](#d03)。
- [D04 页面背景使用公共浅色渐变](#d04)。
- [D06 页面内容与通用卡片使用默认间距](#d06)。

**结构与参数**：

- 登录表单水平居中，最大宽 320；实际宽度取 320 与页面正文可用宽度的较小值，页面正文左右留白 16。
