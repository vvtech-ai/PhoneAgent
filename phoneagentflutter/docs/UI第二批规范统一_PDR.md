## 文件职责与扩展方式

- core/design/native_action_style.dart：只负责C03装饰与按钮样式；现有各按钮保留FilledButton/TextButton类型、操作回调及内容，只接入样式。NativeGradientAction不承接业务状态。
- core/design/native_card_style.dart：只负责D05通用装饰；底部导航继续使用ShellTokens.softShadow。通用卡复用装饰而非统一包装业务Widget。
- home/presentation/widgets/home_card_extent.dart：只按可用宽度、当前字体和标题/说明测量网格高度；本地2x画面发现固定高度会裁切，先用320宽测试复现55高不足78高，再改为内容测量。保留双列、行列间距12、卡片准入和点击，不参与Skill业务选择。
- core/design/native_navigation_backdrop.dart：只负责旧版底部背景绘制及可见时的正文避让范围；壳页面仅组合，不新增状态。首页/联系人/任务/设置保留各自ScrollView与控制器，仅在底部原留白上加导航避让；独立打开时附加值为0。后续类似主页面复用同一UI避让入口，不复制模糊或导航业务。
- 各presentation页/控件：仅接入样式、背景、边距/宽度；不向大文件添加状态或新业务分支。类似页面后续复用上述样式和已有页面背景。
- AGENTS与本PDR声明本批迁移；OpenSpec unify-app-ui-standards保存任务、规则及真实证据，不重写首批历史。
