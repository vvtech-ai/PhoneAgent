# 常见问题

[English](FAQ.en.md) | 简体中文

## Phone Agent 当前开源了什么？

本仓库开放 Android 终端源码、构建配置、测试样例、文档，以及经授权可公开分发的公司自有 CHAKEN 可信通信 SDK。后台、管理后台、数据库和生产运维配置不在仓库中。

## 克隆后可以直接构建 APK 吗？

准备 JDK 11、Android SDK 33 和 Android SDK 路径后，可以执行 `:app:assembleProdDebug` 构建连接默认托管服务的调试 APK。正式分发需要使用自己的签名。详见[构建与配置](BUILD_AND_CONFIGURATION.md)。

## 构建 APK 是否等于获得全部在线服务？

不是。托管服务、账号、短信、电话线路、模型、地图、存储、额度和区域能力与 Apache-2.0 源码许可相互独立，以实际服务策略为准。

## 后台是否开源？能否完全私有化部署？

当前后台不开源，本仓库也不提供完整私有化部署材料。`local` 构建变体允许指向自行实现的兼容服务，但开发者需要独立实现客户端所需的 HTTPS、SSE、WebSocket、认证、任务、通话和记录协议。

## 模型 API Key、短信和 SIP 账号在哪里？

这些凭据只应存在于受控的服务端环境，不应写入 Android 源码、示例属性、APK 或日志。APK 中可提取的值只能是供应商明确允许在客户端分发、可撤销且权限受限的参数。

## Call Skill 已经可以开发了吗？

尚未。Call Skill 是公开路线方向，目前发布的是愿景、概念模型和贡献入口，不是可执行 SDK。状态变化会更新在[路线图](ROADMAP.zh-CN.md)。

## 当前可以贡献什么？

欢迎贡献 Android 客户端功能、稳定性修复、自动化测试、文档、翻译、隐私与安全改进，以及包含输入、结果、风险和测试用例的 Call Skill 场景提案。

## 为什么部分功能在自行构建后不可用？

常见原因包括托管服务未开放对应能力、账号或额度限制、电话线路与区域限制、缺少可选商业 SDK、设备权限、网络环境，以及第三方服务异常。先查看[已知问题](KNOWN_ISSUES.md)和客户端日志。

## 是否可以将 Phone Agent 用于批量营销电话？

不得使用本项目进行骚扰、垃圾外呼、欺骗或未经授权的身份模拟。任何真实电话、录音、联系人、位置、翻译或声音克隆使用都必须遵守所在地法律、运营商规则、供应商条款，并取得必要授权和告知。
