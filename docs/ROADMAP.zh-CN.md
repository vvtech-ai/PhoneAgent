# Phone Agent 路线图

[English](ROADMAP.en.md) | 简体中文

本路线图用于公开项目方向，不承诺具体发布日期、服务额度或最终接口形态。

## 当前：夯实开源终端

- Android 原生任务、拨号、实时翻译、记录和设置体验
- 托管模型目录与终端音色偏好
- 可信通信组件和可选商业 SDK 边界
- 网络、SSE、WebSocket、SIP、WebRTC 与音频链路稳定性
- 构建文档、权限说明、测试和问题定位能力

## 近期方向：定义 Call Skill

- Skill 身份、版本和兼容模型
- 意图匹配与输入槽位规范
- 用户确认、权限声明和安全策略
- 对话策略、工具声明和结果 Schema
- 错误、拒绝、无应答和人工接管语义
- 示例场景、提案模板与测试用例

## 后续方向：开发者工具

- Call Skill SDK 和参考实现
- Manifest / Schema 校验工具
- 本地调试、模拟电话和回放测试
- 示例 Skill 与开发者文档
- 终端与托管服务的能力协商和版本兼容

## 长期探索：社区生态

- 社区 Skill 目录与发现机制
- 质量、安全、隐私与兼容审核
- Skill 版本、签名、更新和撤回机制
- 行业开发者与服务提供方的扩展接口

## 不在本路线图中的承诺

- 后台源码开源或完整私有化部署；
- 免费、无限或覆盖所有区域的电话服务；
- 未经审核的 Skill 自动获得真实外呼权限；
- 对具体模型、线路或第三方服务的永久支持。

欢迎通过[贡献指南](../CONTRIBUTING.md)参与 Android、文档、测试和 Call Skill 设计。
