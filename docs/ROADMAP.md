# Phone Agent Roadmap

This roadmap communicates project direction. It does not promise release dates, service quotas, or final API shapes.

## Now: strengthen the open client

- Native Android task, dialing, translated-call, history, and settings experiences
- Hosted model catalog and client-side voice preferences
- Trusted-call integration and clear optional-commercial-SDK boundaries
- Reliability across HTTP, SSE, WebSocket, SIP, WebRTC, and audio paths
- Build documentation, permission guidance, tests, and troubleshooting

## Near-term direction: define Call Skills

- Skill identity, versioning, and compatibility model
- Intent matching and input-slot specification
- User confirmation, permission declarations, and safety policy
- Dialogue policy, tool declarations, and result schemas
- Error, rejection, no-answer, and human-handoff semantics
- Example scenarios, proposal templates, and test cases

## Later direction: developer tooling

- Call Skill SDK and reference implementation
- Manifest and schema validation
- Local debugging, simulated calls, and replay tests
- Example Skills and developer documentation
- Client/hosted-service capability negotiation and version compatibility

## Long-term exploration: community ecosystem

- Community Skill catalog and discovery
- Quality, safety, privacy, and compatibility review
- Skill versioning, signing, updates, and withdrawal
- Extension interfaces for industry developers and service providers

## What this roadmap does not promise

- Open-sourcing the backend or complete self-hosting;
- free, unlimited, or globally available telephony;
- automatic real-call access for unreviewed Skills;
- permanent support for any specific model, carrier, or third-party service.

See the [contribution guide](../CONTRIBUTING.md) to participate in Android, documentation, testing, or Call Skill design.
