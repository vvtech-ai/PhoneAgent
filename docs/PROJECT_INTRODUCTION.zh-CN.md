# Phone Agent 项目介绍

[English](PROJECT_INTRODUCTION.en.md) | 简体中文

## 项目定位

Phone Agent 是面向电话事务处理的智能终端。它把“用户描述需求、系统理解任务、准备并执行电话、回看结果”组织成一条完整的移动端工作流，让用户能够用自然语言处理订餐厅、会议通知、事务协调、实时翻译等电话场景。

本开源项目提供 Android 终端，不提供后台源码。模型推理、短信认证、任务编排、地图检索、SIP 外呼及数据服务运行在已部署的托管后台中。

## 用户流程

### 1. 登录与准备

用户使用手机号和短信验证码登录或注册。首次使用时，应检查网络、麦克风和扬声器/耳机，并按实际需要授权联系人、电话、定位或相机权限。

![登录界面](images/login.png)

### 2. 首页与任务入口

首页展示电话任务入口、当前通话模型和底部主导航。用户可以选择已开放的场景，或从中央语音入口进入通用任务。

![首页](images/home.png)

### 3. 语音或文字描述任务

任务页完成运行环境检测后，可按住语音按钮说出任务，也可以切换到文字输入。系统会理解任务、补充必要信息并请求用户确认。

![语音任务](images/task-voice.png)

![文字任务](images/task-text.png)

### 4. 通话与实时翻译

通话页用于确认被叫号码、模型和实时翻译开关。受支持的任务可以由后台智能体执行外呼；实时翻译场景还会在终端展示双方转写与翻译结果。

![拨号准备](images/dialer.png)

### 5. 记录与结果

完成后的通话会进入记录列表。用户可以查看时间、号码、通话转写、任务结果及有权限访问的录音。

![通话记录](images/call-history.png)

### 6. 设置与音色

设置页集中管理身份资料、AI 通话模型和语音、可信来电、版本更新及日志上报。获得相应商业服务授权后，还可以接入声音克隆身份认证。

![设置页](images/settings.png)

![AI 音色](images/voice-settings.png)

## 核心能力

- 自然语言电话任务：支持语音和文字输入。
- AI 任务理解：通过对话补齐时间、地点、联系人、人数等必要信息。
- 电话执行：由托管后台编排模型、SIP 和业务工具。
- 实时翻译：支持通话过程中的双向转写和翻译展示。
- 联系人与拨号：读取用户授权的本地联系人并辅助号码选择。
- 结果沉淀：保存任务状态、通话记录、转写和回执。
- 模型与音色设置：显示后台开放的模型，并管理终端侧偏好。
- 可观测性：在用户主动操作下导出或上传客户端日志用于问题定位。

## 技术概览

- Kotlin、Jetpack Compose、AndroidX
- MVVM、单向数据流、Kotlin Coroutines 与 Flow
- Retrofit / OkHttp HTTP 与 SSE 通信
- WebSocket 音频和实时事件通信
- 终端 SIP、WebRTC、音频采集与播放能力
- 本地缓存、联系人、通话记录和 OTA 集成

## 开源边界

本仓库的目标是让开发者理解、构建和扩展 Android 终端。以下内容不属于开源范围：

- Java/Spring 服务端和管理后台源码；
- 模型、短信、SIP、地图、对象存储等生产凭据；
- 生产数据库、运维脚本、部署拓扑和内部研发记录；
- 未获得公开再分发许可的商业 AAR/JAR。

终端和托管后台之间通过 HTTPS、SSE、WebSocket 及电话媒体协议协作。开发者可以更换界面、终端策略或接入自有兼容服务，但不能从本仓库推导出服务端实现。

## 使用责任

电话外呼、录音、联系人、身份资料、位置和声音克隆可能受到法律、运营商及供应商规则约束。使用者应取得必要授权，避免输入无关敏感信息，并对自己的号码、内容、资费和合规性负责。
